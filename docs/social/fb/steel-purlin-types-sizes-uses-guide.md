The most common secondary member in a steel building — the purlin — comes in two main profiles: Z and C. Z purlins lap and suit longer multi-span roofs; C purlins are common for shorter spans and wall girts. But purlin size, spacing and steel grade are never guessed: span, wind, snow, roof slope and the local code all change the answer — there is no universal size table.
