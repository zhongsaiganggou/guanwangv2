The HS code is decided long before the container reaches the port. A fabricated steel building kit usually sits under 7308, a complete prefabricated building may fall under 9406, and unprocessed mill sections belong to 7216 — and that choice drives duty, origin treatment and trade measures. This guide covers the classification logic, how the invoice and packing list must describe the goods, and six misclassification patterns worth fixing before loading.
