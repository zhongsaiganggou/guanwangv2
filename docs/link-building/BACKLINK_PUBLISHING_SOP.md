## 0. 铁律（任何一条违反即停止本轮动作）

1. **真实不编造**：不虚构客户、项目、面积、吨位、跨度、交期、认证、出口国家、价格、节省比例、当地办公室或施工队。工程参数无依据不给固定全球值，写 `depends on drawings / loads / local code / use / crane / corrosion / fire / transport`。
2. **品牌事实只用**：做钢结构 20 年、专注出口 15 年、年产 10 万吨、300+ 工人、CE EN 1090 / CSA CWB / CIDB、销往 40+ 国家；法定名称 **深圳市中赛钢结构进出口有限公司**；品牌 **中赛钢构 / ZhongSai Steel Structure**。
3. **禁用表述**：`own factory / 自有工厂`（改用 our manufacturing bases / 中赛制造基地）；`world-class / leading / No.1 / best / cheap`；不写「年销 1.3 亿」等未对外公开数字；不公开每㎡单价。
4. **联系方式口径**：留官网与 WhatsApp `https://wa.me/8613113270408`（新号 +86 131 1327 0408；电话接听仍可用旧号 +86 131 1327 0408）；正文/简介不写微信；企业邮箱统一为 `zb@zhongsai-steelstructure.com`，不把个人 Gmail 写进新发布内容。
5. **落地页必须已上线**：外链只能指向 Production 域名返回 200 的页面；发布前必须 HEAD/GET 复核，禁止指向 Preview、404、薄页面或未发布稿。
6. **不碰验证码 / 密码 / OTP / 证件**：人机验证、短信码、扫码、KYC 证件属本人接管检查点；agent 不代填、不绕过、不换无关平台凑数。
7. **质量优先于铺量**：宁缺毋滥。渠道会话失效、卡点未解、稿件不达标准时，本轮转为适配准备/观测/外联准备单元，**禁止向低质链接农场、无关行业站或已判死路平台硬发内容凑数**。
8. **URL Freeze**：外链流水线不修改官网任何 URL、路由、表单、API、canonical、hreflang、redirect、GA4、DNS。

## 1. SEO 前提：先认清每条外链能带来什么

### 1.1 实测链接性质（2026-11-23 台账结论，新观测结果优先更新）

| 平台 | 链接形态 | rel | 对 Google 权重的作用 | 实际价值定位 |
|---|---|---|---|---|
| 知乎专栏 | `link.zhihu.com/?target=` 跳转包装 | `nofollow noreferrer` | 不传直接权重 | 品牌曝光 + 中文 SERP 占位 |
| LinkedIn 个人号 | `lnkd.in` 短链包装 | nofollow | 不传直接权重 | B2B 引荐流量 + 品牌曝光 |
| 简书 | `links.jianshu.com/go?to=` 跳转包装 | 待回读确认 | 预期 nofollow/包装 | 品牌曝光 + 中文 SERP 占位 |
| Scribd | 文档内网址是否可点/被索引待观察 | 待观察 | 权重低 | 文档资产 + 品牌曝光 |
| CSDN | 流量偏百度，Google 收录一般 | 待观察 | 有限 | 技术形象补充，不作主力 |
| 行业媒体 guest post | 预期正文/作者简介直链 | 预期 dofollow | **可传导权重** | 高价值外链（需外联达成） |
| 商会/协会名录 | 预期目录页直链 | 预期 dofollow | **可传导权重** | 高价值外链（需入会/列名） |
| 客户/供应商互链 | 双方站点直链 | 预期 dofollow | **可传导权重** | 高价值外链（需双方同意） |
| 免费 B2B/黄页目录 | 审核后可能为直链 | 待回读 | 视目录质量而定 | 补充曝光与品牌词覆盖 |

> 结论：当前可自动化投递的内容平台（Tier B）几乎都是 nofollow/包装，**考核口径是品牌曝光、SERP 占位与引荐流量，不按权重外链计数**；真正能传导权重的 Tier A 路径必须靠外联与合作达成，每日链只做准备与跟进，不自动提交。

### 1.2 蚕食与重复内容检查

- 外链主题不得与当天站内新文章撞同一搜索意图；现有官网页面已覆盖该意图 70–80% 时，不另发同义外链稿。
- 第三方稿件基于已发布官网文章**改写适配**（调整开头、保留核心结论与清单、按平台格式重组），不做整段复制，避免平台侧重复内容判定。
- 同一篇官网文章不在同一天铺到多个 Tier B 平台；同一渠道连续两篇必须换主题、换锚文本。
- 选题优先沿用历史表现好的主题并扩展为系列；按既定要求纳入 CIDB（马来西亚建筑工业发展局）相关主题。

### 3.1 渠道频率上限（反 spam，硬性）

- Scribd ≤1 篇/周；LinkedIn ≤1 帖/周；简书 ≤1 篇/2 周；知乎暂停第二篇（观测解除前）；CSDN 卡点解除前为 0。
- 同一平台两次发布之间至少满足上表间隔；新号养号期不连续发外链稿。
- 每个平台每篇外链数量遵守其上限（简书 ≤2 条；其余按平台实测规则，超出会被拦截或折叠）。

### 3.3 候选选题池（与站内选题池衔接，避开蚕食）

- 沿用 `docs/published-topics.md` 与 GSC 数据机会；历史表现好的主题优先扩展系列。
- 固定纳入方向：CIDB / COA 进口构件路径、SNI/当地合规、FOB/CIF 与出口单证、钢材等级选型（Q235B/Q355B）、仓储/车间/农业建筑选型、防腐与涂层、安装分工与误区。

## 4. 内容适配规范（按平台格式，不改事实）

### 4.1 通用结构

- 开头 2–3 句直接回答买家问题（GEO 可摘取口径）；正文给清单/步骤/对比结论；结尾品牌段 + 自然链接位置。
- 品牌段口径取自 `company-profile-pack.md`，但遵循 §0 铁律（去 own factory、去未公开数字）。
- 责任边界写清：中赛负责 engineering coordination/detailing、fabrication/QC、marking/packing/container loading、export coordination、installation technical guidance；当地负责 permits/registered engineer、foundations/civil、local labour/physical erection、authority submissions。

### 4.2 平台格式要点（实测结论，避免重复踩坑）

- **简书**：只保留 `p / b / i / a`；h1–h4、ul/ol、blockquote 会被剥成段落；Markdown 前缀（`#`、`-`）实时键入不转格式；裸 URL 不自动转锚点；直写保存接口不可用，必须编辑器原生键入 + 失焦等待自动保存，刷新后 GET 回读核验落库。定稿用纯段落版（【】小节标题、「· 」前缀列表），Markdown 原稿勿直粘。
- **Scribd**：仅接受 PDF/DOCX 类文档；Markdown 需先排版导出 PDF；标题、描述、分类（Business / Construction & Engineering）、标签、语言填全；公开不私有；版权选 © All Rights Reserved；PDF 内不放个人 Gmail。
- **LinkedIn**：普通帖正文 URL 自动成短链，不能给词加超链接；导语 + 价值口径段 + 落地链接 + WhatsApp 直达 + 标签；中英双语分段。
- **CSDN**：技术稿风格；标签与封面条件满足前只存草稿。
- **知乎**：优先回答体；新号期不在评论区反复贴链接。

## 5. 发布门禁与登录态处理

### 5.1 会话核验

每轮投递前先在云电脑浏览器核验目标平台登录态：跳登录页 / 要求短信码 / 人机验证 / 扫码 = 会话失效。失效则：
1. 不在该渠道强行操作；
2. 已适配好的稿件落 `docs/link-building/drafts/`；
3. 登记表标注 `blocked: login / captcha / KYC / level / cover` 与卡点细节；
4. 简报说明本轮为何未发布，不重试刷验证。

### 5.2 卡点分类登记

| 卡点类型 | 处置 |
|---|---|
| 登录态过期（短信 OTP / 扫码） | 待本人接管重新登录；会话保存后后续轮次再推进 |
| 人机验证 / reCAPTCHA / 点击验证码 | 暂停，不绕过 |
| KYC / 营业执照 / IEC 证件 | 待本人提供材料；中国主体无印度 IEC 的渠道永久暂停 |
| 平台等级 / 绑定要求（CSDN 三级标签、微信绑定） | 存草稿，条件满足后再发 |
| 封面缺图 | 用 `E:\中赛\工厂图片` 真实素材裁切，或按站内配图规范生成示意图并标注「示意图」；禁止 AI 图冒充真实项目 |

### 5.3 发布按钮授权分级

- **已授权可自动发布**：台账/登记表明确标注「授权自动发布」的渠道，会话有效且稿件、链接、平台校验全部通过后，云电脑可点发布。
- **未授权 / 检查点渠道**：简书等台账标注「发布按钮属本人授权检查点」的渠道，只保存草稿、回读落库，**不代点发布**；在简报与登记表中提示本人复核后发布。
- 渠道授权状态在登记表维护；变更需本人确认。

### 5.4 发布前自检清单

- [ ] 目标落地页 Production 返回 200（本轮 HEAD/GET 复核）
- [ ] 稿件事实、数字、认证、国家与 §0 铁律一致
- [ ] 锚文本自然、数量符合平台上限；无微信、无个人 Gmail、无单价、无 1.3 亿
- [ ] 主题未与当天站内新文章、现有官网页面蚕食
- [ ] 平台格式适配完成；链接位置在文末参考资料/作者简介自然位
- [ ] 会话有效；该渠道未达频率上限
- [ ] 授权状态允许本轮点发布（否则存草稿）

| 节点 | 检查项 |
|---|---|
| 发布当天 | 链接形态（直链 / 跳转包装）、rel（nofollow?）、是否可点、有无「含外部链接 / 待审核 / 仅自己可见 / 违规」提示；记录原始 HTML 片段 |
| 24 小时后 | 回读文章链接是否存活、正文有无被改写/折叠；Google `site:<平台域名> 中赛钢构` 初查收录 |
| 7–14 天 | 收录情况；GA4 对应落地页来源是否出现该平台引荐；链接是否仍存活 |

### 6.2 结论分级（回写登记表）

- ✅ **直链可点、无 nofollow、存活** → 该平台可按频率上限复用；
- ⚠️ **跳转包装或 nofollow** → 仅作品牌曝光/引荐渠道，不投入批量铺量；
- ❌ **链接被删 / 新号禁链 / 内容被折叠** → 暂停该平台，先养号或换形态；
- 连续观测两周无收录、无引荐 → 降级该渠道优先级，周报中提出调整建议。

### 6.3 周日回检轮输出

- 近 14 天已发条目逐条状态；新增收录/引荐/流失结论；
- 渠道分级是否需要调整；卡点渠道是否已具备解除条件；
- 更新 `backlink-register.md` 与 `zh-platform-draft-01.md` 观测清单。

## 7. 成功口径与复盘

- **不以「每日发了几篇外链」为成功指标**。成功 = 可索引的品牌曝光位积累、有效引荐流量、以及 Tier A 可传导权重直链的逐步达成。
- 每周简报汇总：本轮单位类型、渠道、落地页、链接形态/rel、状态、卡点、观测结论。
- 每季度复核一次渠道分级：新开通的高价值目录/媒体升级；长期无收录无引荐的渠道降级；死路清单同步更新到 `directory-targets.md`。

## 8. 与站内发文链的边界

- 站内链（v3，09:00）：产出官网 EN/ZH 文章并部署；外链链只引用已上线的站内页面，不反向修改站内内容。
- 外链链不构建、不部署官网、不 push 官网仓库代码；稿件草稿与台账文档的版本管理按仓库既有规则处理。
- 两条链选题共享 `published-topics.md` 去重库与蚕食检查，避免同主题左右互搏。
