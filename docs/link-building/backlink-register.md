## 三、回写规则

1. **新发布**：新增一行，当天记录链接形态、rel、可见性；24h / 7d / 14d 观测列按节点回填。
2. **存草稿**：状态 📝，卡点类型与解除条件写清；稿件路径指向 `drafts/` 下对应文件。
3. **目录回查**：更新对应行状态；条目上线后补公开 URL 并回读链接形态/rel。
4. **观测分级**：按 SOP §6.2 标 ✅ / ⚠️ / ❌；❌ 渠道移入第二节暂停表。
5. **去重**：同一渠道同一主题不重复登记；换稿换主题才新增行。
6. 本表与 `zh-platform-draft-01.md` 台账冲突时，以最新回读的线上/服务端状态为准，并同步修订两处。
