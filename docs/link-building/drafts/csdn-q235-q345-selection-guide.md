## 正文（粘贴用，Markdown）

Q235 和 Q345 是中国预制钢结构建筑中最常用的两种结构钢牌号。**Q235** 最低屈服强度 235 MPa，多用于次要构件、檩条和低荷载部位；**Q345** 最低屈服强度 345 MPa，多用于工业厂房、仓库和大跨度结构的主承重构件，如柱子、主梁和桁架。

牌号里的「Q」是屈服点的拼音首字母，数字表示以 MPa 为单位的最低屈服强度。选哪种等级，直接影响材料成本、构件截面、焊接性能和整体结构效率。

### 一、为什么钢材等级不能随便选

- **结构安全**：等级决定每个构件的承载能力。
- **材料成本**：高强度等级每吨更贵，但可以减少总用钢量。
- **构件尺寸**：Q345 在相同荷载下可以用更小截面，节省空间和重量。
- **焊接性能**：不同等级碳当量不同，焊接工艺要求不同。
- **采购周期**：Q235、Q345 国内供应充足，其他等级交货期可能更长。

多数标准厂房和仓库，常见组合是主构件用 Q345、次构件用 Q235，兼顾安全与成本。

### 二、Q235：通用碳素结构钢

Q235 对应 GB/T 700 碳素结构钢，是国内用量最大的通用结构钢。

| 性能指标 | Q235 数值 |
|---|---|
| 最低屈服强度 | 235 MPa（厚度 ≤16mm 时） |
| 抗拉强度 | 370–500 MPa |
| 断后伸长率 | ≥26% |
| 碳含量 C | ≤0.22% |
| 硫含量 S | ≤0.050% |
| 磷含量 P | ≤0.045% |

**常用部位**：屋面墙面檩条（C/Z 型钢）、次梁、支撑构件、平台走道、爬梯栏杆、围护配件和泛水板。

**优势**：碳含量低、焊接性能好；成形性和延展性好；供应充足、价格有竞争力；适合冷弯型钢。

**局限**：强度较低，重载构件需要更大截面；不适用于大跨度主结构；相同荷载下材料用量可能更多；不推荐用于多层建筑的高荷载柱。

### 三、Q345：低合金高强度结构钢

Q345 对应 GB/T 1591 低合金高强度结构钢，是主承重构件的常用牌号。

| 性能指标 | Q345 数值 |
|---|---|
| 最低屈服强度 | 345 MPa（厚度 ≤16mm 时） |
| 抗拉强度 | 470–630 MPa |
| 断后伸长率 | ≥21% |
| 碳含量 C | ≤0.20% |
| 硫含量 S | ≤0.035% |
| 磷含量 P | ≤0.035% |

**常用部位**：建筑主柱（H 型钢、箱型截面）、屋面主梁、吊车梁、大跨度桁架和拱结构、多层框架、重载平台、桥梁大梁和抗震区主框架。

**优势**：强度重量比更高；可减小截面、降低总用钢重量；适合大跨度和重载；工艺适当时焊接性能良好；延展性好，适合抗震设计；上部结构更轻，可减轻基础荷载。

**局限**：每吨材料成本高于 Q235；合金含量更高，焊接工艺需要更仔细；厚截面或低温焊接可能需要预热；必须核对碳当量保证焊接性能。

### 四、强度、成本与焊接对比

**强度**：Q345 屈服强度比 Q235 大约高 47%。相同截面下 Q345 可承受更大荷载；相同荷载下可选用更小截面。典型工业厂房主构件用 Q345，相比全部用 Q235，总用钢量通常可减少 15–25%，实际节省取决于荷载、跨度和截面配置。

**成本**：

| 因素 | Q235 | Q345 |
|---|---|---|
| 每吨材料成本 | 较低 | 较高（通常高 5–15%） |
| 总用钢量 | 较高 | 较低（相同荷载下） |
| 整体项目成本 | 重型结构可能更高 | 大跨度/重载建筑通常更低 |
| 运输成本 | 较高（更重） | 较低（更轻） |

小型轻型结构用 Q235 更划算；大型厂房、带吊车仓库和大跨度结构，Q345 往往整体价值更好。

**焊接**：两种牌号都可焊接，但注意点不同。

- **Q235**：焊接性能优异，低碳当量，正常厚度一般不需预热；可用 E43 系列焊条、ER49-1 焊丝。
- **Q345**：焊接性能良好但需更多注意，合金含量提高了碳当量；厚截面（通常 >25mm）或低温环境可能需要预热；用 E50 系列焊条或 ER50-6 焊丝。

碳当量（CEV）是关键指标：Q235 通常 ≤0.40%，Q345 通常 ≤0.45–0.50%；CEV 超过 0.45% 时，一般建议预热并采用受控焊接工艺。

### 五、质量等级 A/B/C/D/E

牌号后面的字母是冲击韧性等级：

| 等级 | 冲击试验温度 | 典型应用 |
|---|---|---|
| A | 无冲击要求 | 一般次要结构 |
| B | +20°C | 常见建筑结构 |
| C | 0°C | 寒冷地区结构 |
| D | -20°C | 严寒/抗震环境 |
| E | -40°C | 极寒环境 |

温带气候多数项目用 Q235B、Q345B 即可；寒冷地区或抗震设计可能需要 C、D、E 级。

### 六、按项目选型的决策框架

1. 确定构件功能：主承重还是次要构件。
2. 确定荷载：轻型/中型/重型，有无吊车荷载、是否在抗震区。
3. 检查跨度：短跨度（<15m）还是大跨度（>20m）。
4. 权衡成本：材料单价 vs 总用钢重量 vs 基础节省。
5. 考虑焊接：现场焊还是工厂焊、板厚、环境温度。
6. 核对当地规范：抗震设计规范和建筑法规。

**常见项目建议**：

| 项目类型 | 主构件 | 次构件 |
|---|---|---|
| 轻型仓库（无吊车） | Q345B 或 Q235B | Q235B |
| 标准工业厂房 | Q345B | Q235B |
| 带桥式吊车厂房 | Q345B（柱、吊车梁） | Q235B |
| 大跨度仓库（>20m） | Q345B | Q235B |
| 多层钢结构建筑 | Q345B 或 Q345C | Q235B |
| 寒冷地区结构 | Q345C 或 Q345D | Q235C |
| 抗震区主框架 | Q345B 或 Q345C | Q235B |

### 七、容易踩的六个坑

1. 重型结构全部用 Q235：截面过大、重量增加、基础成本上升。
2. 轻型次构件指定 Q345：增加成本却没有收益。
3. 忽视焊接要求：Q345 厚截面的焊接工艺和预热不能省。
4. 不考虑等级现货：D、E 级交货期可能更长。
5. 混淆屈服强度和抗拉强度：牌号数字指屈服强度，不是抗拉强度。
6. 不考虑厚度效应：屈服强度随厚度增加而降低；板厚超 16mm 时保证屈服强度可能更低（如 Q345 在 16–35mm 为 325 MPa，35–50mm 为 295 MPa）。

### 八、国际牌号近似对照

| 中国牌号 | ASTM A36/A572 | EN 10025 | JIS |
|---|---|---|---|
| Q235B | A36（近似） | S235JR（近似） | SS400（近似） |
| Q345B | A572 Grade 50（近似） | S355JR（近似） | SM490（近似） |

注意：以上是近似对照，不是精确替代；不同标准的化学成分和力学性能略有差异，国际项目务必与适用规范和负责工程师核实。

### 九、采购前的钢材等级检查清单

- [ ] 每类构件指定的等级（主构件 vs 次构件）
- [ ] 质量子等级（按气候和抗震要求选 A/B/C/D/E）
- [ ] 厚度范围，注意屈服强度随厚度变化
- [ ] 焊接工艺，尤其是 Q345 厚截面
- [ ] 材料证书（MTC，EN 10204 3.1）
- [ ] 是否需要第三方检验
- [ ] 表面处理：底漆、镀锌或涂层规格
- [ ] 制造公差标准
- [ ] 是否接受等效国际等级替代
- [ ] 指定等级和子等级的交货期
