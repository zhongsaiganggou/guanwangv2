## 6. 边界与未做项（如实声明）

- S2（46 页 hero-bg）、S3（项目卡）、S4（图片 TTL）、S5–S7 全部未动。

- manifest 是 gitignore 的构建产物：**单独跑 `astro build`（不经 `npm run build`）会缺 manifest**，此时模板自动回退原 JPEG 并 console.warn，不会失败；正式 CI/本地都走 `npm run build`，无影响。
- `zh-container`（生产 301 合并页）按既有记录从取样中排除。
- 1600w 档保留（retina 桌面用），全量变体 55.4MB 暂不裁撤；若要省体积，裁掉 1600 档约省 15MB，可后续决定。
- 回滚方式：还原 4 个改动文件（`.gitignore`、`package.json`、两个 astro 模板）即可；变体目录与 manifest 均 gitignore，无需清理。
