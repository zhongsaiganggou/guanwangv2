# 询盘诊断：GSC「网页会自动重定向」352 页 + 询盘归零

日期：2026-11-16
数据源：GSC 覆盖报告导出（2026-11-13 快照）+ 逐条重定向实测 + `tools/gsc-baseline/gsc-A-pages.csv`（2026-10-10 至 11-06）+ 生产 D1 `zhongsai-leads`

## 一、结论先行

1. **GSC 那 352 条"会自动重定向"不是询盘减少的原因。** 逐条实测：341 条一跳、2 条两跳，**349 条最终落到正常页面（HTTP 200）**，只有 3 条是真死链。这些是旧站 URL 迁移留下的规范地址改写，属于正常状态。
2. **索引本身是健康的。** 已编入索引 340 个（sitemap 318 条，全是带尾斜杠的规范地址，无一条 legacy URL）；未编入索引 684 个里，352 是重定向、223 是旧 URL 的 404、89 是备用网页——都是迁移残留。这三类里，凡是本地能核到的（352 条重定向、10-07 归档的 266 条 404）已全部处置完，剩下的只是没枚举过的旧 URL。
3. **询盘归零的真因已经确认并修复**：10-31 的提交 `9fb1cc0` 同时干了两件坏事——把微信改成必填（海外买家多数不用微信，浏览器原生校验直接拦住）、并给 INSERT 加了 `gclid/gbraid/wbraid` 三列但生产库从没加（每次提交在写库阶段抛错返回 500）。11-01 至 11-14 期间 D1 零新增即为此。11-14 已修复并真实提交验证通过。
4. **真正制约询盘量的是流量基数，不是索引。** GSC 28 天（10-10 至 11-06）：106 次点击 / 9,102 次展示，CTR 1.2%，平均排名 18，**日均约 3.8 次点击**。即使转化率做到 100%，一个月也只有 3～4 个询盘。要涨询盘，必须同时动流量和转化率，只修网站技术问题不够。
5. **截图里那排「验证 失败」不代表没修好。** GSC 的"验证"是复核你的修复：对"重定向"和"未找到 (404)"这两类，旧 URL 本来就会一直返回 301/404，条件永远成立，所以验证永远失败——这是分类本身的定义，不是新问题。这两类桶的正确处理是：确认跳转都落在正常页，然后把桶当作迁移噪声归档，不要反复点验证。「备用网页（有适当规范标记）」89 条同理，它恰恰说明 canonical 在正常工作。

## 五、按见效速度排序的增询盘动作

**第 1 档（已完成，2026-11-16 已上 Production）。** 13 条旧 URL 已全部 301 到现存页（5 条死链 + 8 条错杀），生产站逐条实测通过，明细见 3.1 节。影响：止住旧 URL 的权重流失，让 Google 把历史排名信号传给现存页。

**第 2 档（已确认，2026-11-16）：没有付费流量。** 用户确认：Google Ads 与 Meta 从未投放。这一条把整条链路定性了——**官网询盘 100% 来自自然搜索**，而自然搜索 28 天只有 106 次点击（日均 3.8）。按现有转化口径（9 月至 11 月约 143 次点击换来 4 条真实外部线索，≈2.8%）推算：

| 自然搜索 | 点击/28 天 | 预期真实询盘/月 |
|---|---|---|
| 现状 | 106 | **约 1～3 条** |
| 42 个零点击页的 CTR 从 0% 提到 2% | +59 | 约 2～4 条 |
| 流量翻倍 | 212 | 约 5～6 条 |

结论：**"最近没询盘"是两件事叠加**——10-31 至 11-14 表单彻底无法提交（已修，已实测），而在此之前也只是每个月 1～3 条的量。想显著增量，只有三条路：拉自然搜索点击、上付费流量、或走社媒/WhatsApp 直接触达。技术修修补补的天花板就在这里。

**第 3 档（2～4 周）：把已有流量往"发图纸报价"上推。**
- 5 个高展示技术文（锚栓安装、MTC、NDT、装箱发运、风荷载）文末已有 `ctaType: send-project-requirements`，但需要核对 CTA 是否真的把用户送到 `/en/contact/` 或 WhatsApp，而不是只回顶部
- 报价页与 Contact 页的首屏 CTA 可访问性（移动端一键 WhatsApp、表单字段数量）已在 11-14 修过表单校验，接下来是按钮位置与文案

**第 4 档（持续）：内容覆盖 + 商业意图页。**
自动发文每天 1 篇在跑，方向对；但技术文只带来排名、不带来询盘。需要补的是"买家决策期"页面：价格区间、交期、认证要求、付款方式、"从中国采购钢结构的风险清单"这类带询盘动机的选题。

## 六、未验证 / 缺口

- 223 条 404 明细仍未全量拿到：本次导出的 `Coverage` 与 `Coverage-Drilldown` 只含重定向那 352 条的 URL 清单，404 分类没有逐条 URL。本地只能用 10-07 归档的 266 条反推（见 3.1 节：其中 263 条已修好，剩 1 条有意保留 404）。GSC 现在报 223 条，说明这个桶里大部分是**我们从未枚举过的旧站 URL**（`old_project_html` 只有 12 个文件，不足以重建旧站全量地址）。要把它们清零，需要在 GSC「未找到 (404)」页点导出、把 URL 清单给我，我再按"有展示/有外链才回收，其余保留 404"逐条判断。**不建议为了数字好看去批量重定向**——这 223 条的实测展示量接近 0，属于迁移噪声。
- 付费流量已确认（2026-11-16 用户答复）：Google Ads 与 Meta **从未投放过**，所以不存在"广告停了导致断流"这一环，官网询盘全部来自自然搜索。
- GA4 侧 11 月表单事件量未核：`form_submit` / `form_error` 的实际计数需要 GA4 后台确认。
