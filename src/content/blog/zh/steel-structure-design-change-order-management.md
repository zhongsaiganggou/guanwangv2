设计变更可以做，但要走书面变更单。变更越早提出，影响越小；一旦材料已采购或构件已加工，变更可能增加费用和工期。变更单应写清改什么、费用、工期变化和双方确认。尽早冻结图纸、在加工前确认要求，可以减少变更。中赛在执行任何变更前都会书面确认。

本文说明什么是变更单、变更时机如何决定费用、变更单应包含哪些内容，以及如何控制变更。

## 什么是设计变更和变更单

设计变更是设计确认后，对约定范围、尺寸、荷载、开洞、围护或节点的任何改动。变更单是记录变更及其对价格、工期影响的书面文件。它是修改合同范围的约定方式，而不是一条非正式消息。

## 变更提出的时机决定影响

| 阶段 | 典型影响 |
|---|---|
| 报价前 | 通常不产生额外费用 |
| 深化设计中 | 影响小，更新图纸即可 |
| 材料采购后 | 材料可能已锁定 |
| 加工制造中 | 已切割或焊接构件可能返工 |
| 编号打包后 | 可能需要重新编号、重新打包 |
| 发运后 | 很有限，现场处理 |
| 现场安装中 | 涉及当地工程师与现场施工 |

具体费用和工期取决于阶段和变更内容，没有固定百分比。

## 变更为什么会增加费用

- **材料已采购**：钢材或围护板可能已锁定
- **构件已加工**：已切割或焊接的部分可能返工或更换
- **重新深化**：图纸和编号可能需要更新
- **工期**：后期变更可能推迟打包和发运
- **重新编号打包**：打包方式和装柜计划可能改变
- **现场施工**：现场变更取决于当地人工和工程

## 变更单应包含哪些内容

1. 改什么、为什么改
2. 涉及的图纸版本
3. 受影响的构件或区域
4. 费用依据
5. 工期影响
6. 双方确认后再执行

## 如何减少变更

- 尽早确认尺寸、荷载、门窗和开洞
- 加工开始前冻结图纸
- 在规格书里写明材料、涂层和围护
- 深化前确定吊车、夹层和设备
- 及时、一次性完成图纸审阅
- 避免材料锁定后再追加内容

## 合理变更费用与需要警惕的费用

- 与已锁定材料、返工、重新深化或重新打包相关的变更费用，通常是合理的
- 与变更无关的收费，或变更单未确认就先施工，应书面提出质疑
- 索要费用依据，并保留图纸、变更单和往来记录

## 工厂变更与现场变更

工厂变更由供应商在构件还在车间时处理；交付后的现场变更涉及当地工程师、审批和当地人工。影响结构安全的变更，实施前应由当地注册工程师审核。

## 责任边界

| 阶段 | 中赛 | 买家/当地 |
|---|---|---|
| 图纸 | 协调深化并提交审阅 | 及时审阅并确认 |
| 变更请求 | 评估费用和工期影响 | 书面提出变更 |
| 变更单 | 执行前写明范围、费用和工期 | 施工前确认 |
| 工厂变更 | 完成约定的返工和重新编号 | 避免非正式口头变更 |
| 现场变更 | 提供技术指导 | 当地工程师、人工和审批 |

## 采购方清单

- [ ] 加工前已确认要求和荷载
- [ ] 图纸已审阅并冻结
- [ ] 变更以书面提出，而非口头
- [ ] 每个变更都有书面变更单
- [ ] 费用和工期影响已先确认
- [ ] 图纸版本为最新
- [ ] 现场变更已由当地工程师审核
- [ ] 变更单和往来记录已归档

## 常见问题

### 下单后还能改设计吗？

可以，但要走书面变更单；后期变更可能增加费用和工期。

### 设计变更一定加钱吗？

报价前或深化早期不一定，但材料采购后、加工开始后可能产生费用。

### 什么是变更单？

记录变更内容、费用、工期影响和双方确认的书面文件。

### 为什么加工后变更更贵？

构件可能已切割、焊接或编号，需要返工或更换。

### 门窗、开洞能后期改吗？

取决于阶段；受影响的围护板和构件可能已经做好。

### 变更要先确认再施工吗？

是的，变更单应在供应商执行前约定。

### 现场变更由谁处理？

现场变更涉及当地工程师、人工和审批，供应商提供技术指导。

### 怎样避免变更单？

冻结图纸、尽早确认设备和开洞，并一次性完成图纸审阅。

## 需要确认或修改设计？

提交项目图纸和要求，中赛会把范围、以及任何变更，书面确认清楚。
