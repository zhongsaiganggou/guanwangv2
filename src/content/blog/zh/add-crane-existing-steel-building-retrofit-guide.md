既有钢结构厂房加装桥式吊车，通常做得到，但不是订一台吊车往刚架上挂。吊车带来竖向轮压、纵向与横向的刹车力，还有一个移动荷载——原来的刚架、柱、柱底板、锚栓和基础从来没有按这些工况设计过。第一个决策是：吊车荷载进既有结构，还是交给一套只承载吊车的独立结构。这个决策对造价、停产时间和风险的影响，远大于吊车选哪个牌子。

## 第一部分：两种承载路径

| 方案 | 含义 | 什么情况下合适 | 主要风险 |
|---|---|---|---|
| 荷载进既有刚架 | 新增吊车梁与既有柱连接 | 刚架有余量且图纸齐全 | 柱或基础隐性超载 |
| 独立吊车结构 | 新柱与吊车梁只承载吊车 | 既有刚架轻、资料缺失或不允许改动 | 用钢更多、需独立基础 |
| 旁边新建吊车跨 | 为吊车新做一跨 | 需要的跨度或净高超过现状 | 工程量与工期最大 |

独立结构往往是造价最低的安全答案，因为它把吊车荷载从一套无法核实的刚架上拿走了。

![既有钢结构厂房旁新建的独立吊车结构，自带柱与吊车梁，与老厂房不连接（示意图）](/images/blog/add-crane-existing-steel-building-retrofit-guide/gantry.jpg)

## 第二部分：回答问题之前需要的资料

- 原结构图纸；图纸缺失时做实测复核。
- 柱截面、柱距、柱底板与锚栓详图。
- 屋面结构、檩条布置与既有支撑体系。
- 吊车参数：起重量、跨度、起升高度、轮压、工作级别、吊车自重。
- 拟设吊车梁标高到屋面结构之间的净空。
- 基础情况：既有独立基础尺寸、地坪做法、可取得的土质报告。
- 场地条件：吊装机械进场、作业高度、可接受的停产时间。

前四项没有，任何答复都是猜。这也是改造报价最常见的卡点。

## 第三部分：真正要核算的部位

| 部位 | 核算内容 | 典型失效形式 |
|---|---|---|
| 屋面梁 | 吊车荷载带来的附加弯矩 | 局部超应力、挠度过大 |
| 柱 | 轴力叠加吊车横向力产生的弯矩 | 失稳、焊缝开裂 |
| 柱底板与锚栓 | 横向力带来的上拔与剪力 | 底板弯曲、锚栓拔出 |
| 独立基础 | 偏心荷载与地基承压 | 沉降、开裂 |
| 支撑体系 | 吊车行走产生的水平力 | 侧移、屋面扭曲 |
| 轨道与吊车梁 | 轮压与轨道对中 | 轨道磨损、啃轨 |
| 节点连接 | 既有焊缝或螺栓的承载力 | 既有焊缝开裂 |

核算必须由能到现场查勘的当地工程师完成，不能靠照片。

## 第四部分：轮压、刹车力与工作级别

吊车荷载不是静载：

- **轮压**集中在轨道和吊车梁上，不会均匀摊到屋面。
- **刹车力**沿轨道方向与横向产生水平力，直接传给柱和支撑。
- **工作级别**决定结构承受这些荷载的频率；频繁使用的吊车和偶尔检修起吊完全是两回事。
- **动载系数**取决于吊车形式与当地规范。
- **疲劳**在循环次数多的项目上会控制节点设计。

这些参数来自吊车厂家与当地设计规范，只给一个起重量是不够的。

## 第五部分：既有厂房里的净空

改造项目往往先败在几何，而不是强度：

- 吊钩最高点到厂房内最高障碍物的距离。
- 吊车梁标高与屋面系杆、檩条标高的关系。
- 吊车端梁与柱边的间隙。
- 轨道、缓冲器和车挡的安装空间。
- 吊车本身与屋面的检修通道。

如果需要的起升高度超过现有屋面能给的空间，答案通常是新建一跨或外部龙门架，而不是把厂房加高。

## 第六部分：加固做法

保留原刚架时，加固通常包括：

- 在吊车梁标高处给柱加补强板或新增构件。
- 新增吊车梁，与柱采用螺栓或焊接连接。
- 在牛腿位置局部加劲，扩散轮压。
- 增加支撑以抵抗刹车力。

既有钢上的现场焊接是质量问题：表面处理、可达性、焊工资质、探伤缺一不可。生产中的厂房更倾向螺栓方案，避免动火与防火风险。

## 第七部分：生产中的厂房做基础

- 既有地坪通常不是按吊车柱荷载设计的。
- 常见做法是在柱列旁或柱列下做独立基础，并与既有基础复核。
- 既有底板偏小时可能需要加大基础或托换。
- 新基础周边的水与排水不能掏空老基础。
- 在运转设备旁开挖与振动，需要专项施工方案。

基础属于当地范围，也是最容易拖长工期的环节。

## 第八部分：电气、轨道与安全

- 吊车供电、滑触线或电缆滑车、隔离点。
- 轨道安装、对中与在吊车梁上的灌浆固定。
- 车挡、缓冲器与限位开关。
- 检修平台、爬梯与防坠落设施。
- 警示标识与作业区划分，与厂方共同确认。

这些用钢量很小，却决定吊车能不能按期验收。

## 第九部分：怎么施工不停产

| 阶段 | 主要工作 | 生产影响 |
|---|---|---|
| 查勘与核算 | 实测、检查、核对图纸 | 无 |
| 设计与审批 | 当地工程师、吊车厂家、报建 | 无 |
| 基础 | 独立基础、锚栓、养护 | 局部，需计划停机 |
| 钢结构安装 | 新柱或吊车梁 | 分区局部影响 |
| 吊车安装 | 轨道、吊装、调试 | 停机窗口 |
| 载荷试验 | 按当地要求试吊 | 停机窗口 |

按跨或按区分期施工，通常比一次长停产的代价更低。

## 第十部分：责任分界

| 事项 | 出口供应方 | 当地 |
|---|---|---|
| 既有刚架可行性核算 | 对提供图纸复核并提意见 | 当地工程师现场查勘确认 |
| 新吊车结构或吊车梁 | 深化、加工、质检 | — |
| 与既有钢的连接 | 新构件详图与加工 | 现场配装与焊接由当地队伍完成 |
| 基础 | 提供接口荷载与柱底板详图 | 当地土建设计与施工 |
| 吊车供货与调试 | 除另行约定外不涉及 | 吊车厂家与当地电气人员 |
| 报建与载荷试验 | 按需提供支撑文件 | 业主与当地主管部门 |

## 第十一部分：订钢前的清单

- [ ] 吊车起重量、跨度、起升高度、轮压已确认。
- [ ] 工作级别与使用频次已知。
- [ ] 已取得原图纸或完成实测复核。
- [ ] 柱、屋面梁、柱底板详图已现场核实。
- [ ] 基础状况已检查。
- [ ] 到屋面与檩条的净空已实测。
- [ ] 已委托当地工程师做承载力核算。
- [ ] 方案已选定：既有刚架、独立结构或新建一跨。
- [ ] 刹车力与支撑影响已复核。
- [ ] 连接方式已定：螺栓或焊接。
- [ ] 轨道、缓冲器、车挡细节已确认。
- [ ] 分期施工方案与停机窗口已与厂方确认。
- [ ] 报建、载荷试验与验收要求已核实。
- [ ] 吊装机械进场条件已确认。

## 第十二部分：常见错误

| 错误 | 后果 |
|---|---|
| 先选吊车再核算刚架 | 吊车到货，厂房接不住 |
| 只算吊车梁 | 柱与基础超载 |
| 忽略刹车力 | 侧移与节点开裂 |
| 用照片代替实测 | 假设错误、现场返工 |
| 在运转厂房大量动火 | 火灾风险与被迫停产 |
| 把既有地坪当基础 | 吊车柱下沉 |
| 没留检修通道 | 吊车无法使用或不安全 |
| 跳过载荷试验 | 主管部门不予验收 |

## 第十三部分：常见问题

**问：任何钢结构厂房都能加吊车吗？**
答：不是。轻钢刚架且基础资料缺失时，可能完全接不住吊车荷载。这种情况下，在厂房内或旁侧做一套独立吊车结构是更稳妥的做法。

**问：加吊车造价最低的做法是什么？**
答：取决于既有刚架。有余量时，与柱连接的吊车梁用钢最省；承载不明或明显不足时，独立结构省去了加固一套谁都核实不了的刚架。

**问：一定要找结构工程师吗？**
答：要。当地工程师必须到现场查勘，并按吊车荷载核算刚架、柱、锚栓与基础。出口加工替代不了这一步。

**问：能不间断生产完成安装吗？**
答：多数可以分期。查勘、设计、厂内加工可以在生产中进行；基础、钢结构安装、调试与载荷试验需要计划停机窗口。顺序决定停产损失。

**问：桥式吊车需要多少净高？**
答：取决于起升高度、吊车自身高度、吊车梁标高与上方屋面结构。既有屋面给不了时，通常新建一跨或做外部龙门架。

**问：既有柱需要加固吗？**
答：如果吊车荷载进入原刚架，往往需要——补强板、新增牛腿或增设支撑。是否需要，来自当地工程师的核算结果，不是经验数字。

**问：改造报价需要什么？**
答：既有厂房的图纸或实测资料、吊车参数、场地位置与预期使用频次。齐了就能把几种方案报价并对比。

## 第十四部分：先看厂房，再看吊车

把既有图纸（或实测资料）、吊车参数与起吊工况发过来，就能在订钢之前把三种方案（与柱连接的吊车梁、独立吊车结构、新建一跨）比清楚。
