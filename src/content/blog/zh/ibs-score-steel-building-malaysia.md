钢构建筑由工厂下料、焊接、涂装的构件组成，运到现场后靠拼装完成，现场用工很少——这正好符合马来西亚对 IBS（工业化建筑体系）的定义。钢结构框架也是 CIDB 认可的体系之一。但 IBS 分数是在整套设计上、按 IBS 内容评分办法算出来的结果，不是钢构厂能出具的证书。向加工厂要“IBS 分数”，等于要一份它没有资格签的文件，通常要到截稿前才发现。

马来西亚的 IBS 框架里，有四样东西都带 IBS 三个字，却分别属于四方。分不清哪一个，项目就会在文件交换上多花两周，甚至卡在审批。

## 第一部分：IBS 在这里到底指什么

CIDB 的定义很清楚：构件在受控条件下生产（工厂里，或现场），运输后在现场以最少的用工完成安装。

由此有三条推论：

- IBS 的计量单位是**构件**，不是整栋楼。
- 生产必须是**受控**的——工厂条件、有文件化的工艺、可重复的产出。
- 现场做的是**装配**，不是加工。

马来西亚认可六类体系：预制混凝土、金属框架（钢结构）、模板、木结构、砌体，以及“其他”类（省人工的构件）。门式钢架厂房属于金属框架这一类。轻钢屋架、钢楼承板、模块化钢隔墙，同样属于这一类。

范围一宽，“我这栋算不算 IBS”就成了伪问题。真问题是：这栋楼里哪些部分是 IBS 构件，以及项目提交的文件有没有如实说明。

## 第二部分：分数属于项目，不属于产品

IBS 内容评分办法是一本手册，用来计算一栋建筑有多大比例是通过 IBS 方式完成的。计算逐个构件展开——结构构件、建筑构件，以及机电部分——按每个构件的做法给出内容分。

| 问题 | 简短回答 |
|---|---|
| 谁算分数 | 项目设计方，通常是建筑师会同工程师与造价师 |
| 算什么 | 一栋具体建筑的设计，逐构件计算 |
| 供应商能算吗 | 不能。供应商只掌握钢构部分，不掌握墙、楼板、机电与装修 |
| 分数是证书吗 | 不是。它是与该设计绑定的申报结果 |
| 设计变了分数变吗 | 会。换一种墙板做法或楼板体系，结果就变 |

这是马来西亚买方询价时最常见的误会。加工厂能告诉你哪些构件是预制的，也能提供这些构件背后的图纸与检测记录；但它给不出项目分数，因为它手里没有其余设计。

## 第三部分：钢构建筑在哪拿分，在哪拿不到

门式钢架工业建筑的可计分内容，集中在少数几个部位。

| 建筑部位 | 常见钢构做法 | IBS 内容 | 买方要确认什么 |
|---|---|---|---|
| 主体框架 | 热轧型钢，栓接或焊接 | 高——工厂加工构件 | 申报图纸里的构件表与节点做法 |
| 屋面结构 | 钢屋架或檩条 | 高 | 屋架是工厂组装还是现场组装 |
| 屋面覆盖 | 檩条上的金属屋面板 | 视体系与归类而定 | 屋面板体系的描述，不能只写颜色 |
| 墙体 | 夹芯板、单层板，或砌体填充 | 差异很大——砌体填充会把墙体拉回传统做法 | 每种墙型的构造剖面 |
| 楼板（多层） | 钢楼承板 + 混凝土 | 视申报时如何归类 | 板型与混凝土做法 |
| 隔墙 | 石膏板或模块化板 | 预制则高 | 板材体系与节点 |
| 楼梯 | 预制钢梯段 | 高 | 梯段与平台的加工图 |

这张表给两条结论。第一，只有钢架撑不起高分——墙、楼板、隔墙的分量一样重。第二，同一栋楼，申报时怎么描述，结果可能不同；这是设计文件问题，不是加工问题。

## 第四部分：四张都叫 IBS 的文件

采购上的混乱基本都从这里开始。

| 文件 | 谁持有 | 实际证明什么 | 不能做什么 |
|---|---|---|---|
| IMPACT 认证（IBS 制造商与产品评估认证） | 制造商，按体系类别 | 该制造商及其产品通过了依据 CIS:24 的评估流程——验证、确认、检测、认证 | 不给项目算分 |
| IBS 身份注册（制造商，或经销商/供应商/代理） | 公司，在六个专业分组之一 | 该公司被列入该分组的认证 IBS 制造商名录 | 不认证某个项目的设计 |
| 项目 IBS 分数 | 项目设计方 | 这栋建筑有多少内容通过 IBS 方式完成 | 不认证任何供应商 |
| 安装方能力（如 B02 钢结构体系培训、轻钢屋架安装工资格） | 个人与承包方 | 安装这些构件的人完成了 CIDB 相应培训与考核 | 不替代产品认证，也不替代项目分数 |

招标文件写“要 IBS 认证”时，就该问一句是哪一行。答案不同，出文件的人也不同：加工厂、当地承包方，还是建筑师。

## 第五部分：加工厂能交什么

加工厂对 IBS 申报的贡献是证据，不是分数。就钢构范围而言，可用的一套材料是：

- **体系说明**——这栋楼是什么：门式钢架、桁架、模块化，跨度与柱距按设计。
- **部位拆分**——哪些部位是工厂预制，哪些是现场成型。
- **构件清单**——构件、屋架、板型、板型材，带尺寸与重量。
- **节点做法**——柱底板、柱拼接、梁柱连接、支撑。
- **检测与检验记录**——材质证明、焊缝检验、涂层检查，以及规范引用的产品检测报告。
- **安装图与标记方案**——构件在现场如何识别，这也是安装方考核会看的内容。

交不了的是：分数、申报表，或“本建筑达到某个分值”的表述。那些属于设计方，最终属于受理申报的主管部门。

## 第六部分：进口钢构怎么算

进口框架并不因此脱离 IBS 框架。构件仍然是工厂生产出来的——关键是文件能不能支撑这个说法。

| 关注点 | 通常怎么处理 |
|---|---|
| 构件在境外生产 | 预制主张靠加工记录支撑；图纸、材质证明、检验报告要能追溯到实发构件 |
| 产品评估 | IMPACT 针对制造商与产品；先核对该制造商是否在对应体系名录里，别假设“有这个类别就行” |
| 安装 | 现场安装仍在当地；安装方资格与承包商注册属于马方 |
| 项目分数 | 由当地按设计计算，使用供应商提供的图纸 |

进口项目真正的风险是文件漂移：报分数用的设计里写的墙板构造或楼板体系，和实际发运的包对不上。这种不一致不会在订货时暴露，会在验收时暴露。

## 第七部分：责任分界

| 事项 | 出口供应方 | 马方 |
|---|---|---|
| 设计配合与深化 | 是——按指定规范做构件设计、出加工图 | 确认设计依据、批准图纸 |
| 加工与质量控制 | 是 | 可派员见证或审厂 |
| IBS 申报用构件清单 | 是——部位拆分、尺寸、重量 | 并入项目申报 |
| IBS 分数计算与申报 | 否 | 建筑师/设计方，会同工程师与造价师 |
| 承包商注册与许可 | 否 | 注册承包商与地方主管部门 |
| 安装与安装方能力 | 仅技术指导 | 当地用工、现场安装管理、按要求配培训合格安装工 |
| 向主管部门报批 | 按需提供支撑文件 | 申报主体 |

界线很干净：供应方证明构件，项目证明分数。

## 第八部分：把 IBS 问题发给供应商之前的清单

- [ ] 已确认招标或主管部门要求的到底是哪一张 IBS 文件。
- [ ] 已确认建筑落在哪个体系类别（金属框架，以及哪个子类）。
- [ ] 与设计方逐部位确认哪些部分将预制。
- [ ] 墙体、楼板、隔墙的构造在算分之前就定下来，而不是之后。
- [ ] 已向供应商索取带尺寸与重量的构件清单。
- [ ] 已索取能追溯到实发构件的材质证明与检验记录。
- [ ] 已核对该制造商是否在对应的认证 IBS 制造商名录中。
- [ ] 已确认现场安装由谁持有承包商注册。
- [ ] 已确认具体构件对应的安装方资格要求。
- [ ] 已确认申报用图纸与加工图一致。

## 第九部分：常见错误

| 错误 | 为什么会发生 | 代价 |
|---|---|---|
| 向加工厂要“IBS 分数” | 招标文件用词随意 | 追错人，白耗数周 |
| 把 IMPACT 认证当项目分数 | 两者都被称作 IBS 认证 | 申报被退回重做 |
| 只算框架不算墙体 | 钢构范围是供应商唯一能控的范围 | 分数达不到目标 |
| 算完分再改墙板 | 后期降本改设计 | 分数要重算 |
| 以为进口就不算预制 | 判定看生产方式，不看产地 | 不必要的改设计 |
| 没有安装记录 | 把安装当普工活 | 交付时不合规 |

## 第十部分：常见问题

**问：钢构建筑自动算 IBS 吗？**
答：不算自动。钢结构是认可的体系之一，工厂预制构件通常符合 IBS 构件条件，但项目归类取决于每个部位怎么做、怎么记录。同样的钢架，砌体填充墙和预制板墙的分数差很远。

**问：IBS 分数就是 IBS 认证吗？**
答：不是。认证（IMPACT）是依据 CIS:24 对制造商与产品的评估；分数是对某个具体建筑设计按 IBS 方式完成比例的逐项计算。一个由公司持有，一个属于某份设计。

**问：中国钢构厂能提供 IBS 分数吗？**
答：不能。算分需要整套设计——墙、楼板、隔墙、机电，由项目设计方计算。供应商能提供的是部位拆分、构件清单、图纸与检测记录，也就是算分所依赖的输入。

**问：进口框架影响 IBS 分数吗？**
答：框架按生产方式判定，不看产地。真正影响结果的是：进口包与已算分的设计是否一致，以及记录能否追溯。

**问：项目需要多少分？**
答：要求的分值取决于项目类型与申报时生效的政策，由主管部门或业主任务书确定。具体门槛应向项目建筑师或造价师确认，不要自行假定数字。

**问：分数高就一定省钱吗？**
答：不一定。预制把工作从现场移到工厂，可能缩短现场工期，但净效果取决于运输、吊装、连接设计与当地人工单价。分数衡量的是做法，不是价格。

**问：IMPACT 是什么？**
答：IBS 制造商与产品评估认证，依据建筑业标准 CIS:24 执行，覆盖验证、确认、检测与认证。通过认证的制造商按体系分类列入名录，其中包括金属框架。

## 第十一部分：发图纸，不要发标签

如果马来西亚项目需要 IBS 申报，询价时把图纸和部位清单一起发过来。我们会回部位拆分、节点做法、材质与检验记录，以及算分所需的加工图——同时会把哪些申报工作属于当地设计方、承包方与主管部门写清楚。
