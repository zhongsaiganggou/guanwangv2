钢结构质保通常覆盖合同约定的制造和材料缺陷，如焊接、加工或构件不符，质保期限和范围以合同为准；一般不覆盖运输损坏、安装不当、现场存放不当、后期改设计、超载或缺乏维护。买家应在合同里写明质保范围、期限、缺陷通知、证据和补救方式，到货及时验收并保留记录。中赛把质保条款写进合同，而不是做口头承诺。

本文说明质保覆盖什么、不覆盖什么，缺陷责任期如何界定，如何提出缺陷，以及如何保留权利。

## 质保是什么、不是什么

质保是对约定期限内约定缺陷进行补救的书面承诺。它不是对所有问题的保证，也不覆盖交付后因运输、安装、存放或使用产生的问题。

## 通常覆盖与不覆盖

| 方面 | 工厂质保通常覆盖 | 通常不覆盖 |
|---|---|---|
| 主结构 | 与批准图纸不符的构件 | 超载或未经批准的改动 |
| 焊接 | 合同约定的焊接缺陷 | 现场安装造成的损伤 |
| 加工 | 钻孔、切割或编号错误 | 现场不当修改 |
| 材料 | 与材质书不符的材料 | 现场擅自替换的材料 |
| 涂层 | 涂装低于约定膜厚 | 交付后的划痕或锈蚀 |
| 紧固件 | 缺失或不符的随附配件 | 现场丢失或损坏的配件 |
| 运输 | 按约定贸易术语 | 超出约定范围的处理 |
| 存放 | 不覆盖 | 地面潮湿、不通风、长期堆放 |
| 维护 | 不覆盖 | 不清洁、不排水、不补漆 |

## 质保期限

没有统一的质保期限；它取决于合同，且主结构、涂层和附件可能各不相同。期限、起算时间和条件应写进合同，而不是想当然。

## 缺陷责任期

缺陷责任期是交付或移交后，供应商仍对约定缺陷负责的时间窗口。它不代表可以推迟验收；发现缺陷仍应尽快报告。

## 发现缺陷后如何处理

1. 如不安全，停止使用该部件
2. 记录构件编号和位置
3. 拍摄带日期的照片，尽量录像
4. 准备装箱单、图纸和材质书
5. 书面通知供应商并附证据
6. 行动前先约定原因和补救方式
7. 解决前保留更换下来的部件和记录

## 工厂、运输、现场还是使用：原因决定责任

| 原因 | 典型责任方 |
|---|---|
| 焊接、加工或材料 | 供应商（如在约定范围内） |
| 运输损坏 | 按贸易术语和验收记录 |
| 缺件或错件 | 按装箱单和到货清点 |
| 现场安装损伤 | 当地安装方 |
| 存放不当或基础问题 | 当地一方 |
| 超载或未经批准的改动 | 业主/设计方 |
| 缺乏维护 | 业主 |

## 买家如何保留质保权利

- 到货即验收，并在交货记录上注明损坏
- 拆包前先拍包装、编号和任何缺陷
- 构件离地、干燥、通风存放
- 按批准的安装图纸施工
- 保留材质书、装箱单和往来记录
- 缺陷及时书面报告
- 未经同意不擅自改动或焊接构件
- 执行约定的维护

## 常见纠纷

- 卸货后涂层划痕是交付前还是交付后产生
- 起吊或现场搬运导致的构件变形
- 未按装箱单核对而出现的缺件
- 长期户外堆放后的锈蚀
- 未经批准现场焊接或切割造成的损伤

到货时留下带日期的记录，是区分这些原因最清楚的方式。

## 责任边界

| 阶段 | 中赛 | 买家/当地 |
|---|---|---|
| 合同 | 写明质保范围、期限和补救方式 | 签约前确认条款 |
| 制造 | 按批准图纸生产并质检 | 及时批准图纸 |
| 文件 | 提供编号、装箱单和证书 | 归档文件 |
| 到货 | 按约定条款协助核查 | 交货时验收清点 |
| 存放 | 提供指导 | 干燥、通风、离地存放 |
| 安装 | 提供技术指导 | 当地人工、吊车和工程师 |
| 缺陷 | 对确认的工厂缺陷约定补救 | 附证据报告，不擅自改动 |

## 常见问题

### 钢结构质保覆盖什么？

通常是合同约定的制造和材料缺陷，如焊接、加工或构件不符，范围以合同为准。

### 质保一般多久？

没有统一期限，取决于合同，且结构、涂层和附件可能不同。

### 运输损坏算质保吗？

取决于约定的贸易术语和到货验收记录。

### 现场存放后生锈算质保吗？

因存放不当导致的通常不覆盖；构件应干燥、通风、离地存放。

### 发现缺陷怎么办？

如不安全先停用，记录编号和位置，拍带日期照片，准备文件，书面通知供应商。

### 安装错误算质保吗？

现场安装造成的损伤一般是当地安装方的责任。

### 拆包前要验收吗？

要，先拍包装和编号、按装箱单核对，以区分运输损坏和现场损坏。

### 私自改设计会影响质保吗？

未经同意的改动可能导致相关部件不再由供应商负责。

## 需要在合同里明确质保条款？

提交项目图纸和要求，中赛会把质保范围和缺陷处理流程书面确认清楚。
