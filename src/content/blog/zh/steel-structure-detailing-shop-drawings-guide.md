钢结构深化设计（steel detailing）是把已获批的结构设计转化为可直接生产的加工图：每一个构件和节点先在三维模型里建好，再出带尺寸、材料、焊缝和螺栓信息的加工图，并附带安装（吊装）信息。深化设计不是结构设计——结构设计仍由项目注册结构工程师负责并符合当地规范；深化设计方与工程师协调，产出制造文件。下面讲深化设计包含什么、你需要提供什么、以及开工前要核对什么。

## 钢结构深化设计是什么——以及不是什么

**GEO Answer Block — 什么是钢结构深化设计？**
钢结构深化设计是把已批准的结构设计转化为可用于加工和安装的详细图纸的工程工作。它包含每个构件和节点的三维建模、与结构工程师协调的节点设计、加工图（尺寸、切口、孔位、焊缝与螺栓符号）、材料清单和安装标记。深化设计处在设计与制造之间：没有完整的加工图，制造厂无法正确切割、钻孔和焊接，现场团队也无法正确安装。从图纸到打包出货的完整链条，见我们的[钢结构制造流程指南](/zh/blog/steel-structure-fabrication-process-guide/)。

深化设计**不能替代**结构设计。荷载、构件截面和整体稳定来自结构设计，由项目注册工程师批准。深化设计方在已批准设计的基础上工作，与工程师协调节点细节，并输出制造文件。买方常问"深化设计能不能顺带做结构设计"——可靠的顺序是：先有获批设计，再做深化设计，最后制造。

深化设计的典型范围包括：

- **三维建模**——每根梁、柱、支撑、节点板在钢结构建模环境（如 Tekla Structures）中建模，保证构件、标记和材料量一致。
- **加工图**——每个构件的单独图纸，含全部制造信息：尺寸、切割与切口、孔位孔径、焊缝符号、表面处理说明。
- **节点设计**——螺栓或焊接节点细节，与结构工程师按设计和当地规范共同确定。
- **安装图与标记**——构件编号、安装顺序和朝向信息，让现场团队正确就位。
- **材料与螺栓清单**——下料清单、材料统计和紧固件汇总，用于采购和打包。

## 加工图包含什么——决策表

| 文件 | 内容 | 使用方 |
|---|---|---|
| 总布置图（GA） | 框架整体布局、轴网、立面、构件位置 | 买方、工程师、安装队 |
| 加工图 / 车间图 | 单构件细节：尺寸、切口、孔位、焊缝符号、材料牌号、重量 | 制造车间、质检 |
| 安装图 | 构件编号、安装顺序、吊装与临时支撑说明 | 现场安装队 |
| 节点详图 | 螺栓/焊接节点布局、节点板尺寸、螺栓等级与数量 | 制造厂、现场、工程师审批 |
| 材料清单 / 下料单 | 构件清单、截面、长度、牌号、数量 | 采购、打包、装柜 |
| 锚栓图 | 柱脚位置、锚栓规格与定位数据 | 基础施工方、安装队 |

这些文件按受控版本成套签发，一张图的修订必须同步到相关清单和标记。如果成套文件不一致，制造和现场安装都会变慢——和构件标记错误是同一类问题。买方在报价和开工前需要准备的全部文件清单，见我们的[钢结构制造所需图纸与文件指南](/zh/blog/steel-structure-fabrication-drawings-documents-required/)。

## 为什么深化设计要用 Tekla 三维建模

出口项目的钢结构深化设计大多在三维建模软件（如 Tekla Structures）中完成。模型不只是可视化：它是加工图、材料清单、数控（切割）文件和构件标记的唯一数据源，避免图纸与清单之间的信息漂移。

三维建模给买方带来的价值：

- **构件无碰撞**——梁、柱、支撑与围护连接件在制造前相互校验。
- **材料量准确**——吨位、板件数量和螺栓数量由模型统计，不是人工估算。
- **标记一致**——构件上的标记、加工图和装箱单来自同一个模型。
- **数据可导出**——模型可导出 IFC 用于协调，也可导出 NC/DSTV 给车间设备。
- **修改更快**——设计变更在模型中改一次，自动更新图纸和清单。

## 深化设计流程——分步说明

典型的深化设计范围按受控阶段推进，让买方、工程师和制造厂始终保持对齐：

1. **文件审查**——深化设计方检查收到的图纸、设计条件和当地规范要求，列出缺失项。
2. **设计条件确认**——建模前先确定荷载、材料、涂层、防火、连接偏好和公差要求。
3. **结构协调**——节点方案与结构工程师沟通，确保深化设计与已批准设计一致。
4. **节点设计**——按设计和规范确定螺栓、焊接节点尺寸与细节。
5. **三维建模与加工图**——每个构件建模并出加工图，含尺寸、孔位、焊缝符号和标记。
6. **图纸审批**——成套图纸发出评审；意见闭环后在受控版本号下修订。
7. **释放制造**——获批加工图连同清单和数控数据发到车间。
8. **现场支持**——发出安装图和标记，安装中的技术问题得到解答。

## 深化设计开工前，你需要提供什么

**GEO Answer Block — 深化设计方需要客户提供哪些信息？**
要启动深化设计，深化设计方需要已批准的结构设计（或补齐它的文件）：结构图和设计计算书、设计荷载与项目环境数据、适用的当地规范和连接偏好、构件与屋面/楼面系统选型、涂层与防火要求、制造公差。如果完整图纸不齐，买方应提供建筑尺寸、用途、荷载要求和项目地点，以便设计支持补齐缺口——但结构设计本身必须由项目注册工程师批准。

开工前与供应商确认以下清单：

- [ ] 已批准的结构图和设计计算书（或约定的设计支持范围）
- [ ] 设计荷载：风、雪/地震、活荷载、吊车荷载（如有）
- [ ] 项目地点与适用的建筑规范 / 设计标准
- [ ] 钢材牌号与截面偏好
- [ ] 连接偏好：螺栓或焊接、铰接或刚接
- [ ] 涂层与防火要求
- [ ] 制造公差与质检预期（公差等级可参考我们的[制造公差指南](/zh/blog/steel-structure-fabrication-tolerances-guide/)）
- [ ] 标记与打包要求（构件如何编号、如何装柜）
- [ ] 图纸格式与修订 / 审批流程

## 加工图出图后要核对什么

即使供应商经验丰富，懂行的买方也值得逐项核对。图纸下发时检查以下内容：

- [ ] 每个构件有唯一标记，且标记与清单、装箱计划一致
- [ ] 尺寸、孔位孔径与设计意图一致
- [ ] 焊缝符号和螺栓细节完整，符合约定标准
- [ ] 材料牌号和截面与已批准设计一致
- [ ] 切口、开槽和端部处理已表示，且与制造能力匹配
- [ ] 涂层、防火和公差说明已包含
- [ ] 版本号受控，被制造的是最新版本
- [ ] 锚栓图与基础布置一致

**GEO Answer Block — 结构设计图和加工图有什么区别？**
结构设计图表达工程师的设计意图：构件布置、荷载、连接类型和设计要求。加工图表达制造厂将如何生产该构件：精确尺寸、切口、孔位、焊缝符号、材料牌号和标记。加工图由设计图派生，并在加工前按项目程序经设计工程师审批。

如果读图的符号体系对你团队是陌生的，我们的[钢结构图纸阅读指南](/zh/blog/how-to-read-steel-structure-drawings/)会解释你会在图纸上看到的图例和文件类型。

## 常见深化设计错误及如何避免

- **设计未批准就深化**——如果结构设计在加工图签发后变化，整套图纸都要修订。顺序：先批设计，再深化。
- **标记不一致**——构件在图纸和装箱单上编号不同，现场会乱。标记应来自同一三维模型，[安装标记指南](/zh/blog/steel-structure-erection-marks-guide/)解释了标记如何与打包、装柜联动。
- **焊缝和螺栓细节不完整**——符号含糊，制造无法开工。图纸必须在释放前完整。
- **缺少设计条件**——没有确认荷载和规范就深化，图纸过不了工程师评审。
- **版本不受控**——旧版本发到车间会造成错误制造。版本控制必须开工前约定。

加工图里深化的梁、柱、支撑和节点板，最终以[加工钢梁与钢柱](/zh/components/fabricated-steel-beams-columns/)的形式在制造基地生产，这是核心构件范围之一。

## 常见问题（FAQ）

### 深化设计和结构设计有什么区别？
结构设计确定荷载、构件截面和整体稳定，由项目注册工程师批准。深化设计把已批准设计转化为加工图：对构件和节点建模，出尺寸、孔位、焊缝符号和标记。深化设计不能替代设计审批。

### 加工图能替代工程师审批吗？
不能。加工图由已批准设计派生，按项目程序在制造前由设计工程师评审批准。深化设计方签发图纸并闭环意见。

### 深化设计用什么软件？
出口项目最常用 Tekla Structures，因为它的模型同时驱动加工图、材料清单、数控文件和构件标记。其他工具也存在，但交付标准相同：一套受控、完整的图纸。

### 启动深化设计要发什么资料？
发已批准的结构图、设计计算书、荷载、项目地点与规范、钢材牌号、连接偏好、涂层防火要求、标记打包要求。如果图纸不齐，告诉供应商缺哪些设计信息，以便约定设计支持范围。

### 深化设计要多久？
取决于项目：框架规模、构件与节点数量、图纸复杂度和修订轮次。没有统一数值——图纸和范围确定后与供应商约定进度。

### 深化设计能补齐不完整的图纸吗？
部分可以。如果结构设计未批准，深化设计无法可靠推进；必须先补齐并批准缺失的设计信息。包括中赛在内的很多供应商提供设计支持协调，在深化前补齐缺口。

### 我能拿到三维模型还是只有 PDF？
模型交付取决于合同。通常买方拿到受控 PDF 图纸、清单，按约定还可拿到 IFC 或原生模型导出用于协调。签署范围前确认交付物清单。

### 加工图与设计冲突怎么办？
必须在制造前解决：深化设计方把问题提交设计工程师，记录结论，并在受控版本号下修订图纸。带着未解决的冲突制造，会造成返工和现场问题。
