材质证明书（MTC，通常按 EN 10204 出具）是证明钢材牌号、化学成分与力学性能符合订单与标准的文件。3.1 由厂家独立质量部门出具，3.2 增加第三方见证检验。验收关键是把证书上的炉号追溯到实物、核对牌号与订单图纸一致、按标准核对化学成分与力学性能——这些值取决于所用钢种与标准，不是固定全球值。中赛做钢结构20年、专注出口15年，为所供钢结构协调 MTC 材质文件。

本文说明 MTC 是什么、EN 10204 3.1 与 3.2 的区别、要读哪些字段，以及如何把证书与到货钢材核对。

## 什么是材质证明书

材质证明书是钢厂出具的材料文件，报告同一炉（同一生产批次）钢材的实际检测结果。它把交付材料与炉号、适用标准、牌号、尺寸以及检测的化学成分、力学性能关联起来。加工厂通常收集所采购钢材的材质证书，并归入项目材质文件包转交客户。

MTC 在不同标准下有不同叫法：材质单（MTR）、钢厂证书、检验证书。欧洲项目常用 EN 10204 规定的检验文件类型。

## EN 10204 3.1 与 3.2 的区别

| 因素 | 3.1 证书 | 3.2 证书 |
|---|---|---|
| 出具方 | 厂家独立质量部门 | 厂家 + 厂家或独立第三方授权检验员 |
| 独立性 | 独立于生产部门 | 经独立见证/核验 |
| 检验 | 对所交付批次按订单执行 | 相同，并由第三方见证或核验 |
| 常见用途 | 多数钢结构订单 | 要求独立检验机构背书的项目 |
| 成本/时间 | 标准 | 增加检验成本与时间 |

需要哪一种取决于项目规范、当地主管部门与合同，不能在交货后再补选。

## MTC 要读哪些字段

- **标准**：如 EN、ASTM、GB/JIS，数值必须按该标准评定
- **钢材牌号**：必须与订单及加工图一致
- **炉号**：批次追溯关键，会出现在实物钢材上
- **尺寸/产品形式**：钢板、型钢、管材及规格
- **化学成分**：碳及合金元素，对照标准限值
- **力学性能**：屈服强度、抗拉强度、延伸率，必要时含冲击试验
- **交货/热处理状态**：如正火、热机械轧制、按交货状态
- **签字与日期**：授权签认与签发日期

化学成分与力学性能的具体值不是固定全球值：取决于钢种与所用标准，MTC 报告的是该炉次的实测值。

## 如何把 MTC 与实物核验

1. 把证书上的炉号与实物构件上的标记/钢印对应
2. 确认钢材牌号与采购订单、加工图一致
3. 核对报告的化学成分落在该牌号标准限值内
4. 按标准核对屈服、抗拉与延伸率
5. 确认证书类型（3.1 或 3.2）与合同一致
6. 有争议时安排独立复验（如现场 PMI 化学成分分析）

## 化学成分与力学性能核对

化学成分逐元素对照该牌号标准表——碳及主要合金元素必须在规定区间内。力学性能读实测值：至少有屈服强度、抗拉强度、延伸率，规范要求时还有冲击功。若项目有独立检验员，可用手持 XRF/PMI 光谱仪在现场核验化学成分；这是抽检核对，不能替代材质证书。

| 环节 | 中赛（加工/供应商） | 采购方/当地 |

| 材料采购 | 采购带 MTC 的钢材并协调文件 | 规定所需牌号、标准与证书类型 |

| 第三方检验 | 配合指定检验员进场 | 如要求 3.2，委托并承担独立检验 |
| 主管报验 | — | 当地注册工程师与主管部门批复 |

## MTC 核验清单

- [ ] 采购订单中已写明所需证书类型（3.1 或 3.2）
- [ ] 证书上的标准与牌号与订单、图纸一致
- [ ] 炉号可追溯到实物构件标记
- [ ] 化学成分在标准限值内
- [ ] 屈服、抗拉、延伸合格，必要时冲击值合格
- [ ] 尺寸与产品形式相符
- [ ] 证书已收入项目交接文件包
- [ ] 有争议材料在使用前隔离并复验

## 常见问题

### 什么是材质证明书？

它是钢厂出具的文件，报告某一炉钢材的实测化学成分与力学性能，以及用于追溯的牌号、标准、尺寸与炉号。

### EN 10204 3.1 和 3.2 有什么区别？

3.1 由厂家独立质量部门出具；3.2 增加独立授权代表的检验或核验。项目要求独立保证时用 3.2。

### 钢结构用 3.1 证书够吗？

多数钢结构订单 3.1 是标准要求。用 3.1 还是 3.2 取决于项目规范、当地主管部门与合同，必须在下单前确定。

### 炉号怎么核对？

炉号会标记或钢印在钢材上，把它与证书对应，再确认该炉次的牌号与检测值。

### 证书与实物不符怎么办？

隔离材料、不得安装，要求供应商核对记录或提供独立复验；不合格材料应在吊装前解决。

### 化学成分能现场检测吗？

手持 XRF/PMI 光谱仪可现场核验化学成分作为抽检，但它是补充，不能替代材质证书与力学性能试验。

### 不同标准的证书一样吗？

欧洲项目常用 EN 10204 3.1/3.2；ASTM、GB 体系有各自材质单格式。牌号与数值必须按文件所列标准评定。

### 中赛提供材质证书吗？

中赛为所供钢结构协调 MTC 文件并纳入项目材质包；当地按项目规范复核并负责主管报验。
