家禽舍的钢结构本身是简单的门式刚架，难点不在钢，而在钢要待的环境：净高被通风机和吊顶定死，柱距要对齐料线与饮水线，围护必须气密、干燥，舍内又是氨气加高湿，任何藏水的节点都会提前失效。这四件事定对了，框架就是常规活；定错了，不是十年后出问题，是第一个养殖周期就出问题。

这篇写给要建鸡舍的业主和承包商（肉鸡、蛋鸡、种鸡都适用），也写给拿着别人做的养殖系统方案来询钢构包的加工方。

## 第一部分：家禽舍不是缩小的仓库

| 决策点 | 仓库 | 家禽舍 |
|---|---|---|
| 净高 | 由货架与叉车净空决定 | 由吊顶、风机静压箱与设备检修决定 |
| 柱距 | 由货架模数与门洞决定 | 由料线、饮水线、隔断与清粪通道决定 |
| 围护 | 防雨、通风即可 | 防雨、气密、保温、可冲洗 |
| 舍内环境 | 常温，偶有潮湿 | 氨气、垫料粉尘、高湿、周期性冲洗 |
| 腐蚀来源 | 主要是外部气候 | 内部氨气 + 冷凝水 |
| 荷载 | 门、月台、地坪 | 饲料、赶鸡、清粪、检修通道 |
| 失效代价 | 少存几天货 | 整批鸡、疾病风险、动物福利合规 |

结构上的结论：框架是标准的，围护、开洞和节点不是。仓库里可以留个台沿、藏个空腔、留个没密封的穿管孔；鸡舍里这些都是隐患。

## 第二部分：订钢之前必须先定的四件事

1. **养殖方式。** 地面平养肉鸡、笼养或大笼蛋鸡、种鸡舍——吊顶高度、通道形式、设备布置完全不同。
2. **通风策略。** 纵向隧道通风、横向通风，或两者结合，是否配湿帘降温。这决定风机墙、进风口位置和静压箱深度。
3. **气候与场地。** 设计温度、湿度、风、雪决定荷载与保温；氨气与湿度决定涂层。
4. **栋数与场区布局。** 单栋还是多栋，服务道路、料塔、生物安全间距、以后扩建。

这些都不是钢结构决定，但每一个都会改变钢结构。在这四件事定下来之前报价，报的是一个形状，不是一栋房子。

## 第三部分：净高与檐高

家禽舍的净高很少是给鸡留的，是给鸡上面的东西留的。

| 决定因素 | 对框架的影响 | 买方要确认什么 |
|---|---|---|
| 吊顶或保温屋面 | 决定框架是否要另承一套吊顶系统 | 吊顶形式、每平米重量、固定方式 |
| 风机静压箱与隧道风机墙 | 端墙要加深，可能需要独立框架 | 风机直径、数量、墙体布置 |
| 湿帘降温 | 增加一段带水、更高湿的墙体区域 | 湿帘高度与位置 |
| 料线、饮水线 | 决定设备区高度与料斗净空 | 管线布置与料斗形式 |
| 垫料与清粪 | 决定门高与端部内部净空 | 清粪机械形式 |
| 当地法规与福利要求 | 可能规定最低净高或最大饲养密度 | 当地主管部门要求 |

檐高取的是这些里最高的那个，不是标准门架模数。如果静压箱深、吊顶又要保温，同样跨度下端部断面可能比仓库更深。

## 第四部分：柱距与柱网

家禽舍的柱距首先是设备决定，其次才是结构决定。

- **料线与饮水线**沿舍长布置，柱位不能打断检修通道和管线支架。
- **隔断与端墙**应落在榀架线上，不能落在两榀之间。
- **门洞**（进料、赶鸡、清粪、检修）每一个都需要一条榀架线和对应节点。
- **屋面排水**间距跟着柱距走，天沟要按当地降雨强度算。
- **以后扩建**沿长度加跨时，柱距能重复才便宜。

只按"每米最少榀数"选出来的柱网，往往会变成每扇门、每道隔断、每个管线支架都要加二次架。钢构包便宜了，房子贵了。

## 第五部分：屋面、吊顶与冷凝

家禽舍有两层围护：屋面和吊顶。两层都要管。

| 构件 | 作用 | 常见错误 |
|---|---|---|
| 屋面板 | 挡雨、排水 | 选板型时不考虑检修上人荷载与风吸 |
| 保温层 | 控温、防冷凝 | 保温在檩条处被压薄，形成冷桥 |
| 隔汽层 | 不让水汽进保温 | 不做隔汽层，或每个自攻钉处都戳穿 |
| 吊顶 | 把养殖区与屋顶空腔分开 | 吊顶直接固定在檩条上，没有设备层 |
| 气密处理 | 让通风可控 | 风机、进风口、料线、电缆穿墙处不密封 |

冷凝是最安静的失效方式。湿热空气上升到冷的屋顶空腔，在板背面结露，滴到垫料、渗进保温，还开始在没人看得见的檩条上生锈，等打开屋面才发现。隔汽层加连续保温在施工时花不了多少，事后几乎补不上。

## 第六部分：通风口就是结构开洞

每台风机、每个进风口、每块湿帘都是围护上的一个洞，每个洞都要有框。

- **隧道风机墙：** 风机重、有振动，墙要独立框架，不能只靠压型板。
- **进风口：** 按系统设计定位，框要能在冲洗时关严。
- **湿帘：** 有水、湿度更高，周边框架与涂层要同时耐受。
- **屋脊与檐口：** 既不能让风雨倒灌进空腔，又不能破坏通风路径。
- **检修门与检修口：** 每一个都要榀架线，并且是可关闭、可冲洗的节点。

通风设计属于养殖系统供应商或当地家禽工程师。加工方要做的是：让这些开洞在结构上成立、密封、防腐，并在开洞与框架冲突时提前提出。

## 第七部分：防腐是寿命决定，不是油漆选择

鸡舍内部同时有氨气、湿气、垫料粉尘和周期性冲洗，比大多数室外工业环境更苛刻。

| 措施 | 在鸡舍里的意义 |
|---|---|
| 主结构热浸镀锌 | 氨气与冷凝水最先攻击裸钢的连接处和藏水部位 |
| 匹配当地环境的涂层体系 | 内外暴露条件不同，一套体系未必两边都够 |
| 避免藏水空腔与未封闭的方管 | 冷凝水积在里面排不掉也干不了 |
| 不锈钢或带涂层紧固件 | 异种金属接触与涂层破损，每个螺钉都是腐蚀起点 |
| 可冲洗的光滑表面 | 粉尘积在台沿上，粗糙面根本洗不干净 |
| 每个低点都能排水 | 排不出去的水就是下一个腐蚀电池的起点 |

具体怎么配，取决于当地气候、冲洗制度、期望使用年限和市场能买到的涂层，不存在一个全球通用标准。可以通用地说一句：藏水的节点在鸡舍里会比仓库更早失效，而且维修更贵，因为要先把鸡清出去。

## 第八部分：地坪、基础与传力路径

鸡舍一般坐在混凝土地坪上，钢架锚固在地坪里。由此有三件事：

1. **地坪是生产空间的地面，不只是基础。** 平整度、排水坡度、分缝都影响垫料状态与清洗。
2. **框架荷载集中在柱脚。** 地坪要按柱脚荷载设计，也要考虑后续的设备与饲料荷载。
3. **围护与地坪之间不能有缝。** 底部的缝就是漏风、渗水、藏垫料和进老鼠的地方。

基础设计、地坪详图与土建属于当地工程师。加工方提供柱底板、锚栓和接口节点，并且要在生产前确认地坪标高与锚栓放线。

## 第九部分：生物安全、冲洗与可清洁性

两批鸡之间要冲洗消毒。洗不干净的节点就是疾病风险。

| 节点 | 要求 |
|---|---|
| 柱与框架表面 | 光滑、有涂层、不留积料的台沿 |
| 吊顶与保温接缝 | 密封、可冲洗、不吸湿 |
| 门与检修口 | 可关闭、密封、框可冲洗 |
| 电缆与管道穿墙 | 密封且可检查 |
| 地坪分缝与阴角 | 做圆弧或密封，可清洁 |
| 排水 | 按冲洗水量设计，按要求设存水弯 |

这是鸡舍钢构包与仓库包差别最大的地方：框架一样，但每个节点都要用"能不能洗干净"来判定。

## 第十部分：多栋场区与布局

一栋是一个建筑项目，一群是一个场地规划。

- **栋间距离**要同时满足生物安全、检修通道与防火间距。
- **料塔位置**与送料车通道，包括转弯与卸料。
- **服务道路**要在雨天也能用。
- **水电配套**：风机用电、降温与冲洗用水、备用发电。
- **以后扩建**：留出沿长度加跨和增加栋数的可能，而不必搬移基础设施。

钢构范围通常止于建筑围护。场地规划属于业主与当地工程师，但最好在第一栋开工前定完，因为在运营中的鸡舍周围补配套，又贵又影响生产。

## 第十一部分：钢构包到底包什么

| 项目 | 一般包含在钢构包 | 一般不包含 |
|---|---|---|
| 主框架、次结构、支撑 | 是 | — |
| 屋面墙面压型板、保温、隔汽层 | 是（如果已规定） | — |
| 柱底板、锚栓、预埋节点 | 是 | — |
| 按通风布置预留的风机、进风口、门洞框 | 是 | 风机与进风设备本身 |
| 天沟与落水管 | 是（如果已规定） | 场地排水 |
| 吊顶系统 | 只在明确约定时 | 养殖专用吊顶与设备 |
| 通风设计、风机选型、控制系统 | 否 | 养殖系统供应商 / 当地工程师 |
| 基础与地坪 | 只做接口 | 当地土建 |
| 安装、调试、生物安全验收 | 技术指导 | 当地队伍与场方 |

"钢构包"与"能养鸡的房子"之间的差距，是大多数争议的来源。它应该写进询价文件，而不是到现场才发现。

## 第十二部分：责任边界

| 环节 | 中赛负责 | 买方 / 当地工程师负责 |
|---|---|---|
| 设计 | 按已发图纸做详图与加工配合；发现开洞与框架冲突时提出 | 结构设计、当地规范、通风与养殖系统设计 |
| 基础 | 柱底板与锚栓配合、放线支持 | 地坪与基础设计、土建施工 |
| 加工 | 加工、涂装、标记、打包、装柜 | 图纸批准与变更控制 |
| 出口 | 出口协调与单证支持 | 进口清关、税费、当地运输 |
| 现场 | 安装技术指导 | 安装、临时工程、许可、调试、生物安全验收 |

## 第十三部分：订钢前的检查清单

- [ ] 养殖方式已确认：肉鸡 / 蛋鸡 / 种鸡；平养 / 笼养。
- [ ] 通风策略已确认，含风机墙、进风口与降温方式。
- [ ] 净高与檐高由吊顶、静压箱与设备反推得出。
- [ ] 柱距对齐料线、饮水线、隔断与门洞。
- [ ] 屋面排水按当地降雨强度设计。
- [ ] 保温、隔汽层与气密性作为一个系统来规定。
- [ ] 每个开洞都有榀架线和可关闭、可冲洗的节点。
- [ ] 防腐按氨气、湿度与冲洗制度来定。
- [ ] 地坪、锚栓与放线在生产前确认。
- [ ] 场区布局与以后扩建在第一栋之前定完。

## 第十四部分：常见问题

**问：能不能直接用标准仓库的钢架做鸡舍？**
答：结构上通常可以，但围护不一样。净高、气密性、保温、通风开洞和防腐都要按鸡舍重新规定，不能从仓库照搬。

**问：鸡舍净高要多少？**
答：取决于养殖方式、吊顶、风机静压箱、湿帘和当地规定，没有全球通用数字，应由系统方案反推。

**问：为什么鸡舍的防腐要求更高？**
答：舍内同时有氨气、高湿和冲洗。藏水的节点比仓库更早腐蚀，而维修要先清群，代价很高。

**问：通风系统由谁设计？**
答：养殖系统供应商或当地家禽工程师。钢构厂负责把开洞做进结构、密封好，并在冲突时提出。

**问：一定要做吊顶吗，能不能屋面板直接当顶？**
答：两种做法都有。独立吊顶加设备层，对通风与冷凝控制更好，但增加结构与造价。这属于系统设计决定。

**问：以后能扩建吗？**
答：通常可以沿长度加跨，前提是柱距能重复、端榀按永久榀做。运营期内扩建是生物安全问题，最好安排在两批鸡之间。

**问：订钢之前要确认什么？**
答：养殖方式、通风布置、净高、柱距、地坪与锚栓放线，以及防腐规格。缺这些，框架就是猜的。
