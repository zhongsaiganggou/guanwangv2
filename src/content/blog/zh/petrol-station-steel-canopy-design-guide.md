加油站钢雨棚不是罩在加油机上的屋顶。它要避开油罐车转弯包络、替加油岛挡雨遮阳、承载灯具与招牌、把水排离加油岛、在无墙屋面上抵抗风吸力，还要躲开燃油危险区域规定。这些约束在造型前就决定了跨度与钢结构。

## 第一部分：雨棚到底要承担什么

- 替加油岛和站在那里的顾客挡雨。
- 承载灯具、招牌，有时还有摄像头与价格牌。
- 电管与排水走在结构内，而非吊在顶棚外。
- 承受没有任何墙体压住的屋面风吸力。
- 让柱避开车辆行驶路径，并保护柱子不被撞。
- 满足加油机、通气管口、卸油口周边的危险区域要求。
- 从马路上看，能识别品牌形象。

这些每一条都是设计输入，不是装修选项。

## 第二部分：四种常见布置

| 布置 | 说明 | 适合 | 限制 |
|---|---|---|---|
| 单岛单棚 | 一顶棚罩一排加油机 | 小型站、低流量 | 招牌面积有限 |
| 多岛连棚 | 一顶连续棚跨多个加油岛 | 城市高流量站 | 跨度大、排水路径长 |
| 双侧分棚 | 商店两侧各一顶 | 商店居中的场地 | 两套排水系统 |
| 雨棚挂接商店 | 从建筑悬挑 | 场地紧张 | 荷载进商店结构 |

布置决定跨度、柱位与水的去向，须在深化前定下。

## 第三部分：什么在决定几何尺寸

| 输入 | 为什么重要 |
|---|---|
| 加油机位置与加油岛尺寸 | 决定无柱区与净空 |
| 油罐车尺寸与转弯路径 | 防止柱子落在扫掠范围内 |
| 车辆上方所需净高 | 取决于当地规范与车型 |
| 招牌尺寸与位置 | 增加受风面积与自重 |
| 灯具布置 | 决定檩条间距与走线路径 |
| 排水出口位置 | 决定屋面找坡与天沟深度 |
| 到商店与油罐通气管的防火间距 | 可能移动柱位或缩短屋面 |
| 当地风荷载与地震作用 | 决定支撑与基础 |

净高、跨度上限与防火间距由当地规范与燃油系统设计确定，不能照抄他国项目。

## 第四部分：危险区域与电气

油气改变了雨棚内部允许的做法：
- 加油机、通气管口、卸油口周边的区域由燃油系统设计方与当地规范划定（例如按当地采用的 IEC 60079 或 NFPA 497）。
- 区域内灯具、线管、接线盒、摄像头须匹配相应等级。
- 电缆走在结构内，不明敷在顶棚上任人碰擦。
- 隔离点不爬屋面即可操作。
- 招牌与价格牌需独立供电。

加工方需要的是危险区域划分图，不是一句口头描述。

## 第五部分：排水与泄漏

- 水须从加油岛排走，不能滴到顾客和加油机。
- 天沟与落水管走在结构内或背面，不横穿顶棚。
- 落水口不能排到加油区或油罐车通道。
- 屋面坡度与天沟容量取决于当地降雨强度。
- 场地雨水与雨棚排水是两套系统。
- 卸油口的防溢围堰属于燃油系统，但不能与雨棚构件打架。

雨棚滴水到加油岛即设计失败，钢结构再对也一样。

## 第六部分：防撞

- 布置允许时，柱应站在车辆扫掠路径之外。
- 柱必须靠近场坪时，防撞柱或防护路缘属设计内容。
- 防护要看得见、可维护。
- 柱底板与锚栓构造应做到换防撞柱不动柱本身。
- 限高杆和招牌支撑与柱一样要做撞击复核。

## 第七部分：防火间距与接口

- 雨棚与商店、压缩机区、油罐通气管之间的间距按当地防火规范。
- 挂接商店时，火灾暴露与结构荷载会传进商店刚架；独立雨棚不会。
- 地下油罐通气管位置常在后期逼着柱位改动。
- 紧急切断与火灾报警装置必须在雨棚下可见、可操作。

后期变更大多出在这些接口上；钢材一旦下料，变更代价很高。

## 第八部分：结构形式

| 形式 | 受力特点 | 说明 |
|---|---|---|
| 门式刚架雨棚 | 每榀两柱，屋面跨中间 | 简单可控，适合宽场地 |
| 悬挑雨棚 | 仅一侧设柱 | 场坪通透，柱底弯矩大 |
| 带拉结或支撑的雨棚 | 柱间设支撑 | 刚度好，但支撑要避开车辆 |
| 挂接建筑 | 屋面由商店结构支承 | 省柱，但荷载进建筑 |

雨棚常由风吸力控制而非自重，基础须按上拔设计，不能只算下压。

## 第九部分：防腐与涂装

- 海边与城市站点有盐分与污染，环境等级决定涂层体系。
- 热浸镀锌适合难重涂构件，涂装适合外露可视面。
- 吊顶是最容易被看到、也最难维护的面。
- 焊缝与损伤部位的现场修补属涂层体系一部分，不是额外项。
- 燃油或清洁剂侵蚀部位可能需要不锈钢或铝件。

涂层厚度与体系取决于腐蚀等级与当地环境，不存在一个全球通用的规格。

## 第十部分：围护与吊顶

- 单层压型板吊顶经济；保温吊顶更整洁、凝结水更少。
- 板缝方向应顺着屋面坡度，避免积水。
- 开放顶棚露出檩条管线，封闭顶棚要留检修条件。
- 颜色与质感既影响品牌，也影响污渍与凝结水的可见程度。

## 第十一部分：预制与运输

- 厂内焊接框架或模块可减少现场作业、提升焊缝质量。
- 模块尺寸受集装箱或框架箱与现场吊车能力限制。
- 拼接点落在现场能对位、能拧螺栓处，不在悬挑中段。
- 编号须与吊装顺序一致，否则雨棚只能躺地上等。
- 雨棚吨位不大但体积大，包装与海运是实打实成本。

## 第十二部分：责任分界

| 事项 | 出口供应方 | 当地 |
|---|---|---|
| 雨棚结构设计与深化 | 是，基于提供的布置与荷载 | 当地工程师复核签章 |
| 加工、涂装、编号、包装 | 是 | — |
| 危险区域划分 | 提出所需输入 | 燃油系统设计方与当地主管部门 |
| 基础与场坪 | 提供柱底荷载与详图 | 当地土建单位 |
| 电气安装与验收 | 预留线管与灯具条件 | 持证当地电工 |
| 安装 | 提供技术指导 | 当地队伍与吊车 |
| 报建与调试 | 提供支撑文件 | 业主与当地主管部门 |

## 第十三部分：设计冻结前的清单

- [ ] 加油机布置与加油岛尺寸已确认。
- [ ] 油罐车尺寸与转弯路径已与柱位核对。
- [ ] 所需净高已按当地规范确认。
- [ ] 已取得危险区域划分图。
- [ ] 灯具与招牌布置已确认。
- [ ] 屋面找坡与排水出口已确定。
- [ ] 落水管避开了加油区与车行路径。
- [ ] 防撞设施位置已确认。
- [ ] 到商店与通气管的防火间距已核对。
- [ ] 场地风荷载与地震作用已确认。
- [ ] 基础上拔设计已协同。
- [ ] 腐蚀等级与涂层体系已选定。
- [ ] 模块尺寸已与海运及吊装能力核对。
- [ ] 吊装顺序与编号方案已确认。

## 第十四部分：常见错误

| 错误 | 后果 |
|---|---|
| 先定屋面造型再看加油岛 | 柱子落在行车路径上 |
| 忽略油罐车扫掠范围 | 第一次卸油就撞棚 |
| 照抄别国净高标准 | 不合规或无法使用 |
| 没有危险区域图 | 灯具与线管验收被拒 |
| 落水口设在加油岛上方 | 水滴到顾客与加油机 |
| 柱靠场坪却不设防撞 | 撞柱后停业维修 |
| 基础不算上拔 | 大风时屋面位移 |
| 拼接点放在悬挑中段 | 现场无法对位 |
| 加工完再加招牌 | 荷载与受风面积失控 |

## 第十五部分：常见问题

**问：加油站雨棚的高度由什么决定？**
答：由最高车辆净空、油罐车包络、加油机高度与当地规范共同决定，应与当地主管部门及燃油系统设计方确认。

**问：一顶雨棚能罩多个加油岛吗？**
答：可以，高流量站点常见。代价是跨度更长、排水路径更多、风吸力更大，构件更深、基础更重。

**问：雨棚必须用防爆灯具吗？**
答：取决于加油机、通气管口、卸油口周边划定的危险区域，由燃油系统设计方与当地规范确定，灯具与线管须匹配。

**问：雨棚的水应该排到哪里？**
答：排离加油岛、加油区与油罐车通道，经结构内或背面的天沟与落水管排出，容量取决于当地降雨强度。

**问：雨棚柱需要防撞柱吗？**
答：柱靠近场坪或车行路径时需要。防撞比换柱、停业维修便宜得多。

**问：独立雨棚和挂接商店的雨棚哪个好？**
答：独立雨棚不把荷载传给商店结构，防火分隔也更简单；挂接式在紧张场地能省柱，但会把荷载与火灾暴露传进建筑。

**问：雨棚怎么运输？**
答：按集装箱、框架箱与现场吊车能力拆成厂内焊接的框架或模块，拼接点设在场内能对位、能拧螺栓处，编号跟随吊装顺序。

## 第十六部分：先定布置，再定屋面

把场地布置、加油机排列、油罐车路径、净高与危险区域图发过来，就能在下料前把几何、排水与防护定下来。
