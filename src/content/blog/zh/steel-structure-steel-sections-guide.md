结构钢材按标准化系列生产：IPE、HEA/HEB（欧标）、UB/UC（英标）、H 型钢（日标/国标），以及角钢、槽钢与方管等。每个系列有固定的尺寸与性能表，构件选用多大截面取决于荷载、跨度与设计。询价时写对系列与规格，可避免报价错误与交货延误。中赛按批准图纸加工；截面由设计团队确认，我们提供工程协调。

本文讲清常用截面系列、怎么看截面表，以及询价时如何准确描述钢材。

![钢材堆场中的 H 型钢、槽钢与角钢料堆（概念示意图）](/images/blog/steel-structure-steel-sections-guide/cover.jpg)

## 一、为什么截面名称重要

钢材按标准化系列生产，不是任意形状。你说"H 型钢 300"，不同地区指的是不同截面。写对系列名称与规格：

- **避免报价错误**——供应商按你描述的内容准确报价。
- **避免交货延误**——截面错了要重订、等待。
- **保证设计有效**——截面性能决定结构设计。
- **加快加工**——精确截面可直接按表切割与详图。

## 二、常用截面系列对比

| 系列 | 地区 / 标准 | 典型用途 | 要点 |
|---|---|---|---|
| **IPE** | 欧标（EN 10034） | 梁、屋架、檩条 | 平行翼缘工字钢；深度系列广 |
| **HEA / HEB / HEM** | 欧标（EN 10034） | 柱、重载梁 | H 形；HEA 轻、HEB 中、HEM 翼缘最厚 |
| **UB / UC** | 英标（BS 4） | 梁（UB）、柱（UC） | UB 翼缘带斜度；UC 翼缘更厚 |
| **H 型钢（H / HW / HM / HN）** | 日标 / 国标（JIS、GB） | 柱与梁 | 宽翼缘 H；按宽度与重量分系列 |
| **角钢（L，等边与不等边）** | 各区域 | 支撑、系杆、轻型框架 | 等边或不等边；按边×边×厚 |
| **槽钢（U / C）** | 各区域 | 檩条、墙梁、收边 | 开口截面；按高×翼缘×厚 |
| **方管 / 矩形管 / 圆管（SHS/RHS/CHS）** | 各区域 | 柱、桁架、支撑 | 方形、矩形或圆形闭口截面 |

系列由设计团队选择；规格由荷载、跨度与当地规范决定。

## 三、怎么看截面表

截面表为每个名义规格列出：

- **高度与翼缘宽度**——外形尺寸。
- **腹板与翼缘厚度**——板厚。
- **每米重量**——用于重量与运费估算。
- **截面性能**——面积、惯性矩、截面模量（用于设计）。

描述钢材时，给出准确的系列名与规格，例如："IPE 240"、"HEB 300"、"UB 457×191×74"、"L 75×75×6"、"SHS 150×150×6.3"。

## 四、什么构件用什么截面？

| 构件 | 常用系列 | 原因 |
|---|---|---|
| 柱 | HEA/HEB、UC、H 型钢 | 轴压大，翼缘承压 |
| 屋架梁 | IPE、UB | 沿梁的抗弯强度 |
| 檩条 / 墙梁 | 槽钢、Z/C 或 IPE | 轻，跨越主框架之间 |
| 支撑 | 角钢、圆管、扁钢 | 拉压构件 |
| 桁架弦杆 | IPE、方管 | 弯压组合 |
| 夹层梁 | UB、IPE、HEB | 楼面荷载与跨度 |

最终规格始终取决于荷载、跨度与批准设计——没有适用于任何跨度的通用规格。

## 五、询价时如何描述截面

1. 给出设计基础：荷载、跨度、雪/风/地震区（如相关）。
2. 按批准图纸列出主要构件的系列与规格。
3. 写明钢材牌号（如 S235、S275、S355 或等效）。
4. 需要时写明标准（EN、BS、JIS、GB）及等效标准。
5. 确认表面处理与涂装要求。
6. 确认各规格的数量与长度。
7. 请供应商确认各规格的可供货与交期。

## 常见问题

### IPE 和 HEB 有什么区别？

IPE 是平行翼缘工字钢，翼缘较薄，主要用于梁与屋架。HEB 是翼缘更宽更厚的 H 形钢，主要用于柱与重载梁。选择取决于荷载与设计。

### UB 和 UC 有什么区别？

UB（通用梁）腹板更深、翼缘带斜度，用于受弯构件。UC（通用柱）翼缘更厚、截面近方形，用于轴压为主的柱。

### HEA、HEB、HEM 是什么意思？

欧标 H 系列：HEA 翼缘最轻，HEB 中等，HEM 同深度下翼缘最重。翼缘更重意味着柱的轴压承载更高。

### 什么是 H 型钢（H / HW / HM / HN）？

日标/国标 H 系列，按宽度分类：HW（宽）、HM（中）、HN（窄）。亚洲来源项目常用作柱与梁。

### 询价时怎么描述一个截面？

准确给出系列名、规格与牌号——例如"IPE 240、S355"——加上设计基础（荷载、跨度）与表面处理。这样供应商才能正确报价与加工。

### 檩条用什么截面？

檩条通常是槽钢、Z 或 C 型钢，或轻型 IPE，跨越屋面主框架之间。规格取决于屋面跨度、间距与荷载。

### 截面规格有标准吗？

有——每个系列遵循公开标准表（IPE/HEA/HEB 用 EN 10034，UB/UC 用 BS 4，H 型钢用 JIS/GB）。每个规格的尺寸与性能是固定的。

### 我可以自己定截面规格吗？

截面规格应来自设计计算，不是经验法则。设计团队按荷载与当地规范确认规格；中赛按批准图纸加工。
