输送通廊从皮带反推。带宽与带速、物料重量、启动与运行张力、驱动位置、通道与检修条件，决定通廊断面、支架间距与支承钢结构；它同时承受皮带、通道与箱体风荷载，并在皮带运行时保持对中。

## 第一部分：通廊包到底包含什么

- 通廊本体（敞开或封闭），含通道楼板。
- 按间距布置的支架或门架。
- 转载塔，皮带在此卸料或改向。
- 上下通道的楼梯、平台与出入口。
- 托辊支架、滚筒支承钢（若在范围）。
- 转载点的溜槽、料斗与挡料板。

范围界线比厂房更关键：皮带、托辊与驱动属输送机厂，结构、通道与围护属钢构包。

## 第二部分：深化前必须拿到的输送机数据

| 输入 | 提供方 | 缺了为什么定不了钢构 |
|---|---|---|
| 带宽与带速 | 输送机厂 | 决定通廊内宽与净空 |
| 物料种类、堆密度、块度 | 工艺设计 | 决定活载、磨损余量与溜槽角 |
| 启动与运行张力 | 输送机厂 | 沿皮带向拉动通廊与支架 |
| 驱动站位置与重量 | 输送机厂 | 把荷载与振动集中在一处 |
| 滚筒与张紧位置 | 输送机厂 | 决定开孔、检修与局部加劲 |
| 通道宽度与栏杆标准 | 业主与当地规范 | 决定楼板宽度与栏杆荷载 |
| 检修通道与吊点 | 运营方 | 决定平台、开孔与单轨预留 |
| 环境温度与风况 | 当地资料 | 决定伸缩缝与风撑 |
| 粉尘与防爆等级（如有） | 工艺与当地规范 | 决定围护、电气与泄压 |
| 两端接口坐标 | 现场测量 | 决定整线走向与标高 |

张力与驱动数据若晚于深化，通廊须重做：皮带沿轴向拉结构，只算竖向荷载的框架必然走动。

## 第三部分：通廊断面形式与适用条件

| 断面 | 受力特点 | 适合 | 限制 |
|---|---|---|---|
| 双平面桁架通廊 | 轻、刚度好、长跨经济 | 多数带宽的通廊线路 | 断面高、加工工时多 |
| 板梁通廊 | 简单、易围护 | 中等跨度、重型皮带 | 每米自重较大 |
| 折板或箱形 | 外观整洁、抗扭好 | 可视区域的封闭通廊 | 焊接质量与变形控制 |
| 模块化槽板 | 现场装配快 | 改造与偏远场地 | 接头多，对位与密封工作量大 |

断面由跨度与皮带决定；带宽加大或单侧加通道，楼板加宽后桁架几何随之改变。

## 第四部分：支架间距与支承布置

- 间距大则基础少，但通廊更深更重。
- 每个中间支承都意味着一个基础、一次测量和一个接头。
- 沿皮带方向的支架要抗拉力，不只是抗竖向荷载。
- 支架水平支撑是防止整线侧向走动的关键。
- 支承避开驱动站、转载塔与在用车辆通道。
- 软基上支架不均匀沉降表现为皮带跑偏，而非结构裂缝。

## 第五部分：不只是重力荷载

| 荷载 | 来源 | 对钢结构的影响 |
|---|---|---|
| 运行与启动张力 | 输送机厂 | 滚筒、张紧与锚固点的纵向拉力 |
| 物料活载与冲击 | 工艺设计 | 楼板与桁架受力，转载点冲击 |
| 驱动扭矩与振动 | 驱动站 | 局部加劲、锚固与疲劳构造 |
| 长条箱体风荷载 | 当地风况 | 支架与通廊侧向与上吸 |
| 长距离热位移 | 环境温差 | 伸缩缝与滑动支座 |
| 积灰 | 运营 | 附加恒载与清扫 |
| 吊装与检修荷载 | 施工方案 | 临时支撑与吊点 |

空载通廊常由风控制：线路长、位置高、自重轻；只算满负荷、支架偏弱的框架大风天同样出问题。

## 第六部分：通道、检修与防护

- 通道宽度与栏杆高度按业主标准与当地规范。
- 散料处楼板要有排水与清扫做法。
- 上下楼梯应落在皮带线之外。
- 滚筒、张紧与溜槽开孔需可拆装防护，检修后可复位。
- 更换托辊的吊点应在设计阶段定。
- 急停与拉绳沿通道布置在结构内部。

## 第七部分：敞开与封闭通廊

| 方案 | 优点 | 限制 |
|---|---|---|
| 敞开加顶 | 造价低、易检查、通风好 | 扬尘、物料受潮 |
| 全封闭围护 | 控尘控雨、外观整洁 | 凝结水、内部腐蚀、需检修口 |
| 封闭加保温 | 降噪隔热 | 围护重、接缝复杂 |
| 敞开加转载点局部罩 | 低成本局部控尘 | 只能局部防护 |

封闭通廊最易坏在接缝：围护板跨伸缩缝刚性固定，第一个高温季就裂。

## 第八部分：伸缩缝、长距离与转载塔接口

- 长线路按计算间距设伸缩缝，支架顶用滑动或导向支座。
- 缝要允许纵向位移，同时抵抗侧向位移。
- 围护板、楼板、栏杆与桥架须同位置断开。
- 转载塔刚度与沉降不同于通廊，接口要分别考虑。
- 溜槽与料斗净空须允许位移不碰撞。
- 不能在现场把缝焊死求严实。

## 第九部分：防腐、磨损与涂装

- 磨蚀物料磨损楼板与溜槽衬板，不只是油漆。
- 封闭通廊屋面内侧常比外侧更早腐蚀。
- 热浸镀锌适合难重涂的支架框架，涂装适合外露围护。
- 海边与化肥厂按实际化学暴露选涂层。
- 耐磨板、可换衬板与检查口应在设计里。

涂层体系与干膜厚度取决于腐蚀等级和该场地的化学环境，不存在一个全球通用规格。

## 第十部分：公差与高强螺栓拼接

- 模块现场螺栓拼接，接头必须能对位，不只看强度。
- 拼接位置宜靠近支架，吊装时接头能有支承。
- 螺栓孔按现场可安装公差制孔；主拼接现场焊接等于重新设计。
- 起拱与直线度影响皮带对中，制作公差须写进图纸。
- 至少一个节间厂内预拼，发货前发现拼接与围护冲突。

## 第十一部分：海运拆分与模块尺寸

- 模块长度受集装箱/散货船尺寸与现场吊车该幅度起重能力限制。
- 长通廊拆成若干模块，成对编号标注拼接关系。
- 桁架通廊轻但体积大，宽断面多用散货或框架箱。
- 围护板、格栅、栏杆与螺栓分运，到场顺序与吊装一致。
- 编号按沿线吊装顺序，不按加工顺序。

## 第十二部分：在运行中的厂区吊装

- 跨在用皮带、道路或堆场吊装，需与运营方确认方案。
- 先立支架，再落通廊模块并拼接。
- 临时支撑保留到拼接完成、第二支承连接到位。
- 每个模块都要校核对中，而不是整条线完工才校。
- 停产窗口往往很短，预装并带部分围护的模块能省数日。

## 第十三部分：责任分界

| 事项 | 出口供应方 | 当地 |
|---|---|---|
| 结构设计与深化 | 是，基于输送机与工艺数据 | 当地工程师复核签章 |
| 加工、涂装、编号、包装 | 是 | — |
| 皮带、托辊、驱动与控制 | 除非约定，一般不含 | 输送机厂 |
| 基础与测量 | 提供锚栓布置与荷载 | 当地土建与测量单位 |
| 吊装与吊车 | 技术指导与吊装方法建议 | 当地队伍、吊车与吊装方案审批 |
| 电气与粉尘分区 | 仅预留条件 | 当地电气单位与主管部门 |
| 调试与皮带对中 | 提供支撑资料 | 输送机厂与运营方 |

## 第十四部分：设计冻结前的清单

- [ ] 已取得带宽、带速与物料数据。
- [ ] 运行与启动张力已确认。
- [ ] 驱动站位置、重量与扭矩已提供。
- [ ] 通道宽度与栏杆标准已确认。
- [ ] 检修通道与吊点已明确。
- [ ] 两端走向与标高已测量。
- [ ] 支架间距已按跨度与基础成本确定。
- [ ] 风与温度工况已纳入荷载组合。
- [ ] 伸缩缝位置与支座形式已确定。
- [ ] 转载塔接口与净空已核对。
- [ ] 接缝处围护、排水与检修口已深化。
- [ ] 腐蚀等级与涂层体系已选定。
- [ ] 拼接位置与运输、吊装限制已对齐。
- [ ] 编号与吊装顺序已与现场确认。

## 第十五部分：常见错误

| 错误 | 后果 |
|---|---|
| 张力未定就开始深化 | 通廊走动、接缝张开 |
| 支架水平支撑当作可省 | 风与启动扭矩下侧向位移 |
| 围护板跨伸缩缝刚性固定 | 第一个高温季板面开裂 |
| 拼接点设在跨中 | 吊装时无法对位、无支承 |
| 通道出入口正对皮带线 | 检修不安全，后期补防护 |
| 通道楼板无排水与清扫口 | 积料超载 |
| 不按化学暴露选涂层 | 封闭通廊内部早期腐蚀 |
| 模块只按运输尺寸定 | 现场吊车在该幅度吊不动 |

## 第十六部分：常见问题

**问：加工方设计输送通廊需要哪些资料？**
答：带宽与带速、物料堆密度与块度、运行与启动张力、驱动位置与重量、通道宽度、检修要求、两端实测走向与标高、当地风与温度资料。

**问：输送机支架间距该多大？**
答：断面深度与基础数量的取舍：间距大则更深更重，间距小则基础、测量与接头更多，须结合皮带荷载与地基确定。

**问：输送通廊需要伸缩缝吗？**
答：长线路需要，热位移与沉降会累积；按计算间距设缝，用滑动或导向支座，围护、通道与桥架须同位置断开。

**问：为什么空载通廊有时会被风破坏？**
答：长窄轻的箱体相对自重大量受风，侧向与上吸可能控制设计，支架支撑与锚固须按此核算。

**问：通廊应该敞开还是封闭？**
答：敞开加顶适合干燥物料与便于检查；封闭适合控尘防雨与外观，但要处理凝结水、内部防腐与检修口。

**问：通廊能按集装箱模块发运吗？**
答：窄断面可以，宽桁架多用散货或框架箱；模块长度受运输与吊车能力限制，拼接点宜靠近支架。


## 第十七部分：先把皮带数据定下来

把皮带数据表、驱动布置、实测走向与标高、通道要求发过来，就能在下料前定下断面、支架间距与接缝。
