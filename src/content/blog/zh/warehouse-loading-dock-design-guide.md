装卸月台不是"墙上开个门洞"。它是车辆与建筑之间的一个接口，尺寸由真正来这个场地装卸的车决定，而不是由一张通用图纸决定。月台高度跟着车厢板高度走，月台高度又决定登车桥类型和坑深，而坑位、坡道、雨棚和墙洞再反过来约束钢架、基础和地坪边缘。这四组数字定晚了，最常见的后果就是仓库交付后车靠不上、货卸不快。

本文讲清月台由哪些部件组成、高度和登车桥到底怎么定、哪些接口数据必须在钢构深化和报价之前交出来。

## 一个完整的装卸位由哪些部件组成

一个能用的装卸位是一套八件套，而这八件分属不同工种：

- **门洞与门**：墙上的洞口、洞口过梁，以及卷帘门或提升门。
- **月台坑**：地坪上容纳登车桥的凹槽，含坑壁、坑底和排水。
- **登车桥（调节板）**：把仓库地坪与车厢地板之间的高差和缝隙搭起来的钢板。
- **防撞块**：承受车辆撞击的橡胶或高分子块，目的是让墙体和坑口不挨撞。
- **门封／门罩**：把车体与洞口之间的缝隙封住的柔性框架，挡雨、挡尘、挡虫、保温。
- **雨棚**：伸出墙外的挑檐，遮住接口区域并给门封遮阳。
- **坡道／装卸场**：车辆停放和调头的外部混凝土场地。
- **安全与控制件**：引导线、止退器或车轮锁、月台灯、信号灯、开门处的防坠落措施。

由此得出两个结论。第一，月台同时是土建、机电和钢构的接口，所以它最容易变成"三不管"的那一项。第二，这份清单上的每个尺寸都由车队决定，而车队是买方信息，不是供应商可以替你假设的。

## 核心决策：月台高度对着车厢板高度

月台高度的定法，是让仓库地坪大致落在来车车厢板的高度上或略低一点。在本地以标准厢式车、半挂车为主的市场，这个数值会落在一个比较窄的区间；在以小型车、改装车为主的市场，直接照搬这个区间就会出错。

| 输入项 | 为什么它决定月台 | 谁负责给答案 |
|---|---|---|
| 到场车型 | 厢式车、半挂车、集装箱骨架车、轻型货车的板高都不一样 | 买方／物流运营方 |
| 满载与空载板高 | 悬挂受压后车板会下沉几厘米，满载和空载不是一个高度 | 买方实测 |
| 车队离散度 | 车型之间高差超过登车桥行程，一个高度就服务不了全部车 | 买方与登车桥供应商 |
| 当地习惯与审批 | 部分市场有惯用月台高度和标准车辆外廓 | 当地工程师 |
| 室内地坪标高 | 内部排水、地坪厚度、是否需要坡道，都从这里推 | 买方与土建方 |

实操规则：**量车队，不要抄图纸。** 月台和真实板高差 150 mm，仍能用，但登车桥长期在行程末端工作，搭板磨损更快，叉车整天在爬小坡；差到 400 mm，通常意味着登车桥选错级别、坑要重做。

一个可作参考、但必须用本地车队核实而不是直接套用的基准：不少外向型仓库把月台地坪做到高出装卸场 1.1–1.3 m，再据此调坡道和坑位尺寸。

## 登车桥怎么选：四种主流方案

月台高度和车型范围确定后，登车桥选型就只剩一个短名单。

| 类型 | 适用场景 | 优点 | 限制 |
|---|---|---|---|
| 坑式液压登车桥 | 一般仓库，车型有离散度的默认选择 | 升降平稳、行程范围大、可停在任意位置 | 需要带排水的坑和电源，土建成本高 |
| 坑式机械登车桥 | 月台处供电不稳定、或维护条件有限 | 结构简单、耐用、运行成本低 | 需人工操作、对搭板不够柔和、行程有限 |
| 台面式（免坑）登车桥 | 改造项目、低频率月台、地坪薄无法开坑 | 不需坑、安装快、土建成本低 | 收起后占用部分洞口，重载高频不合适 |
| 立式收纳登车桥 | 空闲时要求洞口完全清空，如直通式或混合用途 | 板体立起收纳，洞口保持通畅 | 坑更深、结构更特定、造价更高 |

真正决定"能不能用得顺"的，是两个细节：

1. **搭板长度与搭接量。** 搭板要跨过防撞块造成的水平间隙，落在车厢板上；车轻载时板位偏高，搭板仍要够得着。
2. **上下行程。** 登车桥在地坪以上和以下都有工作范围。车队板高离散大时，必须选下行程足够的型号，否则满载车厢下沉后板跟不上。

登车桥的承载力和外形尺寸属于制造厂数据，必须取自选定型号，不能套通用表。月台坑是按那台设备的图纸做的，所以**先定登车桥，再浇地坪**。

## 月台坑、装卸场与车辆作业空间

三个外部条件决定车能不能真用上这个月台：

- **装卸场坡度。** 场地要往远离建筑的方向排水，同时让满载车停得住、车厢不往前窜。纵向坡度通常做得很缓，横向找坡要避免水倒灌进坑里。坡太陡，车会打滑、车尾会翘离月台。
- **进场与调头。** 车必须能正对月台停正。场地局促时车会斜着靠，门封封不严，防撞块从"面受力"变成"边受力"，很快被剪坏。所需回转空间取决于车长，以及月台是 90° 停靠还是直通式。
- **装卸位间距。** 每个位要留出车体宽度、门宽、门封和防撞块的富余，通常按一个固定模数排布。位与位排得太近，门开不全，门封互相干扰，防撞块该分开的地方被共用。

月台沿一面墙排布时，这个模数还要对上[钢构柱网与柱距](/zh/blog/steel-structure-column-grid-bay-spacing-guide/)——这正是物流方案与结构图之间最常被漏掉的一环。

## 月台决策如何压到钢架和土建上

这部分属于建筑本体，也是月台信息必须在加工前到位的原因。

| 月台决策 | 会改动钢构和土建的什么 |
|---|---|
| 装卸位间距 | 沿月台墙的柱网与柱距；支撑不能落在洞口中间 |
| 洞口宽高 | 墙梁排布、洞口过梁、洞口周边局部加强 |
| 雨棚挑出与宽度 | 额外挑梁、与墙体的连接、雨棚风吸力 |
| 坑位与坑深 | 地坪边缘做法、坑壁，以及与柱脚底板、锚栓的净距 |
| 防撞块撞击荷载 | 洞口边缘和坑口周边的局部加强 |
| 门封／门罩形式 | 洞口上沿和两侧的净空、门轨需要的头部空间 |

最容易打架的是坑与柱脚。柱子落在带锚栓和灌浆层的底板上——这套做法见[钢结构基础设计指南](/zh/blog/steel-structure-foundation-design-guide/)——而月台坑是一个带自身坑壁的空腔。如果先定月台模数再排柱网，坑就可能贴在底板边上，中间混凝土不够，结果要么移月台，要么把柱脚节点做局部重新设计，代价都不小。

第二处冲突是洞口与支撑。钢构墙体总要有支撑受力，而月台洞口正好挖掉了一块墙。如果支撑线和月台线重合，必然有一个要挪。这类问题在图纸阶段改几乎不花成本，等柱子加工完再改就很贵。门窗洞口的做法可对照[门窗与洞口设计指南](/zh/blog/steel-structure-doors-openings-guide/)。

## 门封、门罩与门：天气边界在哪

门封／门罩是让月台在雨天、粉尘、高温或低温环境下能用的部件，也最常被低估。

- **门封**装在洞口四周，靠车体压紧来封缝，适合车型比较统一的车队。
- **门罩**是刚性框架加柔性帘布，车直接顶进去，能容忍车宽和停位偏差，高频月台常用。
- **门**开启后要给门封／门罩让位，门轨、过梁和雨棚会争同一块头部空间。

如果建筑是冷库、洁净车间或食品厂，门封不是舒适性配件，而是卫生与温度的边界，它会改变门型、洞口节点，甚至整套月台布置。这类项目的月台必须在早期就定，不能当成收尾项。

## 安全、疏散与敞开的门

敞开的月台门，是一个"落差 + 车辆移动 + 人员穿行"同时存在的边沿。

- 止退器或车轮锁，防止装货过程中车慢慢离开月台。
- 引导轨或防撞块，保护门框和门封不被停偏的车撞坏。
- 月台灯和信号灯，在繁忙月台上属于生产必需，不是选配件。
- 开门处的防坠落措施，在很多地区是强制要求，必须在洞口节点设计前定。
- 月台门是装卸口，不是主要疏散口。疏散路线、安全出口和消防策略要独立设计，当地主管部门对这件事的口径属于报批文件的一部分。

安全件的具体形式按当地法规和现场风险评估定，正确答案在本地。钢构包要做的是把几何空间和固定点位留出来。

## 钢构下单前必须定下来的清单

下面这份清单就是加工厂真正需要的接口数据。空着的项最后都会变成假设，假设最后都会变成变更单。

- [ ] 到场车型，以及满载／空载时的车厢板高度（按实际车队实测）
- [ ] 装卸位数量，哪些用于收货、哪些用于发货、哪些混用
- [ ] 月台高出装卸场的高度，以及室内地坪标高策略
- [ ] 登车桥类型、承载力，以及制造厂的坑位图
- [ ] 坑位尺寸、排水，以及与最近柱脚的净距
- [ ] 洞口宽高、门型、门轨需要的头部净空
- [ ] 门封或门罩形式及其净空尺寸
- [ ] 雨棚挑出长度、宽度，以及是否承受雪载、风吸力
- [ ] 装卸场坡度、车辆回转空间与场地进出
- [ ] 安全件：止退装置、引导轨、月台灯、防坠落
- [ ] 疏散与消防策略，并经当地主管部门确认
- [ ] 登车桥与门的电源位置和控制位置

## 责任边界

月台跨工种，边界要在下单前写清楚。

| 范围 | 中赛 | 当地一方 |
|---|---|---|
| 钢架、墙洞、过梁与雨棚骨架 | 按确认图纸做深化、加工、编号与包装 | — |
| 登车桥、门封、门罩与门 | 只负责接口尺寸协调 | 由专业供应商供货、安装与调试 |
| 月台坑、装卸场、地坪边缘与排水 | 对照基础图与地坪图做接口复核 | 由当地土建承包商设计与施工 |
| 月台高度与车辆外廓 | 依据买方提供的车队数据做工程协调 | 由当地工程师按当地实践确认 |
| 报批、疏散与消防审批 | 按需要提供图纸支持 | 由当地注册工程师提交并取得批准 |
| 现场安装 | 提供安装技术指导 | 由当地劳务完成实际安装 |

## 常见错误

- **没量车队就定月台高度。** 整栋建筑围绕错误的车型做尺寸。
- **浇完地坪才选登车桥。** 坑尺寸对不上设备，唯一的办法是砸掉重做。
- **排月台位时不看柱网。** 坑贴在柱脚边上，或者支撑正好落在洞口里。
- **忽略装卸场。** 图上能用，实际满载车在坡上停不正。
- **把门封当配件。** 在冷库、洁净或食品项目上，它是工艺边界。
- **忘了雨棚荷载。** 挑出长的雨棚是受风结构，不是装饰性挑板。

## 常见问题

**仓库月台应该做多高？**
应当对准真正到这个场地装卸的车辆车厢板高度，且要分别量满载和空载。不少外向型仓库做到高出装卸场 1.1–1.3 m，但这个数值必须用本地车队和当地习惯核实，不能直接照抄模板。

**登车桥一定要做坑吗？**
不一定。坑式登车桥需要带排水的坑和电源；台面式登车桥直接装在板面上、不用开坑，但收起后会占用部分洞口净空。选哪种取决于装卸频率、地坪厚度，以及空闲时洞口是否需要完全通畅。

**月台门可以随便开在墙的哪个位置吗？**
不可以。洞口要落在柱子之间，避开支撑线，并在坑与柱脚底板之间留出足够的混凝土。月台布置和柱网必须一起做。

**每个装卸位要多宽？**
要满足车体宽度、门宽、门封和防撞块，再加操作富余。装卸位通常按固定模数排布，而这个模数要同时配合车型和钢构柱距。

**月台设计会影响钢构用钢量吗？**
会。洞口多意味着过梁和局部加强，雨棚要加挑梁和承受风载，坑与柱脚冲突还可能引起基础局部重新设计。钢架本身的变化通常不大，真正占大头的是土建和协调成本。

**房子建好了还能再加月台吗？**
可以，但那是结构改造：墙洞、支撑、地坪边缘、坑和排水全都要动。在一栋柱网和支撑从来没为月台预留过的建筑上加月台，代价远高于在设计阶段就留好。

## 询价时需要提供什么

只有一张平面图，月台是报不出价来的。请提供车型清单与实测板高、装卸位数量与用途、室内地坪标高，以及已经选定的登车桥或门型。布置尚未定案时，至少提供物流方案和限制条件，让接口和钢架一起深化，而不是等钢架做完再补。
