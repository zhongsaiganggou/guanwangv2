绝大多数钢结构厂房出口按 HS 7308（结构物及结构物部件）申报，整体预制建筑可能归入 9406，未加工的型钢属 7216。归哪一档，取决于集装箱里实际装的是什么、单证怎么描述，最终认定权在目的国海关。编码直接影响关税、原产地优惠和贸易措施，所以要在开商业发票之前定下来，而不是等柜子到港再补。

这篇讲的是归类逻辑，不是报价。税率会变，还跟目的国、原产地和当时生效的贸易措施有关。不变的是分析一套钢结构的思路。

## 第一部分：钢结构会碰到的四个税号

一套钢结构过境，反复出现的就是这四个号。它们不能互换，混用是这行里代价最高的单证错误之一。

| HS 税号 | 覆盖什么 | 典型内容 | 最容易错在哪 |
|---|---|---|---|
| 7308 | 钢铁结构物及结构物部件；税号条文本身把 9406 的预制建筑排除在外 | 钢柱、钢梁、檩条、支撑、屋面墙面骨架、连接板、柱底板等已加工构件 | 整套构件按此申报、实际却是完整预制建筑，或者反过来 |
| 9406 | 预制建筑 | 完整的建筑单元，常随墙板屋面板与配套件一同发运 | 把散件构件当成完整建筑申报 |
| 7216 | 铁或非合金钢的角、型、截面材 | 轧制原尺型钢，尚未切割、钻孔、焊接或按具体结构加工 | 把加工好的建筑构件按原材料申报 |
| 7318 | 螺钉、螺栓、螺母、垫圈等 | 连接螺栓、锚栓、螺母、垫圈，有时单独打包 | 忘了单独包装的紧固件可能单独归类 |

多数情况下决定归类的是条文里那句“已加工用于结构物”。刚下线的 H 型钢是型材；同一根钢梁，切到长度、钻了孔、焊上连接板、按轴线编好号，就是结构物部件了。

## 第二部分：为什么大多数钢结构厂房落在 7308

一套以散件形式出口的钢结构，在海关眼里就是一批为特定结构物加工过的构件。柱子有柱底板和锚栓孔，梁有端板、加劲肋和螺栓孔，檩条按柱距切好，支撑配了节点板。这些都已经不是轧制原尺型材。

所以 7308 是加工钢构件的常规归处：税号条文明确覆盖结构物与结构物部件，也明确覆盖“已加工用于结构物”的板材、杆材、角型材、截面材和管材。

由此有两个实操后果。

第一，发票描述必须对得上这个事实。只写“steel structure”太薄。把建筑类型、构件大类、以及“已加工并按吊装位置编号”写进去，报关行才有东西可用。

第二，装箱单必须一致。发票写“加工钢结构，42 件”，装箱单列的是 42 捆切好钻孔、带编号的构件，故事就成立。发票写“结构”，装箱单写“型钢”，那票基本就要在最不该停的时候停下来解释。

## 第三部分：什么时候该归 9406

9406 这个号存在的理由很直接：预制建筑不只是“一堆构件”。当供应商发的是一套完整建筑单元——结构加上墙板屋面板、门窗，以及让它成为“建筑”而不是“构件包”的配套件——归类的落点就会往 9406 走。

海关看的不是叫法，是货。这套东西是作为一栋完整建筑呈现的，还是作为一套在现场才能装成建筑的构件呈现的？两种答案在真实贸易里都存在，只要货和单证对得上，都能站得住。

实操中主要看三点：

- **完整度**：带着围护、开口和配套件到货的建筑，跟只有骨架的一包构件，读起来完全不同。
- **呈现方式**：怎么描述、怎么包装、对外怎么讲，都会被看到。发票写“预制建筑”，箱子里是三百根散件，一定被问。
- **目的国的既有做法**：有些海关对钢结构成套件有公开指引或裁定。决定报关的是那份东西，不是供应商的偏好。

因为这两个号在某些市场的关税待遇不一样，这不是学术问题。值得在生产开始前就用书面确认下来。

## 第四部分：为什么 7216 不是建筑税号

7216 是材料号。它覆盖铁或非合金钢的角、型、截面材，指轧制出来、还没被做成某个具体结构件的状态。

加工厂按 7216 买进，按 7308 卖出。这是正常的商业链条：钢厂卖型材，加工厂卖加工件。把钻好孔、焊好、编好号的建筑构件按 7216 申报，描述的是投入，不是产出。

破绽在单证上。发票写“H 型钢，6 米，Q235B”，装箱单却是带螺栓孔和配对标记的定尺件，货已经不符合申报税号了。报关行发现会要求改单；海关事后发现可以重新归类，而重新归类通常伴随补税和滞港。

也有一个诚实的例外：如果这一票真的就是未加工的原尺型材，比如买方按材料额度采购、到当地再加工，7216 可以是正确的。判断依据是货的实际状态，不是项目名字。

## 第五部分：归类决策表

开发票之前，用这张表先自己过一遍。每一行描述的都是集装箱里实际装的东西。

| 箱子里装的是什么 | 可能归入 | 为什么 | 要确认什么 |
|---|---|---|---|
| 为一个结构物切好、钻孔、焊接、编号的构件 | 7308 | 已加工用于结构物的部件 | 发票与装箱单描述的是加工构件，不是型材 |
| 带围护板、开口与配套件的完整建筑单元 | 9406 | 预制建筑 | 目的国对成套件的做法，以及围护是否同批 |
| 未加工的轧制原尺型钢 | 7216 | 角、型、截面材 | 这一包里没有任何构件被加工用于结构物 |
| 构件加单独包装的螺栓螺母垫圈 | 7308 加 7318 | 紧固件本身是独立商品 | 紧固件是同包还是单列一行 |
| 屋面板、天沟、泛水等配件 | 常随建筑税号，也可能单列 | 取决于材质与呈现方式 | 目的国对混合货载的处理 |
| 备件与替换构件 | 一般随部件的税号 | 它们是结构物部件 | 描述里写明是“某结构的备件” |

这张表替代不了报关行的意见，但它能在意见给出之前，把最常见的错挡掉。

## 第六部分：单证必须讲同一个故事

归类不只是表格上的一个号，而是一个故事：发票、装箱单、构件上的标记、原产地证，必须用同一种说法讲出来。

| 单证 | 应该写什么 | 什么会毁掉这个故事 |
|---|---|---|
| 商业发票 | 与税号匹配的产品描述：加工钢结构、构件大类、建筑类型 | 只写“钢材”“钢材料”，看不出加工状态 |
| 装箱单 | 件数、标记、重量，并说明构件已切割加工 | 行项目按轧制型材描述 |
| 捆扎标记 | 把每根构件对应到图纸位置的组装标记 | 标记在单证里根本找不到 |
| 原产地证 | 与实际生产情况相符的原产地判定 | 单证支撑不了所声称的原产地 |
| 材质证明 | 所用钢材的牌号与炉批号 | 证书牌号与发票对不上 |

标记的作用比看上去大。捆扎标记、装箱单、图纸编号三者对得上，查验时容易解释，被问时也拿得出依据。反过来，标记是装柜前一晚找人现喷的，就很难说清。

## 第七部分：编码在商业上改变了什么

税号不是形式。它站在买方关心的三件事上游。

**关税。** 目的国的关税表按本国税则号列定税率。六位 HS 只是第一步，多数报关要报到八位甚至十位，同一个六位号在各国可以被拆成好几个税率。这里不报具体税率，因为税率会变，还与原产地和贸易措施相互作用。

**优惠原产地。** 目的国与中国有贸易协定时，原产地单证可以支持优惠申请。能不能享受，取决于协定里的产品特定原产地规则；供应商不能默认“钢结构就一定符合”。这是出口方与进口方要一起确认的事，而且证书必须与货对得上。

**贸易措施。** 有些市场对特定钢产品有反倾销、反补贴或保障措施。一套建筑包是否落入某项措施，取决于该措施的产品范围和申报归类，不取决于宣传册上怎么叫。这也是要早定归类、并且让生产描述保持诚实的原因。

## 第八部分：六种典型错报

钢结构进口里返工最多的就是这几种，没有一种是稀罕事。

| 错法 | 会怎样 | 怎么避开 |
|---|---|---|
| 加工成套件按型材税号申报 | 被重新归类、补税，改单期间产生堆存与滞箱费 | 按加工构件描述，装箱单口径一致 |
| 只有骨架的货按 9406 报 | 被质疑完整度，可能被重新归类 | 9406 留给真正完整的建筑单元 |
| 忘了单独包装的紧固件 | 出现未申报项，申报单要改 | 紧固件单列一行、单独给税号 |
| 发票与装箱单描述不一致 | 扣单、退单补正 | 描述只写一次，全流程复用 |
| 原产地证支撑不了所声称的判定 | 优惠被拒，关税重算 | 出证前先核对协定的产品特定规则 |
| 抄同行旧单据上的编码 | 那个号适配的是他的货，不是你的 | 拿货去套条文，而不是套先例 |

第六条值得单独说。别人用另一个号，不代表你错；去年类似的一票用过这个号，也不代表你对。对，是指货与条文相符。

## 第九部分：出口项目里的责任边界

归类正好落在供应商与进口商之间，这条线应该在合同里写清楚。

| 环节 | 中赛负责 | 进口方 / 当地负责 |
|---|---|---|
| 产品描述与技术规格 | engineering coordination 与详图、构件清单、加工状态说明 | 确认描述与采购订单一致 |
| 出口单证 | 商业发票、装箱单、材质证明、按约定出具的原产地文件 | 核对单证是否符合目的国要求 |
| 归类与报关 | 应要求提供准确的产品事实 | 报关、申请裁定、对接报关行 |
| 关税、税费与贸易措施 | 提供原产地与生产信息 | 缴纳关税税费、确认适用措施 |
| 清关延误 | 及时补充更正单证 | 对接报关行、港口与主管机关 |

规则很简单：供应商描述货，进口商归类并清关。供应商为了让报价好看而悄悄挑一个号，风险最后落在进口商的碼头。

## 第十部分：开发票前的检查清单

- [ ] 已拿货去套税号条文，而不是套上一票的做法。
- [ ] 发票描述写明建筑类型，并说明构件已加工、已准备用于结构物。
- [ ] 装箱单使用同一描述，并列出件数、标记与重量。
- [ ] 单独包装的螺栓、螺母、垫圈已单列一行。
- [ ] 材质证明的牌号与实际用钢一致。
- [ ] 若要申请优惠，原产地证已按协定规则核对。
- [ ] 目的国税则号列已与报关行确认到八位或十位。
- [ ] 适用的贸易措施已对照申报归类核查。
- [ ] 发票、装箱单与捆扎标记使用同一套组装编号。
- [ ] 进口方已书面确认本票将使用的税号。

## 第十一部分：常见问题

**问：钢结构厂房用 HS 7308 对吗？**
答：以散件形式出口、由钢柱钢梁檩条支撑等已加工构件组成的成套件，通常归 7308，因为它们是已加工用于结构物的结构物部件。完整预制建筑则可能归 9406。

**问：供应商能不能为了少缴税选 9406？**
答：不能。税号跟着货和目的国规则走，不跟着偏好走。为改变税负而挑号属于申报错误，后果由进口方承担。

**问：螺栓、锚栓跟结构用同一个税号吗？**
答：通常不。紧固件本身是独立商品，常归 7318，单独包装时尤其如此。它们应当单列，而不是被摊进钢构吨位里。

**问：一票里既有构件又有屋面板怎么办？**
答：混合货载按各组成部分和呈现方式归类，各地做法不同。描述应如实列出组成，让报关行套用当地规则。

**问：HS 编码能决定能不能享受自贸协定税率吗？**
答：不能单独决定。协定里的产品特定原产地规则决定资格，原产地单证要能支撑。编码只是输入之一。

**问：海关重新归类，责任在谁？**
答：申报责任在进口记录人。供应商的责任是提供准确的产品事实与单证。这也是描述要在生产前谈定、而不是到港后再说清楚的原因。

**问：柜子开船之后还能改归类吗？**
答：申报可以修改，但代价总要有人付：堆存、滞箱、补税，有时还有更长的查验。装柜前把描述改对，比卸船后改单便宜。
