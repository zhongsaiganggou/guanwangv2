汽车展厅加售后中心，不是“一栋厂房配一套要求”。它一半是从马路上看要体面的零售空间，一半是举升机下面必须好用的维修车间，两者装进同一个钢构外壳。钢结构适合这类项目，是因为它既能给展厅做大净跨，也能给车间做重复柱距，工期还跟得上品牌开业节点。但排布不由钢架决定，而由品牌标准、设备清单、车辆动线、当地防火与报建要求、场地排水和出入口决定。

排布错了，贵的方式很具体：柱子落在展车区中间、工位深度放不下长轴距车加举升机、地坪承受不了设备点荷载。这三件事，都在钢构深化之前就该定。

## 第一部分：一个外壳，两套需求

| 需求 | 展厅一侧 | 车间一侧 |
|---|---|---|
| 主导因素 | 品牌形象、视线、立面 | 设备排布、车辆动线 |
| 结构重点 | 大净跨、少内柱 | 重复柱距、局部加强 |
| 地面 | 平整、成品感强 | 耐磨、有排水、可锚固设备 |
| 机电 | 照明、舒适空调、低噪音 | 排风、压缩空气、排水、动力电 |
| 消防 | 公众疏散与安全 | 危险区域分隔与灭火 |
| 围护 | 玻璃、造型板、招牌位 | 耐撞墙板、大门、通风 |

两侧可以共用一个屋面、一套主体结构。但地坪做法、防火分区、人车动线，通常不该共用。

## 第二部分：展厅的净跨由什么决定

净跨首先是品牌与陈列决定，然后才是结构问题。真正影响它的是：

- **展车数量**，以及展车是一字排、扇形排，还是放在抬高的展示台上。
- **品牌标准是否要求整面无框玻璃立面**，这会把结构推到周边。
- **是否设夹层**做办公、客休或交车区，以及夹层是结构夹层还是二次钢平台。
- **层高与照明策略**，高空间配高灯位，和低吊顶配吊灯，观感完全不同。
- **招牌与立面分区**，这些位置不能出现支撑或拉杆。

做大净跨并不难。难的是剩下那一两根内柱落在哪里——钢构一旦下料，柱位就定死了。

## 第三部分：车间的柱距由什么决定

车间是另一种几何题：

| 车间要素 | 由什么决定 | 排布后果 |
|---|---|---|
| 工位长度 | 车型、举升平台、技师作业空间 | 通常由最长车型决定，而不是平均车型 |
| 工位宽度 | 举升机尺寸、工具位、门位 | 重复模块比定制工位更省加工成本 |
| 举升机形式 | 双柱、四柱、剪式、四轮定位 | 点荷载与地坪厚度随形式变化 |
| 定位工位 | 设备占地、前后通行 | 需要平整稳定的地坪和明确进出方向 |
| 钣喷区 | 排风、防火分隔、废料收集 | 通常要与展厅分隔成独立分区 |
| 配件与轮胎库 | 货架高度与取放方式 | 可能值得单独做一个低净高区域 |
| 洗车工位 | 排水、供水、隔离 | 地面找坡与隔油必须提前设计 |

工位可以集中在一个大厅，也可以拆成“前场快修 + 后场钣喷”。钢构造价差别不大，运营差别很大。

## 第四部分：玻璃立面与雨棚的结构代价

展厅正面往往是整栋楼结构最别扭的地方：该出现的东西都不能出现——玻璃平面里不能有支撑，展区前方不能有拉杆。

| 部位 | 设计难点 | 常见处理方向 |
|---|---|---|
| 通高玻璃幕墙 | 风荷载与整体抗侧 | 靠屋面蒙皮、门式刚架作用或背侧支撑提供稳定 |
| 入口雨棚 | 悬挑受力、排水、观感 | 悬挑或带拉杆雨棚，并设独立排水路径 |
| 造型板带 | 与玻璃的收口公差 | 放线与幕墙供应商协同 |
| 招牌与灯箱 | 固定荷载与防水 | 二次钢结构与招牌厂家同步设计 |
| 坡道或展台 | 地坪与钢架交接 | 坡道结构与土建同步 |

雨棚要早看：它接雨、受风，而且是客户走进店时头顶第一件东西。

## 第五部分：地坪与设备接口

地坪通常由当地土建做，不在钢构供货范围内。这恰好是 4S 项目最常出问题的接口。

| 事项 | 一般由谁定 | 为什么影响钢构包 |
|---|---|---|
| 板厚与配筋 | 当地结构工程师 | 举升机与设备点荷载必须在柱网冻结前确认 |
| 平整度与标高公差 | 业主与设备供应商 | 定位与测量设备需要明确公差 |
| 分仓缝位置 | 土建设计 | 缝不能穿在举升机脚下 |
| 排水找坡与地漏 | 土建与机电 | 洗车与维修区要找坡、要隔油 |
| 举升机锚栓位置 | 设备供应商 | 锚固放线必须在浇筑前下发 |
| 大门处收口 | 土建与钢构深化 | 门槛与外部地坪标高必须对齐 |

如果举升机的锚栓图在浇筑之后才到，项目就要付后置锚栓或局部开凿的代价。

## 第六部分：防火分隔与危险区域

防火策略由当地规范与主管部门定，钢结构设计要跟着它走，而不是反过来。

| 区域 | 常见关注点 | 设计应对方向 |
|---|---|---|
| 展厅 | 公众聚集、疏散、烟气 | 受保护的疏散路径、排烟措施 |
| 维修大厅 | 车辆燃油、动火、堆放物 | 防火分隔、通风、灭火措施 |
| 钣喷区 | 易燃物、排风 | 独立分隔，独立机电 |
| 电池或电动维修区 | 热失控风险、隔离 | 独立区域、探测、通风、消防救援通道 |
| 配件库 | 可燃包装与货架 | 喷淋与分隔策略 |
| 充电区 | 电气危险、车辆通行 | 设备防护与疏散净空 |

具体要几小时耐火、要不要喷淋，取决于当地规范、建筑使用分类与主管部门的判定。这些属于当地消防工程师与报建流程。

## 第七部分：人车动线十项自查

- [ ] 客户动线与车辆动线分开。
- [ ] 展车不会穿越维修车辆的行驶路径。
- [ ] 交车与 PDI 车辆不混入客户停车区。
- [ ] 服务接待处有带雨棚、有指示的落客位。
- [ ] 工位之间可直接驶出，不需要倒穿另一个工位。
- [ ] 配件卸货不堵塞服务通道。
- [ ] 加油或充电区在主车流之外。
- [ ] 废油与轮胎集中点有独立通道。
- [ ] 消防车能到达维修区与充电区。
- [ ] 员工停车、洗车、客户停车不共用一个入口。

交付后运营方投诉最多的，通常是动线问题，不是结构问题。

## 第八部分：屋面、排水与热带暴雨

在马来西亚、泰国、印尼等地区，4S 店的屋面必须扛住短时强降雨，而且不能漏到展车区。

| 风险 | 设计考虑 |
|---|---|
| 天沟与女儿墙溢流 | 设溢流口与备用排水路径 |
| 雨棚滴水到客户区 | 雨棚设天沟、落水管有组织排放 |
| 玻璃接缝的风驱雨 | 钢架、幕墙、墙板的接口细部 |
| 金属屋面冷凝 | 隔汽与保温策略 |
| 落水口堵塞 | 落水口防护与检修通道 |
| 屋面检修 | 安全通道与防坠落措施 |

排水能力是当地降雨参数决定的；钢构包要做的是为指定系统提供结构支承，而不是默认一个通用做法。

## 第九部分：充电与电池作业区

增加电动车销售与售后的经销商，会发现原排布没给这些留位置。

- 充电车位需要电力容量、电缆路径与车辆净空。
- 电池维修区需要隔离、探测与经主管部门认可的消防策略。
- 高压作业工位可能需要与普通工位分开。
- 存放或搬运电池包时，地坪荷载会变。
- 交车区可能需要独立充电位，避开主展车动线。

这些几乎不改钢架，但它们改排布、改地坪、改机电、改消防报建——所以必须在深化前写进任务书。

## 第十部分：报价前该给什么

- [ ] 总平面图，含出入口、标高、场地边界条件。
- [ ] 品牌标准或参考布局，标明展车区与立面意图。
- [ ] 展车数量与陈列方式。
- [ ] 车间设备清单，含举升机形式与锚固数据。
- [ ] 工位数量、功能与预期车型尺寸。
- [ ] 夹层需求与用途。
- [ ] 雨棚范围与招牌位置。
- [ ] 需要的防火分区与主管部门意见。
- [ ] 屋面墙面材质、颜色与保温要求。
- [ ] 当地设计荷载：风、必要时地震、楼面活荷载。
- [ ] 工期与期望交付时间。
- [ ] 当地土建与基础设计是否已委托。

只凭一张品牌效果图报价，最后一定被改图推翻；按上面这份清单报价，才能直接下料。

## 第十一部分：常见错误

| 错误 | 为什么会发生 | 代价 |
|---|---|---|
| 设备清单未定就冻结钢架 | 钢结构急，设备不急 | 工位宽度与地坪荷载在加工后变更 |
| 把地坪当成别人的事 | 土建是独立标段 | 交付调试时锚栓与分仓缝打架 |
| 支撑被布在玻璃立面上 | 幕墙设计晚于结构 | 出现可见拉杆或返工重做 |
| 屋面做完才加雨棚 | 雨棚被当成建筑附加 | 重新深化、排水渗漏、交付延期 |
| 展厅与钣喷共用一个防火分区 | 消防策略还没介入 | 分区改造 |
| 没考虑电动维修 | 开业后才加 EV 业务 | 充电与电池区挤进不合适空间 |

## 第十二部分：责任分界

| 事项 | 出口供应方 | 当地 |
|---|---|---|
| 设计配合与深化 | 是 | 确认设计依据、品牌标准与荷载 |
| 加工、质控、标记、包装、装柜 | 是 | 可派员见证或审厂 |
| 出口协调与海运单证 | 是 | 清关、内陆运输 |
| 基础与地坪设计 | 仅提供接口条件 | 当地结构工程师与土建 |
| 消防策略与报建 | 按需提供支撑资料 | 当地消防工程师、建筑师、业主 |
| 当地用工与现场安装 | 仅技术指导 | 当地承包商 |
| 设备安装与调试 | 否 | 设备供应商与经销商 |
| 幕墙、招牌、专项立面 | 仅提供接口尺寸 | 专项分包 |

## 第十三部分：常见问题

**问：展厅和车间能共用一个钢架吗？**
答：能。通常是一个主体结构，两侧用不同柱距，设备位置做局部加强。但两边仍需要不同的地坪做法、机电路径，往往还需要不同的防火分区。

**问：展厅需要多大净跨？**
答：取决于品牌标准、展车数量和立面是否要整面无遮挡玻璃。没有通用数值，净跨跟着陈列布局走，剩下柱位必须在加工前定案。

**问：维修车间的地坪由谁设计？**
答：通常由当地结构工程师与土建承包商，依据设备供应商的荷载与锚固数据设计。钢构供应商提供柱脚位置、门洞等接口条件，地坪本身属当地设计责任。

**问：车间与展厅之间的防火分隔怎么做？**
答：由当地规范与主管部门判定，依据使用性质、危险程度和疏散要求。钣喷区或电池区通常要独立分隔；普通维修区是否需要与展厅分隔，取决于规范与消防工程师的策略。

**问：雨棚可以后加吗？**
答：可以，但设计和主体一起做更省。后加意味着重新深化节点、重做排水，可能还要改立面收口。

**问：一开始就要按电动车充电设计吗？**
答：如果建筑使用期内计划做 EV 销售或售后，电力容量、车辆净空、电池区与消防策略都应在排布阶段考虑。在已完工展厅里加充电，通常受既有机电与地坪限制。

**问：4S 项目最容易拖在哪？**
答：设备信息给得晚。举升机形式、锚固图、烤房要求和充电方案都会改地坪、改工位、改消防，而钢构加工不可能无限期等。

## 第十四部分：先定布局，再定钢架

钢构是 4S 项目里最简单的一环。最贵的，是加工完才发现展车区的柱子位置不对、举升机锚栓对不上地坪。把品牌布局、设备清单与总平面一起给过来，钢构包才能一次深化到位。
