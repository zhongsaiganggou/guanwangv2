钢结构无损检测（NDT）是在不切割、不破坏构件的前提下，检查焊缝与钢材内部或表面缺陷的检验。常用方法为目视检测（VT）、超声波检测（UT）、磁粉检测（MT），规范要求时再用射线检测（RT）或渗透检测（PT）。用哪种方法、抽检多少、什么算合格，由项目规范、执行等级与买方要求决定。中赛按约定范围实施并随钢材出具报告。

本文讲清每种方法能证明什么、检测如何卡进工序，以及订货前该把哪些内容写进规范。

## 一、NDT 在钢结构上到底检什么

NDT 只瞄准"藏起来会出事"的部位：焊缝体积、热影响区，厚板时还有母材本身；它不是给整个货包盖章。

- **安全**——内部缺陷可能在远低于设计值的荷载下扩展、失效。
- **质量控制**——车间内发现缺陷，返修快、成本低；工地上发现则两难。
- **证据**——NDT 报告随钢材走，是工程师与监管方要的质量文件。
- **验收**——规范定义方法、范围与判定标准，NDT 拿实物去对照。

常被与 NDT 混淆的还有两份文件：材质证明书（MTC）证明钢厂交的是什么钢（炉号、化学成分、力学性能），不涉及怎么焊；尺寸检查证明几何，不是内部致密性。三样通常都要。

## 二、检测方法与各自的证明力

| 方法 | 能证明什么 | 覆盖不到的 | 用在哪 |
|---|---|---|---|
| **目视检测（VT）** | 焊缝成形、焊脚与喉厚、咬边、飞溅、表面裂纹、组对间隙 | 表面以下的一切 | 每条焊缝，其他方法前后都要做 |
| **超声波检测（UT）** | 内部平面型缺陷：未熔合、未焊透、裂纹、厚板层状撕裂 | 几何过复杂时探头进不去；表面需涂耦合剂扫查 | 全熔透焊缝、厚板焊缝、母材检查，按规范 |
| **磁粉检测（MT）** | 铁磁性钢材的表面与近表面裂纹 | 奥氏体不锈钢等非磁性材料——改用 PT | 焊趾、热影响区，按规范 |
| **渗透检测（PT）** | 任何材料（含非磁性）的表面开口裂纹 | 表面以下的缺陷 | 不锈钢构件、MT 不适用的接头 |
| **射线检测（RT）** | 内部体积型缺陷：气孔、夹渣、未焊透 | 与射线束平行的紧贴型平面缺陷检出不可靠；需辐射安全管控 | 规范明确要求 RT 时 |

![用磁轭对钢焊缝做磁粉检测（概念示意图）](/images/blog/steel-structure-ndt-testing/mt.jpg)

有两点直接决定结果能不能用：一是资质，焊缝 NDT 须由按 ISO 9712 或 ASNT Level II 认证、覆盖对应方法与专业的人员执行；二是时机，UT 与 MT 必须在裸钢上做，涂装、镀锌后显示被遮盖、耦合也变了，那时做的不是检测，是返工决策。

## 三、什么关切用哪种方法

买方多半带着"担心"来，而不是方法名。下表把关切对上方法。

| 图纸或规范里的关切 | 对应方法 | 说明 |
|---|---|---|
| 焊趾处的表面开口裂纹 | 先 VT，再 MT（不锈钢用 PT） | MT 只对铁磁性钢有效 |
| 全熔透对接焊缝的未熔合 | UT | RT 对紧贴型平面缺陷不敏感 |
| 对接焊缝里的气孔、夹渣 | RT 或 UT | RT 留下可归档的永久影像 |
| 厚板的层状撕裂风险 | 下料焊接前对母材做 UT | 这是母材检查，不是焊缝检查 |
| 焊脚或喉厚不足 | 用焊缝量规做 VT | 属尺寸项，不是致密性项 |
| 涂层厚度或附着力 | 涂层检测，不是焊缝 NDT | 按涂装规范单独做 |

规范点的方法若与实际关切对不上（如给平面型缺陷指定 RT），应在技术评审阶段提出，别等焊完涂完再改。

## 四、NDT 在订单里的时间点

每种方法都有窗口期，检测须被有意排进工序：

1. **母材阶段**——担心层状撕裂或厚板时，下料前先做钢板 UT。
2. **加工期间**——焊完冷却后、表面处理前做焊缝 NDT。
3. **终检**——全部焊缝目视检测，加上约定的 UT、MT 或 RT 范围。
4. **出厂前**——买方或其委派的验货员见证约定检测，并审阅报告。
5. **现场**——当地团队检查可见焊缝与连接，发现异常拍照反馈。

加工顺序见[钢结构是怎么加工出来的](/zh/blog/steel-structure-fabrication-process-guide/)，出厂环节见[出货前验货](/zh/blog/steel-structure-pre-shipment-inspection-guide/)。

## 五、写进 NDT 规范的九项内容

这一节决定报告到货后能否被接受：

- [ ] **标准与验收等级**——例如 ISO 5817 焊缝质量等级 B、C、D，AWS D1.1 验收条款，或项目所在地规范。
- [ ] **执行等级或检验类别**——适用欧标体系时写 EN 1090-2 的 EXC1 至 EXC4，或当地等效要求；等级决定检验投入的基线。
- [ ] **按接头类型定方法**——对接焊缝、角焊缝、全熔透与部分熔透分别写，以及工程师要求额外覆盖的接头。
- [ ] **检测范围**——哪些构件、哪些焊缝，全检还是抽检。比例属规范层面的决定，没有通行数字；供应商没看到你规范就报比例，那是猜的。
- [ ] **停止点与通知**——涂装前、包装前设停止点，并留出见证人进场的时间。
- [ ] **人员**——认证体系、等级与方法，证书随报告归档。
- [ ] **报告内容**——构件与焊缝编号、方法与设备、操作者与等级、验收标准、结果、日期，以及审阅方需要的语言。
- [ ] **返修与复检**——批准的返修工艺，返修部位必须复检。
- [ ] **第三方**——谁委派、谁在场、谁付费，车间给什么准入条件。

## 六、买方如何核验报告

1. 对照检验计划逐项核对：计划里的构件或焊缝是否都出现，缺编号即残缺文件。
2. 核对报告上的方法与验收标准是否与你规范一致，而不是供应商的默认口径。
3. 核对操作者资质等级、方法是否记录，且检测日期在证书有效期内。
4. 用构件编号与装箱单、安装图交叉核对，确保检过的就是发走的那件。
5. 关注返修项：有返修无复检记录，就是未闭环项。
6. 报告与[材质证明书](/zh/blog/steel-structure-mill-test-certificate-guide/)归在同一个质量档案里，材料证据与工艺证据放在一起。

## 七、快速回答

### NDT 和材质证明书是一回事吗？

不是。MTC 证明钢厂生产的钢材（炉号、化学成分、力学性能，按 EN 10204 3.1 或 3.2）；NDT 检的是加工后的构件与焊缝。一份证料，一份证工艺，都该进质量档案。

### NDT 报告由谁签？

执行检测的技术人员签记录，制造方质检会签；委派第三方时由其出具或背书报告。签字对应实际检测人的资质等级。

### 焊缝 NDT 里的"合格"是什么意思？

合格指显示落在约定标准限值内——如 ISO 5817 的某一质量等级、AWS D1.1 的验收条款，或项目专用判据。没指明标准的"合格"不是判据；只写"通过"的报告事后无法审计。

## 常见问题

### 钢结构工程需要做哪些 NDT？

取决于规范与执行等级。常见基线是全部焊缝目视检测，再对工程师指定的接头做 UT、MT、PT 或 RT。主结构与全熔透焊缝通常比次要角焊缝检得多，最终范围以你规范为准。

### 所有焊缝都要 UT 或 RT 吗？

不是。方法与覆盖范围跟随焊缝等级与规范。很多项目是全部焊缝目视检测，再在明确范围内加做 UT、MT 或 RT，而非整结构全做。

### NDT 由谁做？

中赛质检在车间实施约定 NDT 并归档报告；买方委派的第三方验货员可到场见证同一批检测，两条路径不互斥。

### 我应该收到什么报告？

能用的报告要列出构件与焊缝编号、方法与设备、操作者资质等级、验收标准、每项结果与日期；验货员与设备校准证书通常一并附上。

### 焊缝 NDT 用哪套验收标准？

标准来自你规范点明的那一本——ISO 5817 焊缝缺欠质量等级、AWS D1.1 结构焊接验收条款，或当地规范——再对应到所用方法。报告应写明标准与等级，便于审阅方复核。

### 焊缝 NDT 不合格怎么办？

记录显示，按批准工艺返修，返修部位用同一方法复检合格后放行。返修与复检结果都进档案，焊缝历史保持可追溯。

### NDT 包含在价格里吗？

NDT 属订货时约定的质量范围。要确认包含什么——方法、范围、报告、见证准入——第三方检测是否另计，几家报价才是在同一范围上比。

## 责任边界：供应商与当地团队

| 环节 | 中赛（钢供应商） | 当地团队 |
|---|---|---|
| 规范 | 订货与技术评审时确认 NDT 范围与检验计划 | 订货时写明所需标准、范围与验收等级 |
| 材料 | 提供材质证明书，需要时提供钢板 UT | 与注册工程师一起审核材料文件 |
| 加工 | 表面处理前实施约定 NDT 并出具报告 | — |
| 见证 | 给买方或第三方验货员车间准入与停止点通知 | 需要时委派并支付验货费用 |
| 文件 | 报告、证书与检验档案随钢材发运 | 到货核对档案，归档用于报批 |
| 现场 | — | 检查可见焊缝与连接，拍照反馈异常，按当地规范安排现场检测 |

结构报批、许可、基础设计与现场焊接验收，仍由当地注册工程师与主管机关负责——中赛的 NDT 范围止于车间范围。
