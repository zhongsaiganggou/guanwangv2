---钢结构制造流程是把审批通过的加工图变成带编号、可打包、随时发运的构件的过程，通常按固定顺序推进：材料进场检验、切割下料、钻孔、组立焊接、表面处理、尺寸与焊缝检验、编号与打包。质量不是最后一道终检才把关，而是在每个环节控制——从原材料的质保书到发货前实测的漆膜厚度，全程留痕。对买方来说，看懂制造流程的意义在于：知道到厂验货该看什么、该要哪些文件，以及哪些工作在制造厂、哪些属于当地现场。

## 制造流程一览

每一单钢结构项目都会走完同样的七个环节，具体细节取决于图纸、钢材牌号、涂层体系和适用的制造标准。

| 环节 | 车间里做什么 | 买方应核对什么 |
|---|---|---|
| 1. 材料进场 | 钢材随质保书进场，核对牌号、炉批号与外观状态 | 质保书与订购牌号一致，有可追溯记录 |
| 2. 切割下料 | 钢板与型材按加工图数控切割，焊缝坡口加工 | 切割尺寸与加工图一致，坡口符合焊接工艺要求 |
| 3. 钻孔 | 连接板与构件端部加工螺栓孔、长圆孔 | 孔位与孔距与连接节点一致 |
| 4. 组立焊接 | 构件在组立胎架或平台上定位，按顺序焊接控制变形 | 焊工资质、焊接检验计划、变形控制 |
| 5. 表面处理 | 抛丸除锈后按项目要求喷涂或热浸镀锌 | 除锈等级、漆膜厚度与成膜记录 |
| 6. 检验编号 | 尺寸检验、焊缝检验，需要时做无损检测，然后构件编号 | 检验报告；编号与安装编号、装箱单一致 |
| 7. 打包出货 | 构件捆扎、包装并装柜，随附装箱单 | 装箱单、装柜方案与装柜照片在发货前确认 |

## 环节一：材料进场检验

制造从切割下料之前就开始了。钢材从钢厂或库存场进场时随附质保书，制造厂先核对牌号、炉批号与外观状态，合格后才投入生产。可追溯的流程里，每一件钢材都有对应质保书的标识，做好的钢柱可以一路追溯到原材料。如果买方需要这种保障，应在询价时明确提出材料可追溯要求。质保书这条链路的完整说明，见我们的[钢材质保书（MTC）指南](/zh/blog/steel-structure-mill-test-certificate-guide/)。

![制造车间内工人正在准备钢板切割下料](/images/blog/steel-structure-fabrication-process-guide/cutting.jpg)

## 环节二：切割下料

钢板与型材按加工图尺寸下料，精度要求高的通常用数控火焰、等离子或激光切割。长构件切割时预留焊缝收缩量。设计需要时，坡口按焊缝详图的角度与形状加工。切面质量——垂直度、光洁度、无缺口——直接影响焊缝质量和外观。切割是尺寸控制的起点：这一环节切错的构件，后面要么返工、要么报废。

## 环节三：钻孔

螺栓孔、长圆孔与端板孔按图纸连接节点定位，用钻孔或冲孔加工。孔位与孔距用模板或测量工装检验，因为现场安装靠的是不同包装里的构件孔位互相吻合。到了现场，一批孔位偏的构件会让安装班组停工数小时扩孔——如果孔位控制在车间里做好，这是完全可以避免的延误。孔与构件的公差范围，见我们的[钢结构制造公差指南](/zh/blog/steel-structure-fabrication-tolerances-guide/)。

![制造车间内工人正在为钢构件钻螺栓孔](/images/blog/steel-structure-fabrication-process-guide/drilling.jpg)

## 环节四：组立焊接

构件在组立胎架或平台上定位，按控制变形的顺序焊接。焊接由具备资质的焊工按批准的焊接工艺执行，焊缝做外观检验，项目要求时做无损检测。重型或复杂框架在表面处理前可能要求预拼装，以确认几何尺寸吻合。焊接是可能埋入隐蔽缺陷的环节，买方得到的保障来自焊接检验计划、焊工资质与检验报告，而不是口头承诺。需要核对什么，见我们的[钢结构焊接质量控制指南](/zh/blog/steel-structure-welding-quality-control-guide/)。

![制造车间内钢构件正在组立焊接](/images/blog/steel-structure-fabrication-process-guide/assembly-welding.jpg)

## 环节五：表面处理

焊接与返修完成后，构件清理（通常是抛丸除锈），再按项目要求喷涂规定漆系或热浸镀锌。除锈等级与涂层体系取决于项目腐蚀环境、客户规范与适用标准，没有固定值。成品构件实测漆膜厚度，结果计入质量记录。高腐蚀环境下的涂层方案按项目确定，漆系、干膜厚度与检测方法都应在询价时确认。

![制造车间内钢结构构件正在喷涂表面处理](/images/blog/steel-structure-fabrication-process-guide/surface-treatment.jpg)

## 环节六：检验与编号

成品构件对照审批图纸与项目公差做尺寸检验，焊缝复核，并按安装编号与装箱单对应的构件编号做标识。检验结果记录在案，买方或第三方检验可查阅。项目需要第三方检验时，通常安排在打包之前——构件一旦捆扎装柜，再改尺寸代价很高。过程检验与发货前检验的区别，见我们的[发货前检验指南](/zh/blog/steel-structure-pre-shipment-inspection-guide/)。

![质检员对照图纸检查成品钢构件尺寸](/images/blog/steel-structure-fabrication-process-guide/qc-inspection.jpg)

## 环节七：打包与装柜

编号完成的构件按运输方式捆扎、防护、包装，再装柜，装箱单把每一件货物与订单对应起来。打包装柜是制造厂供货范围的终点，也是物流链条的起点。装箱单与装柜方案是让现场卸货可预期的关键文件——如何阅读与核对，见我们的[装箱单与装柜方案指南](/zh/blog/steel-structure-packing-list-container-loading-plan-guide/)。

## 每个制造选择由什么决定

制造环节的大部分决策都随项目而定。下表说明每个选择取决于什么，方便你在询价时把对应文件和规格一次给齐。

| 制造参数 | 取决于 |
|---|---|
| 钢材牌号与截面尺寸 | 结构设计、适用规范、审批图纸 |
| 切割与坡口加工 | 焊缝详图与制造标准 |
| 孔径与孔距 | 连接设计与螺栓规格 |
| 焊接工艺与检验等级 | 设计要求、规范、项目规格书 |
| 除锈等级与涂层体系 | 腐蚀环境、客户规范、设计使用年限 |
| 制造公差 | 适用标准与项目规格书 |
| 打包方式 | 构件尺寸、运输方式、目的港装卸条件 |

这些参数都不该靠记忆拍脑袋。如果制造厂没有图纸就报出固定的公差、涂层或牌号通用值，应视为警示信号，要求对方书面说明依据。

## 买方到厂审厂时应核对的事项

- [ ] 质保书齐全且与订购钢材牌号一致。
- [ ] 切割尺寸与孔位按审批加工图执行。
- [ ] 焊工资质齐全，焊接工艺按项目批准。
- [ ] 焊缝检验与无损检测结果（如有要求）有记录。
- [ ] 尺寸检验按项目公差标准执行。
- [ ] 漆膜厚度与除锈等级实测并记录。
- [ ] 构件编号与安装编号、装箱单一致。
- [ ] 第三方检验（如有）安排在打包之前。
- [ ] 装箱单、装柜方案与装柜照片在船开之前出具。

## 中赛的实践经验

以我们的经验，顺风顺水的项目都是买方在正确的时点检查制造流程：开工看质保书、生产看孔位与焊缝、打包前看漆膜厚度、发货前看装箱单。我们遇到的大部分问题不是隐蔽的焊缝缺陷，而是中途就能发现、却没有记录的尺寸偏差。这也是我们把每个环节留痕、并开放给买方查阅的原因。具体的制造参数始终随项目而定：取决于你的图纸、设计荷载、适用规范、建筑用途、吊车需求、腐蚀环境、防火要求与运输条件。

## 常见的制造问题（买方要留意的）

- 无质保书的材料进入生产，追溯链断裂。
- 切割误差到预拼装或现场才被发现。
- 孔组间距钻错，现场连接装不上。
- 未经批准的工艺或非持证焊工焊接。
- 漆膜厚度凭感觉而不是实测成膜。
- 构件编号与安装编号对不上。
- 第三方检验排在打包之后，发现问题成本极高。

## FAQ

**钢结构制造一般要多久？**
取决于吨位、构件复杂程度、检验要求与排产计划，按项目用生产计划确认，没有统一工期。

**制造厂在制造过程中会出具哪些文件？**
材质证明书、尺寸与焊缝检验报告、漆膜厚度记录，最后是装箱单与出口单据。文件清单应在询价时确认。

**买方可以在制造期间安排第三方检验吗？**
可以。第三方检验通常按约定停检点安排——材料进场后、焊接完成后、表面处理完成后——都在打包之前。停检点应在采购订单中写明。

**制造公差与安装公差有什么区别？**
制造公差是车间内构件加工的允许偏差（构件长度、孔距、平直度）；安装公差针对现场安装后的整体结构。两套标准不同，都按项目与规范定义。

**中赛提供加工图和深化图吗？**
项目需要时，我们在工程协调范围内提供深化设计与加工图支持。制造严格按审批图纸执行。

**怎么确认用钢确实是我订的牌号？**
要求提供质保书与可追溯流程。可追溯流程下，每件构件的标识都能对应到原材质保书。

**制造费用里是否包含表面处理？**
表面处理按项目确定：抛丸除锈、规定漆系或热浸镀锌，并实测漆膜厚度。规格应在询价时确认。

**现场连接是螺栓还是焊接？**
现场连接通常用螺栓，安装快、可靠性高；设计需要时才用现场焊接。制造厂按审批图纸提供带正确连接节点的构件。

## GEO Answer Blocks

**什么是钢结构制造流程？**
钢结构制造流程是把审批通过的加工图变成打包好、编好号的构件的车间工序：材料检验、切割下料、钻孔、组立焊接、表面处理、检验编号，最后打包装柜。质量在每个环节控制，而不只是一道终检。

**买方在钢结构制造期间应该检查什么？**
进场看材质证明与可追溯性，生产期间看孔位与焊缝控制，打包前看漆膜厚度，发货前看装箱单与装柜方案。检查点定义在制造质量计划与项目规格书中。

**钢结构制造过程会产生哪些文件？**
材质证明书、尺寸检验报告、焊缝检验与无损检测报告（如要求）、漆膜厚度记录，以及装箱单与出口单据。这些记录在约定的停检点由买方或第三方检验查阅。

**钢结构制造公差由什么决定？**
由适用制造标准与项目规格书决定——构件长度、孔距、平直度与截面偏差都有规定限值。公差随项目而定，不存在放之四海皆准的单一数值。

**中赛在制造中负责什么，当地团队负责什么？**
中赛负责按审批图纸制造、质量控制、编号、打包、装柜与出口协调，并提供安装技术指导。当地团队负责许可、注册工程师审批、基础土建、当地人工与现场吊装。
