电动车充电站的钢结构雨棚，不是把车棚放大一号。它是围绕充电桩布局、车辆动线、净高、线缆管理、风吸力、排水和当地报建条件设计出来的结构。跨度只是其中一个输入。真正决定用钢量的，是一个雨棚下压几个车位、直流柜放在棚下还是棚外、什么车辆要从棚下通过，以及这个轻而通透的棚子在风里怎么受力。

这篇写给开发商、充电运营商、商场业主和总包。

## 第一部分：雨棚到底要承载什么

| 项目 | 是否由雨棚承载 | 设计影响 |
|---|---|---|
| 棚面与檩条 | 是 | 恒载叠加风吸力 |
| 充电桩立柱 | 有时 | 点荷载与防撞保护 |
| 直流功率柜 | 有时 | 较重点荷载、散热与检修通道 |
| 桥架与线管 | 是 | 棚下布线空间 |
| 照明与监控 | 是 | 固定点与检修可达性 |
| 标识与导视 | 是 | 受风面积与固定节点 |
| 光伏组件 | 可选 | 增加恒载、对风吸更敏感 |
| 消防探测或灭火设施 | 可选 | 与当地消防部门配合 |

这些内容要在设计初期定下来。等雨棚只按“一个棚面”设计完，再回头加柜体或光伏，代价很高。

## 第二部分：车位模块与动线

| 布局 | 适合场景 | 优点 | 限制 |
|---|---|---|---|
| 倒车入库、每排一个雨棚 | 商场与写字楼停车场 | 沿用现有停车模块 | 线缆长度与车位宽度偏紧 |
| 直进直出 | 高速服务区与车队场站 | 不用倒车、周转快 | 雨棚更长、行车通道更宽 |
| 单侧悬挑雨棚 | 场地狭窄 | 立柱在车位外侧 | 基础弯矩更大 |
| 中柱双悬挑雨棚 | 大型场站 | 每车位用钢更省 | 中柱把两侧行进方向分开 |
| 雨棚覆盖充电位加等候车道 | 高流量商业 | 排队不占主通道 | 棚面与排水面积增加 |

车位模块应按车辆尺寸和充电枪线长度确定，而不是照搬别的项目的标准停车柱网。

## 第三部分：净高与车辆构成

净高取决于要从棚下通过的最高车辆：

- **乘用车**：最常见，但棚顶设备与标识仍会吃掉净高。
- **厢式车与轻商用车**：更高，而它们往往才是快充的真实用户。
- **大巴与货车**：需要更高净高、更长车位和不同的结构形式。
- **棚顶设备**：充电桩、收线器、照明都会占用净空。

净高要和运营商确认，不能照抄数字。它也是加工完成后最难改的一项。

## 第四部分：结构形式

| 形式 | 适合 | 说明 |
|---|---|---|
| 单坡悬挑 | 狭窄场地、贴建筑侧棚 | 立柱在车位外，柱脚弯矩大 |
| 双坡门式雨棚 | 两排车位 | 对称、省钢、两侧排水方便 |
| T 形双悬挑 | 中柱一排、四排车位 | 柱少，单柱用钢多 |
| 四柱独立雨棚 | 小型场地、一两个车位 | 简单，但停车区内柱子多 |
| 依附既有建筑的雨棚 | 扩建与沿街商业 | 必须复核既有结构的承载与风吸 |

依附既有建筑是风险最高的做法：原结构从来没有按雨棚的荷载和风吸力设计过。

## 第五部分：决定用钢量的荷载

轻而通透的雨棚，控制工况往往是风，而不是自重。

- **风吸力**：开敞棚面像机翼，上吸力可能大于向下荷载。
- **标识与光伏的受风**：增加受风面积和偏心荷载。
- **雪与冰**：取决于当地气候与棚面几何，边缘积雪漂移常见。
- **地震**：取决于场地与当地规范，轻棚同样需要锚固。
- **车辆撞击**：防撞柱是结构件，不是装饰件。
- **温度变形**：长雨棚需要伸缩构造。

以上每项都必须来自项目所在地与当地规范。为一个市场设计的雨棚，不能不做复核就搬到另一个市场。

## 第六部分：基础与锚固

| 部位 | 由什么决定 |
|---|---|
| 柱底板尺寸 | 柱荷载、上拔力、锚栓布置 |
| 锚栓 | 上拔与剪力，不只是压力 |
| 基础埋深 | 当地土质、冻深、地下水位 |
| 灌浆与垫板 | 安装公差与荷载传递 |
| 防撞柱 | 充电设备与立柱的车辆撞击保护 |
| 地面做法 | 排水坡度与设备周边防滑 |

最常被漏掉的就是上拔力。只按向下荷载设计的基础，在强风里托不住棚面。

## 第七部分：排水与防水

- 天沟与落水管必须把水排离充电桩、柜体与人员通行区。
- 滴水线不能落在充电设备或客户操作区上方。
- 长雨棚要预留伸缩缝，并保证坡度连续。
- 沿海场地要选适配环境的防腐体系，包括切口与紧固件。
- 棚面检修通道要设计出来，而不是现场拿梯子凑。

水电设备处在同一片场地上，是整个运营期都要面对的维护问题。

## 第八部分：与电气的配合

雨棚是结构包，但它会约束电气设计：

- **柜体位置**：棚下、独立柜房，还是远处。
- **线缆走向**：桥架、线管与牵引点需要空间与检修通道。
- **接地与等电位**：结构钢可能参与，由当地电气工程师决定。
- **散热与通风**：直流柜需要风道，闷在棚下的封闭角落是坏位置。
- **检修通道**：柜门打开不能挡住正在使用的车位。
- **隔离开关与急停**：位置须与运营商确认。

电气设计属于当地范围，雨棚要设计成能接受它。

## 第九部分：消防与场地安全

动力电池车辆火灾与燃油车火灾特性不同，当地消防部门对充电场站的要求也据此制定。结构上通常涉及：

- 充电车位与相邻建筑、储存区的防火间距。
- 疏散与通行路线不被立柱和防撞柱阻断。
- 排水不在设备所在位置积水。
- 按当地要求配合探测、报警与灭火设施。
- 标识与应急信息的位置。

具体要求来自当地主管部门与保险公司，不来自通用指南。

## 第十部分：报建与责任分界

| 事项 | 出口供应方 | 当地 |
|---|---|---|
| 雨棚结构设计与深化 | 工程协调与加工图 | 当地注册工程师复核并签章 |
| 加工与质量控制 | 是 | — |
| 编号、包装、装柜 | 是 | 接货与内陆运输 |
| 基础与锚栓设计 | 提供接口荷载与柱底板详图 | 当地土建与结构设计 |
| 电气设计与接线 | 不涉及 | 当地持证电气承包商 |
| 报建与送审 | 按需提供支撑文件 | 业主与当地工程师 |
| 安装 | 技术指导 | 当地安装队伍与吊车 |
| 充电桩供货与调试 | 除另行约定外不涉及 | 运营商与桩企 |

## 第十一部分：订钢前的清单

- [ ] 车位布局与动线已与运营商确认。
- [ ] 净高已按车辆构成（含厢式车）定下。
- [ ] 充电桩与柜体位置已标注，含重量与检修通道。
- [ ] 线缆走向与桥架路径已与电气设计方对齐。
- [ ] 雨棚形式已选定，立柱位置已对照停车复核。
- [ ] 场地风、雪、地震参数已取得。
- [ ] 已按开敞棚面复核风吸力。
- [ ] 基础与锚栓设计已在当地委托。
- [ ] 排水出口位置已确认。
- [ ] 已按场地环境选定防腐体系。
- [ ] 防撞柱与撞击保护已定位。
- [ ] 消防策略与防火间距已在当地复核。
- [ ] 报建路径与验收节点已明确。
- [ ] 安装方法与吊车进场条件已现场核实。

## 第十二部分：常见错误

| 错误 | 后果 |
|---|---|
| 把充电雨棚当车棚做 | 风吸与锚固设计不足 |
| 净高先定死再看车辆构成 | 返工重做或使用受限 |
| 设计冻结后再加柜体与光伏 | 雨棚超载、排水改变 |
| 忽略线缆走向 | 现场电气返工 |
| 基础只按向下荷载设计 | 大风时锚栓失效 |
| 立柱落在车位内 | 车辆撞结构、车位不可用 |
| 排水直接排到充电桩上方 | 长期潮湿与电气风险 |
| 当地工程师未复核荷载就下单 | 加工后改设计 |

## 第十三部分：常见问题

**问：普通车棚能直接改成充电雨棚吗？**
答：通常不能不做复核就用。充电雨棚要承载充电桩、柜体、桥架与标识，并作为开敞结构抵抗风吸力；只按棚面荷载设计的车棚，一般不足以覆盖这些工况。

**问：充电雨棚要做多高？**
答：净高取决于要从棚下通过的最高车辆，再加上棚顶设备与标识占用的空间。由运营商与当地设计方确认，不能照搬标准停车尺寸。

**问：直流柜必须放在雨棚下面吗？**
答：不一定。柜体可以放棚下、独立柜房或远处，但每种选择都会改变点荷载、散热、检修与布线。这个决定属于电气设计方与运营商。

**问：充电雨棚最大的结构风险是什么？**
答：轻质开敞棚面的风吸力。雨棚受风面积大、恒载小，锚固与基础必须按上拔力设计，而不只是按钢自重。

**问：雨棚上能加光伏吗？**
答：如果从设计开始就把附加恒载、风吸敏感性、布线与检修通道考虑进去，可以。既有雨棚加光伏则需要当地工程师做结构复核。

**问：基础由谁设计？**
答：由当地土建或结构工程师，依据雨棚设计方提供的柱底荷载、锚栓布置与场地土质完成。基础设计通常属于当地范围，不属于出口范围。

**问：从出图到交货要多久？**
答：取决于设计确认、深化、材料、加工排期、涂装、运输与当地基础施工。工期应从场站的通电目标日期倒排。

## 第十四部分：给布局，不要只给跨度

充电雨棚要靠布局、车辆构成、设备位置与场地荷载来确定，而不是一个跨度数字。把车位平面、充电桩与柜体清单、车辆类型、场地位置与当地设计参数一起发过来，在订钢之前就能把结构方案比清楚。
