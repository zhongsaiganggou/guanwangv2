凡在马来西亚承接施工的企业，除 Act 520（2011 年修正）第 40(1) 条豁免情形外，都必须依第 25 条向 CIDB 注册。注册挂在**做施工的那家公司**名下，限定类别、限定合同额上限。它不说明你的钢材是否合规——那是产品与制造商的另一件事。境外钢构厂不能把自己的证书借给当地安装方，安装方的注册也不能替进口钢材背书。

所以进口钢构项目其实有三项并行核查：谁能装、构件要符合什么、项目还要哪些审批。把三者压成一句“CIDB 证书”，通常会等到吊车进场才发现缺口。

## 第一部分：三件常被当成一件的事

| 核查项 | 谁持有 | 证明什么 | 不能做什么 |
|---|---|---|---|
| 承包商注册 | 实际施工的公司 | 持证人可在指定类别内承接施工，合同额不超过其等级上限 | 不认证钢材、屋面板或节点 |
| 产品合规与认证 | 制造商与产品 | 构件符合 MS 或马来西亚认可的其它标准（如需认证则须认证） | 不给任何人施工资格 |
| 项目审批 | 业主与其注册专业人员 | 设计与施工获主管部门批准 | 不核验上面两项 |

招标文件只写“要 CIDB 认证”而不指明是哪一项时，通常指的是第一项——但被要求出文件的那一方，往往找错了。

## 第二部分：承包商注册到底授权了什么

注册不是一张“什么都能干”的牌照。注册条件写得很清楚：

- 不得承接**超过其注册等级所允许的工程价值**的项目。
- 不得承接**注册类别以外**的工程。
- 证书**不可转让**。
- 证书到期后，在完成续期之前**不得投标或继续施工**。
- 必须在每个工地招牌上显示注册号。

两条现实推论：第一，只能做小工程的承包商，不会因为“以前装过钢构”就有资格装你的项目；第二，一个集团里持有注册的那个实体，不能把合同转给未注册的关联公司。

## 第三部分：本地承包商与外国承包商，注册方式不同

| | 本地承包商（PPK） | 外国承包商 |
|---|---|---|
| 范围 | 按类别与等级，可续期 | 仅限证书上载明的那个项目 |
| 有效期 | 至证书到期，需续期 | 至证书载明的项目完工日 |
| 投标 | 可在自身类别与等级内投标 | 不得凭此证书投标其它工程 |
| 延期 | 走续期流程 | 须在期限结束前提出申请并附证明文件 |
| 工地招牌 | 须显示注册号 | 须显示注册号 |

进口项目最常踩的坑在这里：供应商想派自己的安装队，但国内资质在马来西亚不生效。马方需要注册承包商；即使办了外国承包商注册，那张证书也只绑这一个项目。

## 第四部分：注册带来的义务，买方可以据此要求

- 中标后 **14 天内**向 CIDB 报送该工程信息。
- 任命**经 CIDB 认证**的技术工人与工地主管。
- 确保所有现场工人持有**有效的建筑人员卡**。
- 确保使用的产品与材料符合 **MS 或马来西亚认可的其它标准**，需要认证的须经认证。
- 在营业场所展示注册证书，在工地展示注册号。
- 遵守其等级与类别附带的各项条件。

第四条是进口钢材真正被检验的地方。承包商对“使用合规、已认证产品”负责，这意味着买方的技术规格与供应商的文件，必须在第一颗螺栓施拧之前就对得上。

## 第五部分：钢构厂在这套框架里站哪

加工厂的职责是提供证据，不是提供注册。

| 供应商提供 | 供应商不提供 |
|---|---|
| 材质证明与实发构件的可追溯性 | 承包商注册 |
| 焊接与涂层检验记录 | 现场施工资格 |
| 规范引用的产品检测报告 | 项目审批 |
| 安装图、标记方案、节点做法 | 人员卡或安装工资格 |
| 安装技术指导 | 当地熟练工 |

如果招标文件要求“钢材供应商持有 CIDB 承包商注册”，那是要求找错了对象。正确的做法是指明实际施工的注册承包商，并把供应商的文件包附在后面。

## 第六部分：授标安装合同前要核的十项

- [ ] 承包商证书在有效期内，未过期、未被吊销或暂停。
- [ ] 注册**类别**覆盖钢结构安装，而不只是普通土建。
- [ ] 注册**等级的合同额上限**高于本合同金额。
- [ ] 证书持有人与签约、开票主体是同一家公司。
- [ ] 外国承包商的证书明确写了本项目的名称。
- [ ] 承包商确认会在中标后 14 天内向 CIDB 报送。
- [ ] 施工方案中列名的工地主管与技术工人持有有效认证。
- [ ] 承包商承担全部现场工人的建筑人员卡责任。
- [ ] 承包商说明将如何核验进口构件符合指定标准。
- [ ] 供应商的文件包在进场之前、而非之后交到承包商手里。

## 第七部分：向各方索要哪些文件

| 文件 | 向谁要 | 用途 |
|---|---|---|
| 承包商注册证书（含类别与等级） | 安装承包商 | 确认施工资格与合同额上限 |
| 与签约主体一致的公司注册资料 | 安装承包商 | 防止把合同签给未注册的关联公司 |
| 主管与技术工人的认证记录 | 安装承包商 | 注册条件要求 |
| 施工方案与安装顺序 | 安装承包商 | 说明构件如何吊装与临时支撑 |
| 材质证明与检测报告 | 钢构供应商 | 支撑承包商的产品合规义务 |
| 标记方案与安装图 | 钢构供应商 | 把每件实发构件对应回设计 |
| 安装指导与节点做法 | 钢构供应商 | 减少现场返工与争议 |

## 第八部分：常见错误

| 错误 | 现场长什么样 | 后果 |
|---|---|---|
| 把产品证书当施工资格 | 供应商证书被当成“CIDB 批文”归档 | 没等合规承包商到位就开工 |
| 授标超出承包商等级 | 合同额高于注册上限 | 违反注册条件 |
| 用关联公司签约 | 证书在另一家公司名下 | 合同与注册对不上 |
| 外国队伍用本国资质施工 | 该项目没有马来西亚注册 | 被叫停，进场成本打水漂 |
| 没有人员卡 | 现场工人无有效卡 | 检查不合格 |
| 进口钢材无追溯 | 证书与实发构件对不上 | 无法证明产品合规 |

## 第九部分：进口项目的责任分界

| 事项 | 出口供应方 | 马方 |
|---|---|---|
| 设计配合与深化 | 是 | 确认设计依据并批准 |
| 加工、质控、标记、包装、装柜 | 是 | 可派员见证或审厂 |
| 出口协调与海运单证 | 是 | 负责清关与内陆运输 |
| 承包商注册与现场临建 | 否 | 注册承包商 |
| 熟练用工、安装、临时支撑 | 仅技术指导 | 注册承包商及其认证人员 |
| 产品合规证据 | 材质与检测记录 | 承包商确认符合指定标准 |
| 项目审批与报建 | 按需提供支撑文件 | 业主及其注册专业人员 |

## 第十部分：常见问题

**问：钢构厂要把钢材卖到马来西亚，需要 CIDB 承包商注册吗？**
答：不需要。注册是针对在马来西亚承接施工的一方。供应商的义务是提供符合指定标准的构件与文件，注册由安装承包商持有。

**问：能不能用供应商的证书满足承包商要求？**
答：不能。证书不可转让，且绑定注册主体、类别与等级。供应商的产品证书与承包商注册是两种不同的文件。

**问：合同额超过承包商等级会怎样？**
答：承包商不得承接超过其注册等级所允许价值的工程，等于违反注册条件。要么拆分范围，要么换一家等级覆盖合同额的承包商。

**问：外国承包商能在马来西亚装我的厂房吗？**
答：只能凭与该项目绑定的外国承包商注册。该证书不允许投标或承接其它工程，延期必须在期限结束前提出申请。

**问：进口钢材是否符合马来西亚标准，由谁负责核？**
答：注册承包商须确保产品与材料基于 MS 或其它认可标准、需要认证的已获认证。实际执行中，供应商的材质证明、检测报告与检验记录就是承包商依赖的证据。

**问：承包商要把项目报给 CIDB 吗？**
答：要。中标后 14 天内须报送该工程信息，这是注册条件之一。

**问：承包商注册和项目的 IBS 分数是一回事吗？**
答：不是。注册授权公司施工；IBS 分数衡量设计有多大比例通过预制方式完成。同一项目可能两者都涉及，但互不替代。

## 第十一部分：看持有人，不看信头

授标安装之前，先要证书、看类别与等级、把主体名称与将要签约的公司对上。然后把供应商的文件包交给这家承包商，让产品合规义务落在真实记录上，而不是一句承诺。
