棕榈油厂钢结构是从工艺设备清单反推的，不是拿仓库图纸改尺寸。杀菌笼、脱果机、消化与压榨工位、锅炉房、仁壳筒仓与废水区，先定下荷载、振动、腐蚀等级与检修空间；产能、设备厂图纸、当地规范、场地与运输条件，才决定柱距、断面与分段。没有放之四海皆准的油厂钢构。

## 第一部分：钢结构包包含什么

图纸上是一栋厂房，实际是一组职责不同的结构。范围没划清，是现场返工最常见的起点。

- 主厂房框架：柱、梁、檩条与围护。
- 杀菌与脱果区：重框架、局部加强，检修用单轨吊或吊梁。
- 锅炉房与烟囱支承，自锅炉厂供货范围结束处起。
- 仁壳筒仓钢支架（筒仓坐在钢腿上时）。
- 平台、通道、楼梯、栏杆与屋面检修通道。
- 设备厂不供的支承钢：风机底座、管架、溜槽支架。
- 吊梁、单轨与检修开孔，须在吊装前就存在。

不在包内：工艺设备本体、管道保温、电气仪表、锅炉受压件、全部土建。这些接口必须写进报价，没报价的接口最后都变成争议。

## 第二部分：深化前必须拿到的数据

只有平面草图无法深化。下列输入决定框架能否定尺寸，每项都有明确的提供方。

| 输入 | 提供方 | 缺了为什么定不了 |
|---|---|---|
| 产能与工艺流程 | 业主 / 工艺设计 | 决定设备数量、工位尺寸与平台范围 |
| 含标高的设备布置 | 工艺设计 | 决定柱位、坑位与净高 |
| 主要设备重量、重心与支点 | 设备厂 | 决定局部荷载、底座与支承钢 |
| 动载：脱果机、消化罐、压榨、筛分 | 设备厂 | 决定隔振与框架加强 |
| 杀菌笼行程与抽出空间 | 设备厂 / 业主 | 决定开间净宽与单轨位置 |
| 锅炉与烟囱接口 | 锅炉厂 | 决定供货分界与传给钢构的荷载 |
| 蒸汽与凝结水温度 | 工艺设计 | 决定热位移与接口构造 |
| 腐蚀环境与冲洗习惯 | 业主 | 决定涂装体系与构造 |
| 当地风、地震与规范 | 当地注册工程师 | 决定设计基准，不能取默认值 |
| 场地、运输与吊装条件 | 业主 / 施工方 | 决定模块尺寸与吊装顺序 |

动载数据若晚于制作，框架等于现场重新设计：让节点松动的脱果机，同样会让设备对中走掉。

## 第三部分：不只是屋面加风荷载

框架同时承担几类荷载，峰值又不在同一时刻。这就是照抄仓库门式刚架行不通的原因。

| 荷载 | 来源 | 对钢构的影响 |
|---|---|---|
| 设备恒载 | 杀菌罐、脱果机、压榨、储罐、锅炉 | 局部柱荷载、底座尺寸、支承钢 |
| 动载与振动 | 脱果机、消化罐、压榨、筛分、风机 | 加强、节点构造、隔振、连接疲劳 |
| 温度作用 | 蒸汽管、热设备 | 膨胀余量、接口间隙、不可刚性包死 |
| 湿度与凝结水 | 蒸汽、冲洗、热带气候 | 腐蚀等级、排水构造、避免积水 |
| 检修荷载 | 抽笼、换转子、单轨起吊 | 开间净宽、吊梁能力、临时支撑 |
| 风荷载 | 当地风资料 | 支撑、屋面固定、围护约束 |
| 地震作用 | 当地规范 | 框架延性与连接设计 |
| 施工荷载 | 模块重量、吊车站位 | 吊装方案与临时工程 |

错误做法是加成一个「重型」数字再全部加重；正确做法是把荷载放在它发生的位置：脱果开间加强、振动设备隔振、仓库型开间保持经济。

## 第四部分：哪个区域用哪种形式

没有一种框架能覆盖整座油厂，多数是混合结构，组合应在投标前定下。

| 形式 | 适合 | 优点 | 限制 |
|---|---|---|---|
| 门式刚架 + 局部重构件 | 主厂房、打包成品区 | 深化快、吊装快、单吨造价低 | 局部动载需另加强 |
| 支撑式重框架 + 独立设备基础 | 杀菌与脱果区 | 控制振动与抽笼净空 | 加工工时多、公差更紧 |
| 独立钢塔或支承框架 | 仁壳筒仓、烟囱、部分储罐 | 工艺荷载不进主厂房框架 | 多一套基础与接口 |
| 轻型屋面敞开钢构 | 锅炉房、废水与公用区 | 通风、检修方便、围护成本低 | 防雨与腐蚀暴露 |
| 螺栓连接模块化框架 | 偏远场地、分期扩建 | 适箱运输、现场装配快 | 接头多，对位密封量大 |

两条规则写死：振动设备放在自己的加强子框架上，只在设计打算连接处与主框架相连；筒仓与烟囱不挂在按风荷载设计的屋面框架上。

## 第五部分：腐蚀是设计输入

油厂又湿、又热、又带蒸汽：冷钢材结凝结水，冲洗水积在凹槽，蒸汽管接头常在有人修之前就已渗漏，涂装与构造属于设计阶段。

- 构造排水：不留平底凹槽、不做存水封闭箱体、不留不通风空腔。
- 杀菌区、锅炉房、废水区按比打包区更严的腐蚀等级处理。
- 封闭截面内侧、围护背板等易凝结部位要保护。
- 体系按实际暴露与业主维护能力选，不能照默认规格。
- 热表面与蒸汽管位置，体系按该处温度选型。
- 想清楚补涂通道：修不了的涂层会安静失效。

涂层类型、道数与干膜厚度取决于腐蚀等级、当地大气与维护计划，把别的项目整套规格照搬不是设计决策。

## 第六部分：决定油厂能不能跑起来的接口

油厂问题多数在接口，而非构件中间。

- 抽杀菌笼：钢构布置必须留净空，含单轨与检修临时平台。
- 换脱果机转子：检修开孔、吊梁与净高在设计阶段定，不能等停机再谈。
- 锅炉房分界：锅炉厂供受压件，钢构供支承框架与烟囱支架，写进合同。
- 仁壳筒仓出料：支架、溜槽支架与平台要对上设备厂连接点。
- 废水与公用区：敞开结构、耐腐蚀构造、检修车通行。
- 屋面排水：热带暴雨下，天沟与落水管属于结构布置，不是收尾。

## 第七部分：地坪、坑池与基础不是钢构

设备基础、坑池、地坪与周边土建属于当地范围，钢构必须按实际做出来的尺寸深化。

- 锚栓位置与标高，放行制作前必须实测。
- 坑边、沟槽与排水坡度影响柱脚与平台框架。
- 钢构支承振动设备时，基础质量与连接构造是一套；改一个就牵动另一个。
- 筒仓或烟囱下的不均匀沉降，表现为出料口对不上，不是框架开裂。

谁承担土建，谁就要在深化冻结前确认实测值，否则第一个对中问题会在调试阶段出现。

## 第八部分：在老厂旁边吊装

多数项目是扩建：新线立在运行中的油厂旁边，吊装方案彻底不同。

- 模块尺寸受吊车在该幅度起重能力限制，不只是集装箱。
- 带压蒸汽管或运行锅炉旁动火，进场前谈好动火许可制度。
- 临时支撑保留到开间闭合、设备底座连接完成。
- 吊车通道与设备厂进场通道互相占位，排进同一份计划。
- 到货顺序跟吊装顺序：先框架，后围护与平台。

## 第九部分：工艺厂钢构的打包与海运

工艺厂钢构不是仓库套件，装箱单必须反映这点。

- 按与吊装图一致的件号标记，按区域打包而非按构件类型。
- 加强的设备子框架要一眼可辨，混装成捆就是现场延误。
- 保护机加工面与螺栓摩擦面，连接组件与散板分开。
- 模块长度在深化前核对集装箱或散货船限制。
- 锚栓、柱底板与垫板作为受控组件，随柱表发运。

## 第十部分：责任分界

| 范围 | 中赛（钢结构包） | 当地方 |
|---|---|---|
| 工程协调与深化 | 钢框架、平台、支承钢、连接节点 | 工艺设计、设备选型、当地规范确认 |
| 制作与质控 | 构件、焊接、涂装、尺寸检查 | 设备厂设备检验 |
| 标记、包装、装柜 | 件号、装箱单、装柜方案 | 卸货与现场堆存 |
| 出口协调 | 单证、发运协调 | 进口清关、当地运输 |
| 安装 | 技术指导、吊装图 | 当地劳务、吊车、监管、许可 |
| 基础与土建 | 接口数据与柱底板节点 | 设计、施工、测量、实测确认 |
| 报批 | 按要求提供设计资料 | 注册工程师、许可、报批 |

除合同另有约定，基础设计、安装劳务与报批属于当地范围。早说才能避免「钢构供应商顺带把油厂也供了」的默认假设。

- [ ] 腐蚀等级与冲洗习惯已确认。
- [ ] 当地风、地震与规范基准已确认。

## 第十二部分：常见错误

| 错误 | 后果 | 更好的做法 |
|---|---|---|
| 把油厂当大仓库 | 节点抖松，设备对中走掉 | 先划设备区，再局部加强 |
| 动载未到就深化 | 重新设计、现场返工 | 数据齐了再冻结框架 |
| 筒仓或烟囱挂在屋面框架 | 构件超载、检修受阻 | 独立支承、独立基础 |
| 全厂一套涂装规格 | 湿区早失效、干区过度 | 按暴露分区做涂装表 |
| 锚栓按图假设不实测 | 柱子立不上去 | 放行前实测确认 |
| 忽略抽笼与换件空间 | 设备没法检修 | 把检修包络画进布置 |
| 模块只按集装箱定尺寸 | 吊车在该幅度吊不动 | 运输与吊装同时约束 |

## 常见问答

**问：油厂钢构和普通工业厂房有什么不同？**
答：普通厂房由屋面、风荷载与偶发吊车荷载控制；油厂框架还要承担振动设备、热表面、蒸汽凝结水与抽笼检修，加强位置、节点构造与腐蚀等级都不同。

**问：报价前需要哪些资料？**
答：产能与流程、含标高的设备布置、主要设备重量与支点、动载、杀菌笼行程、锅炉接口、蒸汽温度、腐蚀环境、当地设计基准与运输限制；缺这些，报价只是暂估。

**问：设备基础由谁设计？**
答：通常由当地土建或结构工程师按设备厂数据设计，钢构包提供柱底板与接口荷载；两者须按同一份实测数据深化，否则调试时对不上。

**问：框架可以拆给几家做吗？**
答：可以，但接口就是风险：平台、单轨、支承钢与围护都挂在主框架上，拆开供最容易在关键位置产生公差冲突。

**问：杀菌区与锅炉房的腐蚀怎么处理？**
答：按比干燥区更严的腐蚀等级，构造排水而非存水，隐蔽面同样保护，涂层按表面温度选型。

**问：偏远场地适合螺栓模块化框架吗？**
答：通常适合，集装箱运输与现场装配更简单；代价是接头更多、对位密封量大。模块尺寸要同时对照集装箱与现场吊车。

## 把工艺数据发过来

设备清单、荷载与当地设计基准摆上桌面，框架才谈得上定尺寸。把工艺流程图、含标高的设备布置、设备厂数据表与实测场地条件发过来，范围、接口与不含项就能在制作前定清楚。
