吊车轨道的安装质量，由三个环节共同决定，而不是一个环节。吊车供应商定轨道型号、轨距和安装公差；钢构厂定吊车梁标高、牛腿位置和轨道底板做法；现场定吊车梁顶面的实测标高、底板下的灌浆和最终的对中记录。这三方里只要有一方认为"那是别人的事"，结果就是吊车跑起来发顿、轨道焊缝开裂，或者轨道根本贴不平底板。下面把顺序、灌浆做法和必须签字确认的检查项讲清楚。

## 轨道这一套到底包含哪些件

把轨道按"每米多少钱"来询价的人，通常在安装阶段才发现少了一堆东西。

| 部件 | 作用 | 通常由谁提供 |
|---|---|---|
| 轨道型材 | 承受吊车轮压、引导车轮轮缘 | 吊车制造商（或其指定型号） |
| 轨道底板（垫板） | 把轮压扩散到吊车梁上翼缘，并提供可调的水平基面 | 钢构厂，按吊车供应商节点图加工 |
| 轨道压板/扣件 | 横向固定轨道，抵抗轨道纵向爬行 | 吊车制造商或轨道供应商 |
| 调整垫片 | 灌浆前把底板调到实测标高 | 现场安装队 |
| 灌浆料 | 填满底板与梁翼缘之间的空隙，使载荷全断面传递，而不是只落在垫片点上 | 现场，按指定型号 |
| 锚栓或焊接栓钉 | 把底板与吊车梁连接 | 钢构厂，按项目采用的[锚栓安装](/zh/blog/steel-structure-anchor-bolt-installation-guide/)做法 |
| 端部车挡 | 限制吊车行程 | 吊车制造商 |

这里有两套并存的通行做法，不能混用。一套是底板直接焊在吊车梁上翼缘、轨道再用压板压在底板上，没有灌浆，标高由加工控制；另一套是底板先垫片找平、对准吊车供应商的公差，再灌浆形成连续支承。用哪一套，是吊车供应商和当地工程师一起定的技术条件，不是加工厂凭习惯选。同一条轨道上，一部分底板焊、一部分底板灌浆，轨道线上必然出现台阶。

## 为什么底板下面要灌浆

只靠垫片接触的底板，本质上是一块"垫在几个点上的板"。轮压集中作用在离散点上，板在点与点之间受弯，吊车每过一次，连接就承受一次局部反复应力。灌浆改变的就是这件事：浆体填满空隙后，底板在整个面积上贴住梁翼缘，局部板弯曲下降、振动下降，轨道获得连续基面。

灌浆还买来了可调性。吊车梁按自己的加工公差制造、按另一个安装公差架设，长轨道上的顶面标高必然有起伏。先垫片、后灌浆，可以把底板调成一条共同线，再铺轨道；否则只能让轨道去迁就梁。

三种情况下，灌浆不是可选项：

- 吊车供应商安装手册明确要求底板灌浆，或规定了底板与梁之间的最大空隙；
- 轨道长度较长，梁的累积公差会超出轨道直线度公差；
- 吊车吨位大或工作级别高，局部板弯曲与连接疲劳不可忽视。

## 施工顺序：从吊车数据到签字记录

下面这个顺序是避免返工的顺序，每一步都产出下一步要用的记录。

1. **收集吊车供应商的轨道数据**：轨道型号、轨距（两条轨道中心距）、轮压、轨道固定节点、安装公差表、要求的底板节点。没有这些，吊车梁无法定稿；更完整的吊车参数清单及其对钢架的影响，见[吊车厂房设计指南](/zh/blog/overhead-crane-workshop-design-guide/)。
2. **在图纸上定死牛腿和梁标高**：牛腿标高决定轨顶标高，必须与吊车供应商的要求、轨道和底板厚度一起核对。
3. **按该标高加工吊车梁和底板**，包括锚栓/栓钉和压板焊接位置，并记录加工实测值，不能只写名义尺寸。
4. **架设吊车梁并实测上翼缘标高**：沿轨道按固定间距、在每个底板位置测量。这份实测数据是垫片的输入，必须在架设后测，不能照图纸假设。
5. **用垫片把底板调到要求标高和水平**，并检查底板与梁翼缘的间隙在灌浆料允许范围内。垫片要靠近锚固点布置，不能只垫四个角。
6. **支模、留排气孔**：浆体要有围挡，空气要有出路。没有排气孔，是底板中间出现空洞最常见的原因。
7. **按产品规定的稠度拌合并浇筑**，每块底板尽量一次连续浇完，从一侧推进，让浆体前沿把空气从排气孔赶出去。
8. **按产品要求养护到强度**。灌浆未达标前，不装轨道、不拧压板、不允许吊车行走。
9. **安装轨道、压板和车挡**，随后实测轨道线：轨距、直线度、标高、接头间隙，以及建筑伸缩缝处的轨道伸缩节点。
10. **把对中记录交给吊车供应商**做调试。吊车制造商通常会在试车前复核轨道，有这份记录，复核更快，也少了"是谁动过"的扯皮。

## 灌浆料怎么选、怎么浇

轨道底板下的灌浆料不是普通砂浆。它被指定为无收缩、自流平（可流淌）的灌浆料，有标定的抗压强度和标定的施工厚度范围，级别通常由吊车供应商或当地工程师指定。现场能控制的是决定这份材料成不成立的所有细节：

- **基面处理**：梁翼缘与底板底面必须干净、干燥、无油污、无松动氧化皮和浮锈。浆体只会粘结在它被浇筑的那个面上。
- **间隙控制**：每种灌浆料都有最小和最大施工厚度，超出范围不是灌不进去就是强度损失。正确的处理是改垫片，不是加水。
- **稠度**：自流平灌浆料按厂家水灰比计量拌合，不能凭手感。"为了好浇多加一点水"是浆体强度不足最常见的原因。
- **围挡与排气**：模板要挡住浆体压头，排气孔要留在底板最高点。
- **温度与养护**：浇筑时的环境温度、表面温度与养护方式按产品说明书执行。薄板暴晒加快速失水，会明显降低表层达到的强度。
- **记录**：产品名称、批号、配比、浇筑日期、环境温度、养护方式，与对中测量记录放在同一份竣工资料里。

## 对中验收：测什么、用什么测、谁签字

轨道对中不是一个数字，而是一组检查项，每一项的合格值都有出处。

| 检查项 | 控制什么 | 常用工具 | 合格值出处 |
|---|---|---|---|
| 轨距（两轨中心距） | 轮缘间隙与吊车行走 | 钢卷尺或标定过的轨距尺 | 吊车供应商安装手册 |
| 平面内直线度 | 吊车跑偏、轮缘接触、轨道侧磨 | 钢丝线或激光线 | 吊车供应商／当地规范 |
| 轨顶标高与水平度 | 桥架水平、两侧驱动载荷分配 | 水准仪或数字水平仪 | 吊车供应商／当地规范 |
| 接头间隙与错台 | 过缝冲击、焊接质量 | 塞尺＋靠尺 | 轨道供应商／吊车供应商 |
| 建筑伸缩缝处的轨道伸缩节点 | 温度变形不顶死、不拉断 | 按节点图做外观与尺寸核对 | 设计图与当地规范 |
| 压板贴合与紧固扭矩 | 轨道爬行与横向约束 | 扭矩扳手、外观检查 | 紧固件供应商数据 |
| 灌浆后底板贴合 | 全板面传力 | 敲击检查＋板边外观 | 技术条件／工程师指令 |

这张表比数字更重要的有两点。第一，合格值不是全球通用的：吊车供应商手册和当地规范可能对同一项给出不同限值，取严者。第二，测量必须沿轨道逐点记录，写清仪器和日期。竣工资料里只写一句"对中合格"，等吊车在某个柱距开始发顿时，这句话没有任何价值。

## 轨道决策如何压到钢构包上

轨道安装的问题，通常早在一张加工图上就埋下了，离灌浆还有好几个月。

| 轨道决策 | 对钢构包的影响 |
|---|---|
| 轨距与假定值不同 | 牛腿与梁的位置、吊车跨这一跨的柱距 |
| 轨顶标高提高 | 牛腿标高、柱长，有时连檐口高度都要改 |
| 由焊接底板改为灌浆底板 | 底板节点、锚栓栓钉、垫片余量、梁上翼缘平整度 |
| 轨道线要设伸缩节点 | 吊车梁接头节点、与建筑伸缩缝的对位、车挡位置 |
| 吊车工作级别提高 | 梁截面、挠度限值、牛腿加劲、局部板厚 |
| 车挡与缓冲器荷载 | 轨道端部与柱牛腿处的局部加强 |

最贵的一种情况，是吊车梁加工完之后轨距或轨顶标高才变。这时它已经不是轨道问题，而是梁、牛腿和柱子的问题，而吊车的到货日期往往已经定死。

## 六个常见错误

1. **没测梁就先灌浆**。在从未测量过的梁上灌浆，等于把误差永久锁死，之后底板再也调不动。
2. **把灌浆当成砂浆**。普通砂浆会收缩、开裂，也灌不进薄缝；它是安静地失效，几个月后才以轨道异响的形式暴露。
3. **不留排气孔**。浆体绕过底板把空气封在中间，敲击时空响，实际承载面积只有设计值的一小部分。
4. **加水太多**。比规定更稀的自流平灌浆料很好浇，强度却只剩标定值的一小部分。
5. **先焊轨道后对中**。对中测量之前就把轨道焊死，等于取消了压板和垫片本来提供的调整量。
6. **漏掉伸缩节点**。跨建筑伸缩缝连续焊接的轨道，热天顶弯、冷天拉脱紧固件。
7. **提前加载**。浆体未达强度就装轨道、走吊车，压坏的那一层在底板下面再也修不了。

## 出口项目的责任边界

轨道安装正好落在钢构供应商、吊车制造商与当地团队的分界线上。典型出口包的分工是：

| 阶段 | 中赛负责 | 当地团队／吊车供应商负责 |
|---|---|---|
| 轨道与固定数据 | 做接口协调，核对梁节点与所供轨道数据是否匹配 | 吊车供应商提供轨道型号、轨距、固定节点和公差表 |
| 吊车梁与底板加工 | 加工、尺寸检查、编号、包装、装柜 | — |
| 吊车梁架设 | 提供安装技术指导、螺栓与对中作业说明 | 当地安装队实施 |
| 底板垫片与灌浆 | 技术指导中给出工艺说明与检查点 | 当地队按指定级别选材与施工，当地工程师验收 |
| 轨道安装与对中测量 | 按吊车供应商公差表复核测量记录 | 吊车供应商或其指定安装方实施并调轨 |
| 吊车调试 | — | 吊车供应商调试，按当地要求报检 |

这句话落到实处：钢构包可以让轨道安装变得顺理成章，也可以让它根本装不成，但它不负责装轨道。指望钢构厂交付一台调试好的吊车，是对包范围的理解错误；而让吊车供应商的公差表在加工完之后才到，则等于提前取消了钢构厂满足公差的能力。

## 下单前的检查清单

- [ ] 已拿到吊车供应商书面的轨道型号、轨距与轨顶标高
- [ ] 已拿到吊车工作级别、轮压与载荷图
- [ ] 底板做法已确认：焊接底板，或垫片＋灌浆底板
- [ ] 加工图上已体现底板节点、锚栓栓钉与垫片余量
- [ ] 轨道固定节点（压板、焊接压板或直接固定）已确认
- [ ] 轨道伸缩节点与建筑伸缩缝的对位关系已确认
- [ ] 车挡与缓冲器荷载已提给钢构设计
- [ ] 技术条件中已写明灌浆料级别、施工厚度范围与养护要求
- [ ] 测量方法与记录格式已确认，包含沿轨道的测点间距
- [ ] 合格值取自吊车供应商手册与当地规范，取严者
- [ ] 现场作业说明中已写入检查点与停检点
- [ ] 竣工资料清单已定义：对中记录、灌浆记录、扭矩记录、竣工轨道线

## 常见问题

**每条吊车轨道底板下面都要灌浆吗？**
不是。底板直接焊在吊车梁上、轨道再用压板压住的做法没有灌浆，标高由加工控制。灌浆用于底板先垫片找平、需要连续支承的情况，通常出现在较长轨道、较重吊车，或吊车供应商手册明确要求时。

**轨道底板下面用什么灌浆料？**
无收缩、可流淌的灌浆料，有标定的抗压强度和施工厚度范围，级别由吊车供应商或当地工程师指定。水泥基和环氧基都有使用，选哪种取决于间隙大小、可用的养护时间和使用环境，而不是当地能买到什么。

**轨道对中怎么测？**
轨距测两轨中心距，平面直线度用钢丝线或激光线比对，标高用水准仪或数字水平仪，接头间隙与错台用塞尺加靠尺。合格值来自吊车供应商安装手册与当地规范，测量沿轨道逐点记录。

**轨道由钢构厂装还是吊车厂装？**
通常由吊车制造商或其指定安装方安装，因为轨道、扣件和公差表都属于吊车包。钢构厂交付的是让轨道装得成的吊车梁、牛腿和底板节点，并提供结构的安装技术指导。

**灌浆没养护好可以先装轨道吗？**
不能。灌浆必须达到标定强度后才能上轨道、上压板、施加吊车荷载。压坏一层未达强度的浆体，底板下面无法修复。

**吊车梁加工完才发现轨距变了怎么办？**
那就是结构变更：牛腿位置、梁间距，甚至吊车跨的柱距都要动。所以吊车供应商的轨道数据必须在吊车梁深化之前定死，而不是等吊车到现场再说。

## 询价要提供什么

只给一个起重量，吊车厂房是报不出来的。请提供吊车供应商的数据表（轨道型号、轨距、轮压、工作级别）、厂房宽度与长度、已经定死的轨顶标高，以及项目要按哪一本当地规范验收。若吊车尚未选定，给出预计吨位与工作级别，吊车梁可以按写明的前提预留，而不是靠猜。
