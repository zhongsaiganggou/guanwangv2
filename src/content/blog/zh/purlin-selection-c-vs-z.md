C 型钢与 Z 型钢檩条都是冷弯薄壁的屋面与墙面构件。Z 型檩条通过搭接实现连续多跨、适合更长跨度；C 型檩条结构简单、适合较短跨度，也常用作墙梁。选型取决于跨度、荷载、屋面坡度与连接设计。中赛将檩条与屋面围护系统一并供货，并按结构图纸协调规格。

本文对比两种截面，并说明如何写进采购规格。

![屋面檩条成排固定在屋面梁上（概念示意图）](/images/blog/purlin-selection-c-vs-z/cover.jpg)

## 一、C 型与 Z 型对比

| 因素 | C 型檩条 | Z 型檩条 |
|---|---|---|
| 截面 | 槽形 C 截面 | 翼缘错位的 Z 截面 |
| 跨度表现 | 单跨或简单跨，跨度较短 | 连续多跨，可搭接 |
| 搭接 | 一般不搭接 | 支座处搭接实现连续 |
| 屋面坡度 | 简单低坡屋面 | 适合较陡与连续屋面 |
| 典型用途 | 檩条、墙梁、轻型构件 | 门式刚架屋面檩条 |
| 受弯效率 | 短跨表现好 | 长跨效率更高 |
| 连接 | 腹板或翼缘螺栓连接 | 支座处嵌套搭接 |

## 二、什么决定选型

- **跨度**——屋面梁或框架开间的间距。
- **荷载**——屋面恒载、风、雪与检修荷载；数值取决于当地规范与现场条件。
- **屋面坡度**——较陡屋面常用 Z 型搭接连续。
- **连接细节**——搭接长度、螺栓布置与连接件按檩条厂家表格。
- **腐蚀环境**——涂层厚度取决于现场大气与设计寿命。
- **供货情况**——截面规格与钢牌号应与项目规格一致。

檩条规格、搭接长度与间距必须按实际图纸与荷载计算——没有固定全球值。

## 三、规格清单

- 屋面与墙面檩条间距在布置图上明确
- 截面规格与钢牌号按荷载表选择
- 支座搭接长度与螺栓布置确认
- 连接件或支架按框架连接详图
- 涂层体系匹配腐蚀环境
- 需要时布置套管或角钢拉条
- 编号与包装按装柜计划列出

## 常见问题

### C 型和 Z 型檩条有什么区别？

C 型是槽形截面，用于较短、简单的跨度，也作墙梁；Z 型翼缘错位、支座搭接实现连续多跨，长跨效率更高。

### 我的屋面用哪种更好？

取决于跨度、屋面坡度、荷载与连接设计。门式刚架连续多跨屋面常用 Z 型；短跨与墙梁用 C 型。与设计工程师确认。

### C 型和 Z 型可以混用吗？

可以，实践中常见：屋面用 Z 型檩条、墙梁或小构件用 C 型，各按其跨度与荷载选定。

### 檩条能跨多长？

取决于截面规格、间距、荷载以及是否搭接。按檩条厂家荷载表针对实际项目计算——没有固定全球值。

### 檩条怎么固定在框架上？

檩条连接件（支座）螺栓连接或焊接在屋面梁上，檩条再螺栓固定在连接件上；支座处搭接按厂家详图。

### 檩条需要多厚涂层？

涂层体系取决于现场腐蚀环境与设计寿命。与供应商和当地工程师确认环境与规格。

### 我需要自己算檩条规格吗？

不需要。供应商按结构图纸协调檩条规格、搭接与细节，当地工程师确认荷载与规范要求。提交图纸与现场条件即可计算。

### 檩条包含在钢结构报价里吗？

檩条可以与框架和围护系统一起供货。在报价中确认范围、规格与涂层。
