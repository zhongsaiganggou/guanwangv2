组装标记是车间打在构件上的编码，用来告诉现场：这根构件属于图纸上的哪个位置、和哪一根构件是配对的。配对标记是其中一个专门解决“配对”的部分——柱与牛腿、梁端与连接板、拼接构件的两半，靠同一组配对码在现场重新认亲。组装标记让结构找得到，配对标记让节点装得上。少了它们，加工再准的框架到了现场也会变成一场搜索。

本文讲清组装标记怎么编、配对标记补了什么、什么情况下试装值得花钱、标记怎么熬过抛丸涂装与装箱，以及发货前买方该查什么。

## 第一部分：组装标记、安装标记、件号、箱唛不是一回事

四个词经常被混着用，但它们回答的问题不同。

| 标记类型 | 打在哪 | 回答什么问题 | 典型内容 |
|---|---|---|---|
| 组装标记 | 构件本体，车间 | 这根构件属于哪个图纸位置 | 轴线、标高、构件类型、序号 |
| 配对标记 | 必须互配的两根及以上构件 | 和哪一根配对、什么方向 | 配对码、左右、旋转或箭头 |
| 安装标记 | 构件与安装图 | 现场吊到哪里、装在哪里 | 同一套编码，远距离可读 |
| 箱唛 | 捆包、木箱或吊牌 | 哪一包发到哪里、里面是什么 | 包号、项目号、重量、件数 |

同一个编码承担多个用途是可以的，前提是逻辑写清楚、图纸对得上。不能接受的是同一个字符有两种含义，或者车间图上有码、安装图上找不到对应。

组装标记在详图阶段就要定，不是加工完再补。它必须和轴线、标高、吊装顺序对齐，因为这三者决定了构件的位置。涂装之后再改编号，要么重标，要么让现场相信自己的标签而不是图纸。

## 第二部分：能用的组装标记长什么样

全球没有统一的编号标准，项目规范各不相同，通常由加工厂提出、业主工程师在加工前确认。好用的系统共享同样的骨架：

- **位置基准**：轴线或轴网 + 标高，让编码指向一个位置，而不只是一种类型。
- **构件类型**：短前缀，如 C 柱、B 梁、R 斜梁、P 檩条、BR 支撑。
- **序号**：在同类型同位置内唯一。
- **方向**：左右、镜像或手别，用在非对称构件上。
- **配对引用**：需要时写上它所连接构件的编码。

像 `C-3/B-2-L` 这样的码是可读的：C 轴第 3 根、B-2 标高、左侧。像 `12` 这样的码不可读，因为它不带位置，等于在现场另起一套编号。

两条规则比格式更重要。第一，唯一：除图纸明确认定为可互换的构件外，不允许两根构件共用一个码。第二，可追溯：从构件到车间图、到装箱单、到安装图，一路查得下去，不需要打一通电话。

## 第三部分：配对标记——为什么一对构件需要自己的语言

加工误差会累积。牛腿焊偏 3 mm、梁端板转了一点、拼接板从错误一侧钻孔，这些在车间都还能装上，到了现场却没有胎架、没有第二次机会。配对标记的作用，就是让车间的“装得上”可以复现。

![两根待配对构件平放在垫木上，节点两侧有同色配对标记带和方向箭头（示意图）](/images/blog/steel-assembly-marking-match-marks/match-marks.jpg)

配对标记做三件事：

1. **绑定构件**。C-3 柱上的牛腿和配它的 B-2 梁共用同一个配对码。
2. **锁定方向**。箭头或左右字母说明哪一端朝哪，避免看起来对称的构件被装反。
3. **记录配合**。凡做过试装的节点，标记证明现场用的是同一对构件，而不是后来照图另配的一根。

配对标记最值钱的地方，是几何受限的节点：斜交或变截面节点、箱形柱的焊接短牛腿、组合截面、折线斜梁，以及开长圆孔或焊短牛腿、现场几乎没有调节余量的连接。

对直线框架上的普通栓接端板，配对标记的意义就小得多：任何一根同型构件都能装到任何同型位置，逐一配对只会增加搬运成本，不增加控制。

## 第四部分：什么时候试装值得花钱

试装（预拼装、车间预装）是把结构的一部分在厂里组装、检查、标记，再拆开打包。它不是默认工序，只有当现场装不上的风险高于厂内试装成本时才做。

| 条件 | 是否试装 | 原因 |
|---|---|---|
| 节点几何复杂或斜交 | 通常要 | 单看分开的图纸无法验证节点 |
| 箱形柱梁带焊接短牛腿 | 通常要，每类至少首件 | 焊接牛腿与封闭截面在现场几乎没有调节余量 |
| 大跨或折线斜梁 | 多数要 | 长度与角度误差只有装起来才暴露 |
| 重复的标准门式刚架 | 一般不要 | 同型构件可互换，图纸控制配合 |
| 新截面或新焊接参数的首件 | 要 | 在大批量生产前确认工艺 |
| 项目规范或工程师要求 | 要 | 合同要求 |
| 现场没有吊车时间做调整 | 要 | 第一次起吊就必须装得上 |

试装还有第二个好处，常被忽略：它是唯一能实际验证“标记本身是否好用”的办法。如果厂里的人靠标记配不上，现场的人同样配不上。

试装的成本是实打实的：场地、吊车台班、螺栓装拆、涂层破损修补、额外搬运。它应该单列报价，而不是藏进吨单价里，这样买方才能判断几何复杂度是否值得。

## 第五部分：标记方法与它能活多久

标记要熬过抛丸、涂装、打包、海运和现场搬运，比大多数人以为的寿命长得多。

| 方法 | 耐久性 | 适用 | 局限 |
|---|---|---|---|
| 油漆漏印 | 较好，在底漆或面漆表面 | 大构件，远距离可读 | 先标记后涂装会被盖住 |
| 记号笔 | 低 | 加工过程中的临时参照 | 褪色、蹭掉、涂装后消失 |
| 金属吊牌 | 高 | 捆包、小件、对涂装敏感的构件 | 搬运中可能被扯掉，需要固定点 |
| 钢印 | 很高 | 规范允许的重板与构件 | 部分钢种或部位不允许，会形成应力点 |
| 焊道标记 | 高 | 极少，仅在明确允许时 | 损伤表面，主构件上通常禁止 |
| 带码不干胶标签 | 中 | 装箱单与已挂牌的捆包 | 潮湿或高温下会脱落 |

由此有三条实操规则。

**先标记，再保护。** 构件抛丸、上底漆后，组装标记应打在底漆面上，并保持不被覆盖或加一层相容的清漆。用面漆直接盖住漏印，只有在标记仍然清晰时才可接受；不少车间的做法是面漆后在原位重标一次。

**别把唯一的标记放在会被遮住的面。** 柱子上会被混凝土包住的面、梁上被底板压住的面，标了也没人看得见。至少标两个面，并选择安装后仍然可见的面。

**配对标记必须两根都打，且打在节点附近。** 只标梁不标柱，梁进了捆包、柱进了另一包，配对码就失效了。配对码要打在连接处两侧，用同一套方向基准。

## 第六部分：标记、打包、装柜必须对得上

组装标记不只是车间的事，它是把车间和现场串起来的那根线。

- **装箱单**：每一包应列出所含的组装标记，现场开箱前就能发现缺件。
- **装柜顺序**：首批吊装用的构件应最后装或单独成包，到场即可用。有标记才做得到；没有标记，装柜计划只能按重量和猜测排。
- **捆包标签**：箱唛应引用包内的组装标记，而不是另起一套只存在于出口部电脑里的包号。
- **现场收货**：收货核对是用构件上的标记去对装箱单和安装图，比数件数快得多。

检验这套系统有个简单办法：随手拿一张装箱单，抽一行，只用单据和构件上的标记，试着在现场把这根构件找出来。如果几分钟都找不到，说明标记系统还没做完。

## 第七部分：常见错误与现场后果

| 错误 | 现场会发生什么 | 预防 |
|---|---|---|
| 只标类型，不标位置 | 工人在几个柱距里反复试 | 标记包含轴线与标高 |
| 配对码只打在一根上 | 另一根靠找、靠硬装 | 节点两侧构件都打配对码 |
| 对称构件没有方向标记 | 装成镜像或上下颠倒 | 节点处加左右字母或箭头 |
| 标记被涂层或别的构件遮住 | 吊装开始后读不到 | 标两个可见面，面漆后重标 |
| 漏印被面漆盖到看不清 | 现场自己起编号 | 保护或重标，打包前检查 |
| 打包后才标记 | 为了认件反复开包 | 标记与核对在打包前完成 |
| 详图定稿后又改编号 | 车间图、构件、安装图三边不一致 | 编号随图纸批准一起冻结 |
| 小件没有标记 | 支撑、连接板、螺栓混在一起 | 小件按组装与包号挂牌 |

最后一条错得最不成比例。少一个连接板标记，在车间补只要几块钱，到现场可能耗掉一天吊车时间。

## 第八部分：发货前检查清单

- [ ] 每根构件都有组装标记，且与批准的车间图、安装图一致。
- [ ] 每个几何受限节点，两根构件上都有配对码。
- [ ] 镜像、斜交、折线构件有方向标记。
- [ ] 标记在最终涂层后仍清晰，没有被盖住。
- [ ] 有一个面会被遮住时，至少另标一个可见面。
- [ ] 小件（连接板、支撑节点板、螺栓）按组装与包号挂牌。
- [ ] 装箱单使用的是同一套组装标记。
- [ ] 装柜顺序把首批吊装构件单独成包并清楚标注。
- [ ] 试装过的节点有记录，说明当时配对的是哪几根。
- [ ] 抽样标记由非标记本人对照图纸复核过。

**问：组装标记应该包含什么？**
答：位置基准（轴线与标高）、构件类型前缀、唯一序号，以及非对称构件的方向标识。如果这根构件要和特定伙伴配合，还要写上配对标记用的配对码。无法同时追溯到车间图与安装图的编码，不是可用的组装标记。

**问：组装标记就是安装标记吗？**
答：不完全等同。组装标记在加工与打包阶段标识构件及其图纸位置；安装标记是同一信息面向现场的呈现，要远距离可读、与安装图一致。很多项目用一套码兼顾两者，但现场版本必须在运输和涂装之后仍然清晰。

**问：什么时候该用配对标记，而不是每根构件都编唯一码？**
答：节点几何受限或做过试装时用配对标记：斜交连接、箱形截面的焊接短牛腿、折线斜梁，以及只能和自己的伙伴装上的构件。可互换的标准构件，位置码就够了，逐一配对只增加搬运成本。

**问：能在构件上打钢印或焊标记吗？**
答：只有在项目规范允许时才可以。钢印在部分重板上可接受，但主构件、高强钢或疲劳敏感部位常被限制；焊道标记在成品构件上通常禁止。常规做法是油漆、吊牌和标签，具体由规范决定。

**问：标记怎么熬过涂装和海运？**
答：打在稳定的表面上，抛丸和涂装时保护，车间工艺要求时在面漆后重标；捆包与小件用吊牌；打包后抽样检查。用记号笔在抛丸前写的码，活不下来。

**问：小件要逐件标记吗？**
答：支撑节点板、连接板、螺栓这类小件，按组装与包号挂牌即可，不必每件一个唯一码。逐件标记会拖慢打包，挂牌在搬运中也容易掉；识别信息由包标签和装箱单承担。

**问：标记返工由谁承担？**
答：图纸批准后改编号、或者车间把标记盖进漆里，属于加工端返工，费用应在下单前约定。构件标得没问题、现场把标记弄丢，属于现场成本。责任先说清，后面就不用吵。

## 第九部分：责任边界

| 阶段 | 中赛范围 | 当地团队范围 |
|---|---|---|
| 详图与编号 | 提出标记逻辑，编制车间图与标记清单待批 | 对照轴线、标高与吊装顺序审核并批准编号 |
| 加工 | 施打组装标记与配对标记，按要求试装 | 加工前确认项目特定的标记要求 |
| 打包与装柜 | 标注捆包、按组装标记编装箱单、按吊装顺序装柜 | 确认收货计划与卸货设备 |
| 现场安装 | 提供带标记的构件与安装技术指导 | 识读标记、配对、安装与校正，管理当地人力与吊车 |
| 报批 | 按要求提供加工与标记记录 | 办理许可、检验与政府报批 |

除合同另有约定，现场实体安装与标记的现场解释由当地团队负责；供应商的责任是把标记做清楚，并在打包全过程保持一致。

## 第十部分：加工端的实话

在典型的出口项目里，标记是打包前最后几道工序之一，也是进度一紧最先被牺牲的一环。这个顺序是反的。少一个标记，再快的吊车也补不回来；现场认不出构件，就会自己想办法。

可行的顺序是：编号随图纸批准冻结，加工时施打，受限节点试装，涂装前核对一次、打包前再核对一次，装箱单直接用同一份标记清单生成。这不是多一道官僚流程，而是让现场装得上的最短路径。
