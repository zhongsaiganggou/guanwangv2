---钢结构报价单能不能比，取决于三件事是否对齐：供货范围、计价重量口径、贸易条款。看报价的正确顺序是先看供什么、再看他怎么计量、最后看排除了什么，然后才去看总价。同一个厂房报出两个相差很大的数字，未必有人在骗你——一家可能是出厂价、按理论重量、只做底漆；另一家可能是 FOB、含包装与配件、含完整涂装体系。

这篇文章讲的是你手上已经拿到的那份文件。下面逐行拆解报价单应有的十项内容、最容易被排除在外的费用，以及把两家供应商放到同一口径上的方法。


## 同一个厂房，为什么总价不一样

钢材是按重量卖的，不是按建筑面积卖的。用"每平方米多少钱"来报，吨位、围护含量、配件清单全被藏起来了，两家可能就是同一块地、不同的房子。总价还会随钢材牌号、涂装体系、墙面板构造、包装方式、柜量、运费有效期和付款条件变化。

想弄清这些变量背后的成本逻辑，可以先看[钢结构厂房造价的构成](/zh/blog/steel-warehouse-cost-guide/)。本文的前提是：你已经有数字了，现在要判断这个数字对不对。

## 一份报价单该有的十项内容

少了任何一项都不算错，但都还不具备可比性。

| 报价行 | 应写明什么 | 要核对什么 |
|---|---|---|
| 1. 供货范围 | 只供材料、含加工、含包装、含海运、含安装 | 价格是停在工厂门口，还是到你的工地 |
| 2. 计价重量 | 按图纸理论重量还是实际过磅重量；出厂重量还是装船重量 | 两家是否同一口径，否则吨位没有可比性 |
| 3. 钢材牌号与来源 | 各构件组的牌号、钢厂来源、质保书 | 是否允许代用、由谁批准 |
| 4. 加工范围 | 下料、钻孔、焊接标准、公差、预拼装、检验等级 | 第三方检验或无损检测是在价内还是价外 |
| 5. 表面处理 | 除锈等级、底漆类型、干膜厚度、面漆、厂内或现场施工、修补 | "刷过漆"不是规格，体系和膜厚才是 |
| 6. 围护与保温 | 板型、厚度、芯材与密度、颜色、泛水收边、紧固件 | 配件、屋脊与檐口收边是列项还是含糊"含" |
| 7. 门窗洞口 | 门、窗、百叶、采光带、五金、暂列金额 | 哪些是供货项，哪些是当地采购的暂估价 |
| 8. 包装标识装柜 | 打包方案、构件编号、装箱单、柜量、由谁装柜 | 装柜、加固、码头操作费是否在价内 |
| 9. 贸易条款与运费 | EXW、FOB、CIF 或 DAP、指定港口、运费有效期、卸货责任 | 哪些费用到起运港为止，哪些从目的港开始 |
| 10. 商务条款 | 有效期、付款节点、交期、随附单证、变更流程 | 是固定价还是可调价，触发条件是什么 |

缺哪一行，就用书面方式问，不要按"最便宜的理解"自行假设。供应商的答复就是报价的一部分。

## 最常被漏掉的九项

钢结构价格与一栋建成建筑之间的差距，基本都在下面这些项目上，而它们几乎都不是钢材。

| 项目 | 通常由谁负责 | 为什么重要 |
|---|---|---|
| 基础与土建 | 当地土建承包商 | 常是钢构包之外最大的一笔 |
| 锚栓预埋、定位与灌浆 | 当地土建 | 偏位最后变成现场费用，不会出现在钢材价里 |
| 安装人工与吊车 | 当地安装队 | 在很多市场，这一项接近材料价 |
| 许可、注册工程师、报审 | 业主／当地工程师 | 无法随钢材一起出口 |
| 进口关税、增值税、清关、港杂 | 买方 | 取决于目的国与税则归类 |
| 内陆运输与工地卸货 | 买方 | 掏箱与场地条件最容易被低估 |
| 现场修补与补漆 | 当地承包商 | 运输磕碰和现场切割需要配套涂装，不是"一桶漆" |
| 防火涂料施工（如需） | 当地专业分包 | 钢材可带体系供货，但施工只能在当地完成 |
| 超出约定等级的第三方检验 | 买方 | 增加的见证点与检测通常另行收费 |

看报价时只需要带着一个问题：这个价是买钢材，还是买一栋房子。除合同另有约定，上表第二列都在供货加工报价之外。

## 两家报价怎么放到同一口径

同口径对比不是压价谈判，而是把"其实并不存在的差异"先去掉。

1. **先把两家剥到同一范围。** 把运费、安装、可选项从两边都拿掉，只比供货加工本体。
2. **重算吨位。** 要求两家给出分构件组的重量明细，并确认是理论重量还是实际重量。
3. **把涂装拉平。** 比除锈等级、底漆类型、干膜厚度、是否含面漆，而不是比"有没有刷漆"。
4. **把围护拉平。** 比板厚、芯材密度、颜色、收边与紧固件清单。
5. **把运费拉平。** 同一港口、同一柜量、同一有效期、同一贸易术语。
6. **把被排除的加回去。** 基础、安装、税费、内陆运输单独列一栏当地费用，才是真实项目总价。

| 需要拉平的项目 | 分别问两家什么 | 为什么影响对比 |
|---|---|---|
| 计价重量口径 | 理论还是实际；出厂还是装船 | 吨位差异可能只是计价惯例，不是设计差异 |
| 涂装 | 体系、膜厚、厂内还是现场施工 | 只做底漆与完整体系是两种产品 |
| 围护 | 板的构造、芯材、配件清单 | 配件是真实成本，最容易被藏起来 |
| 包装装柜 | 打包方案、柜量、由谁装柜 | 装柜与加固会改变到岸成本 |
| 贸易术语 | EXW／FOB／CIF、指定港、有效期 | 两个都写 FOB，覆盖的起运港费用可能不同 |
| 付款 | 定金比例、节点、尾款触发条件 | 现金流本身就是价格的一部分 |

如果某家回答不了某个拉平项，这件事本身就在说明这份报价是怎么拼出来的。

*涂装要按体系和干膜厚度定义；报价单里写"已涂装"并不构成规格。*

## 为什么最低那个数往往不是最低成本

下面这些特征，通常能解释一个低得可疑的总价：

- 只给每平方米单价，没有吨位与构件明细
- 只写"标准涂装"，没有体系、膜厚和施工地点
- 围护只报板，泛水收边和紧固件不列项
- 运费写"下单后再通知"
- 没有有效期，或有效期早于你的决策日
- 交期短于加工加涂装的实际工序时间
- 没有单证清单，质保书与装箱单变成后加项
- 范围里悄悄排除了预拼装、标识或装柜

这些都不证明对方有恶意，只证明两份报价不在同一口径上——正是上一节要解决的问题。

## 可直接引用的结论

**一份合格的钢结构报价单应包含什么？**
应写明供货范围、计价重量口径、钢材牌号与质保书、加工与检验范围、涂装体系与干膜厚度、围护板与配件清单、门窗洞口、包装标识与装柜安排、贸易术语与运费有效期，以及有效期、付款节点、交期等商务条款。

**钢结构报价里通常不含什么？**
基础与土建、锚栓预埋定位与灌浆、安装人工与吊车、许可与注册工程师报审、进口关税与清关、内陆运输与工地卸货、现场补漆修补、防火涂料施工，以及超出约定等级的第三方检验，除合同另有约定，通常都在供货加工报价之外。

**两份钢结构报价怎么比才公平？**
先把两份剥到同一供货范围，用同一重量口径重算吨位，拉平涂装体系与围护配件清单，对齐贸易术语、港口、柜量与有效期，再把被排除的当地费用单独加成一栏。只有得出的项目总价才具备可比性。

*包装、标识、装柜与码头操作，夹在钢材价与到岸价之间；先确认报价覆盖了其中哪几项。*

## 常见问题

### 同一个厂房，两家总价差很多，正常吗？

通常是因为供货范围、计价重量口径或涂装与围护规格不同，而不是其中一家乱报。先把这三项拉平再比。

### 每平方米单价能作为参考吗？

可以作为早期粗估，但没有吨位、围护含量与配件清单支撑时，不能用于对比。

### 报价按理论重量还是实际重量？

行业里两种都有；关键是两份报价使用同一口径，并以图纸为准。理论重量一般按构件明细计算。

### 报价单只写"已涂装"，为什么不够？

因为只做底漆与完整涂装体系（含明确干膜厚度）是两种产品，耐久性和成本都不同。

### 锚栓包含在报价里吗？

通常随钢构包供货，但预埋定位、校正与灌浆属于现场作业。要确认哪一部分在价内。

### 出口报价包含安装吗？

一般不含。安装人工、吊车与现场安全由当地负责，除合同明确约定外通常单独报价。

### 报价应附哪些文件？

至少应有范围说明、重量明细、涂装与围护规格、贸易术语、有效期与付款条件；若含质保书与装箱单，应逐项列明。

### 报价有效期一般多久？

取决于供应商、钢材市场与运费市场；日期应写在报价上，不要自行假设。可参考[报价为什么会过期](/zh/blog/steel-structure-quotation-validity-price-changes/)。

## 想让报价能逐行对比，把图纸发过来
